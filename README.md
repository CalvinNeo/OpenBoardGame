## Switching browsers

Choose **Logout → Confirm & Copy Access Key** to disconnect while keeping your
current room and seat. In the other browser, choose **Create Room** or **Join Room**,
then select **Access key** in the name dialog and paste the copied key. This
reconnects directly to the original room, player, and game state instead of creating
a new player. Normal **Confirm** keeps the existing logout behavior.

The key only packages the existing room reconnect credentials; it does not create
an account or add access-key storage. Keep it private. It cannot recover a room or
seat that no longer exists. If copying fails, you stay logged in.
