## Switching browsers

Choose **Logout → Confirm & Copy Access Key** to disconnect and transfer all saved
room credentials from this browser, not just the current room. In the other
browser, choose **Create Room** or **Join Room**, then select **Access key** in the
name dialog and paste the copied key. This restores access to your previous rooms
without creating a new player. It opens the requested room if included, otherwise
the last available room. Use **Reconnect** in the room list to switch between your
previous rooms, keeping each room's original player, seat, and game state. Normal
**Confirm** keeps the existing logout behavior.

The key is a snapshot of all existing room reconnect credentials at export time;
it does not create an account or add access-key storage. Keep it private. It cannot
recover a room or seat that no longer exists, but an unavailable room does not
prevent restoring the others. Previously copied single-room keys still work for
that room; copy a new key to transfer all saved rooms. If copying fails, you stay
logged in.
