# Task 97 — The Castles of Burgundy（勃艮第城堡）

## 范围与依据

新增 `castles_of_burgundy`，支持 2–4 人、房间机器人、旁观与存档恢复。采用 2011 基础版规则、所有玩家使用标准 1 号领地与中央起始城堡；包含六类板块、八种建筑和全部 26 张知识板块。不包含其他领地、扩展与单人模式。

核对 [Ravensburger / alea 原版英文规则书（存档）](https://cdn.1j1ju.com/medias/04/f5/f9-the-castles-of-burgundy-rulebook.pdf)。规则文字重新归纳，棋盘自行用 CSS / SVG 绘制，只用文字、颜色和 Emoji，不使用商业 UI 或原版美术。

## 规则与状态机

- 共 A–E 五阶段，每阶段五轮；每轮公开投掷每人两颗骰子和一颗公共白骰。白骰将本轮货物放到对应货站，不能作为玩家行动骰。
- 玩家按本轮开始时的船只顺序，连续完成两个骰子行动；船只改变下一轮顺序，同格后来者排在上方。起始顺序随机，依次获得 1–4 工人。
- 四种主行动：按骰点从货站拿板块到三格仓库；按骰点将仓库板块放入领地；卖出某一骰点的全部货物；用任意骰子取得工人。工人可调整骰点，1 与 6 相邻；服务端计算最少工人费用并在确认前展示。
- 领地放置检查颜色、空位、与已建板块相邻；同一城市不能有重复建筑，知识 1 例外。仓库满时必须明确选择要丢弃的旧板块。
- 每回合另可花 2 银币购买一次黑市板块；知识 6 扩展购买来源。使用 `End Turn` 保留两颗骰子用完之后购买的机会。
- 建筑、城堡与船只产生即时待选步骤，必须先处理或明确跳过允许放弃的奖励，再继续普通行动。市政厅、城堡引发的连锁逐步处理。船只取货明确选择货站和可容纳的种类，最多保留三种货物。
- 畜牧按同一牧场内相同动物累计得分；知识 7 按实际计分的板块数量加分。区域完成按大小 1 / 3 / 6 / 10 / 15 / 21 / 28 / 36 加本阶段 10 / 8 / 6 / 4 / 2 分；每色第一、第二位完成者领取相应人数奖励。
- 每阶段结束发矿山收入与知识 2 奖励。每一轮结束进入 `round_end`，保留刚完成的局面、收入与分差；全员点击 `Next Round` 后才继续，机器人仅确认自己的席位。末轮显示最终分项与胜者。
- 终局计入未售货物、银币、每两工人及知识板块；同分先比较领地空格更多者，再比较最终行动顺序中更靠后者。原版英文印刷为更少空格，按 [Yucata 规则中的勘误](https://www.yucata.de/en/Rules/CastlesOfBurgundy)更正。

## 服务端实现

- `game/castles_of_burgundy_data.py`：1 号领地坐标、骰点、区域，板块与知识说明，人数对应货站配给，严格 action / config schema。
- `game/castles_of_burgundy.py`：初始化、纯字典状态、确定性随机、合法动作与费用、待选步骤、计分、机器人、深拷贝保存恢复。
- 所有动作在副本验证与执行，失败不扣资源、不消耗骰子、不污染市场或回合；拒绝观众、非当前玩家、错误阶段及类型不正确的请求。
- 公开视图包含所有已公开的骰子、板块和玩家领地；隐藏未来供给顺序和随机状态。仅当前可操作玩家获得合法动作详情。
- 接入 `game/definitions.py`、`game/tags.py`；运行 `scripts/gen_dev_order.py` 更新开发顺序。

## 前端实现（FRONTEND.md / task40.md）

- 独立 `static/games/castles_of_burgundy.js`，IIFE 私有作用域；全局接入函数使用 Burgundy 前缀。独立 `static/castles_of_burgundy.css`，类名以 `burgundy-` 限定。`app.js` 只增加面板显示及渲染分发。
- 酒红与浅羊皮纸风格；🏰 城堡、⛵ 船只、⛏️ 矿山、📜 知识、🏘️ 建筑、动物 Emoji；🪙 银币、👷 工人、⭐ 分数，类型同时配文字以便辨识。
- 桌面左侧六角领地，右侧骰子与行动；公共货站紧凑排列。玩家领地可切换查看，知识说明、回顾、日志放可折叠或限高滚动区。移动端使用 `Estate` / `Depots` 标签切换，下方保留行动区和所选面板；拿取、购买及船只效果自动切换到货站。货站两列，禁止横向滚动、文字溢出和模块覆盖。
- 点击骰子、市场／仓库板块、目标六角格后显示具体效果与工人费用，再 `Confirm`。所有动作都通过点选完成，无 JSON、无坐标文本输入。空白与 Esc 取消选择，不添加 Clear Selection。
- `Help` 规则对话框；`Explain` 捕获点击屏蔽原操作，有说明的控件显示虚线与问号光标，disabled 控件也能通过 pointerdown 命中查看说明。解释后或 Esc 退出，弹窗支持 Esc、遮罩关闭与焦点恢复。
- 非游戏内容 UI 使用英文；按钮紧凑换行；`Next Round` 显示已确认人数，等待真人时不自动跳过。
