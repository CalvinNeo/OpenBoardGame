## 核心体验

每名玩家从自己颜色的 `1-5` 五张起始牌开始，手牌通常维持 3 张。轮到玩家时必须完成以下三种行动之一：

1. 打出牌到场地、生命之河，或使用能力牌；
2. 用手牌组成尚未使用的配方，生成一颗宝石；
3. 消耗一颗共享心，把一张牌交给队友。

三行场地各有 7 个格位。永恒族沉睡在行的右端，玩家从左向右填牌。第一次填到永恒族左边通常需要 4 张牌，之后依次需要 5、6 张；第四圈没有永恒族，需填满 7 张并取得该行奖励。完成一行时，行动玩家选择复苏其中一个永恒族，将其专属 8 张牌放到自己的玩家牌库底部，从而延续牌流；但该永恒族的诅咒会立刻影响全队，直到有人献上宝石。

这是一个共同胜负游戏：所有玩家达成关卡目标即胜；任一玩家在自己的回合无法执行三种行动之一，或从河流奖励区取得 `Game Over`，全队即败。若胜利与失败在同一玩家的同一回合发生，**胜利优先**。

### 卡牌类型

#### 数字牌

- 颜色：🔴 热情 `red`、🔵 冷静 `blue`、🟢 和谐 `green`、🟡 挑战 `yellow`、🟣 灵感 `purple`。
- 数字：`1-9`。
- 可打到场地或河流，也可用于生成宝石。

#### 双色数字牌

- 只有 `red_green` 与 `blue_yellow` 两种颜色对。
- 打到场地时必须选择正向或倒向，牌的左半颜色约束左邻牌，右半颜色约束右邻牌；放下后不能旋转。
- 生成宝石或判断谜题时，行动者为它选择其中一种颜色。
- 牌本身仍只有一个数字。

#### Rare 万能牌

- 打出当下可忽略公共相邻限制和当前场地牌限制，但女巫诅咒仍会禁止它进入场地。
- 打出当下不视为任何颜色或数字，所以也不会被数字/颜色诅咒挡住。
- 放入场地后，在后续牌的合法性、宝石配方和谜题判断中可代表任意颜色及数字。
- Rare 可以相邻。
- 山地的 `9` 右边、洞穴的 `1` 右边仍可继续放任意数量 Rare。
- 可直接打入河流；多个 Rare 可同时用于一个宝石配方。

#### 能力牌

- 选择“使用能力”时执行对应效果，通常随后进入弃牌区。
- 也可不发动效果，像普通资源一样打到河流。
- Stage A 中 A 系能力牌进入关卡区；第三张带来一颗星。
- 牛头人能力牌例外地进入场地。

#### 骷髅牌

从 Stage D 开始出现，有红、蓝、绿、黄、紫五色。

- 只能打到场地，通常不能进入河流或生成宝石。
- 必须遵守场地、相邻颜色和诅咒限制，但可放在另一张骷髅右侧。
- 一行存在未覆盖骷髅时，普通数字牌或 Rare 不能继续放到它右侧，必须先从左向右覆盖骷髅。
- 覆盖时，数字牌需与骷髅同色；双色牌任一颜色匹配即可；Rare 匹配任意色。
- 白色骷髅奖励牌只能覆盖彩色骷髅，之后任意颜色数字牌都可覆盖白色骷髅。
- 玩家可以公开说自己手里有骷髅牌。

40 张随机牌的文字规则可确认是红、蓝、绿、黄各 `1-9` 共 36 张，再加 4 张 Rare；随机牌中没有普通紫色数字牌。

### 建议的卡牌数据结构

```text
CardDefinition:
  id: string
  source_deck: starting | eternal | random | river_bonus | gatekeeper | special
  kind: number | rare | ability | skull | white_skull | camp_bonus | game_over
  number: 1..9 | null
  colors: [red|blue|green|yellow|purple]  # 0、1 或 2 个
  ability_id: string | null
  eternal_id: string | null
  metadata: object

CardInstance:
  instance_id: string
  definition_id: string
  orientation: normal | rotated | null
  chosen_color: color | null
  chosen_number: 1..9 | null
  face_up: boolean
```

不要把 Rare 的任意颜色/数字永久写进 `chosen_*`。它在不同后续判断中可以有不同解释；`chosen_*` 只记录规则明确要求当场选择且之后固定的项目，例如双色牌的场地方向。

## Stage A 新手模式设置

### 4 人新手模式起始布局

1. 三行各放 3 个永恒族及其洗好的 8 张专属牌：
   - 上行：A-1 凤凰、A-2 人鱼、A-3 国王；
   - 中行：B-1 幽灵、B-2 骷髅、B-3 女巫；
   - 下行：C-1 美杜莎、C-2 牛头人、C-3 海怪。
2. A-4 妖精、B-4 吸血鬼、C-4 木乃伊不使用。
3. 上、中、下行场地分别为山地、洞穴、营地。
4. 在 6 个星星来源处放星星；获 4 颗即胜。
5. 放置 8 个普通宝石配方和对应宝石。
6. 共享区放 3 颗心。
7. 上行第四圈奖励放营地奖励牌；中行是恢复全部心；下行是获得星星。
8. 河流奖励区从下往上为 `Game Over`、3 张河流 Rare。
9. 每名玩家选择红/蓝/绿/黄之一，拿对应 `1-5` 起始牌及 2 个交流圆片。
10. 洗各自牌库并抽 3 张。看完手牌、摆好交流圆片后，共同决定起始玩家，之后顺时针行动。

### 人数修正

- 3 人：使用 3 人专用的 6 宝石配方卡，而不是完整 8 配方；具体 6 格布局需从正版组件录入。
- 2 人：每人选择一个主颜色，再各选一个未用的副颜色。洗副颜色的 5 张起始牌，随机移除 3 张，把剩余 2 张面朝下放到自己的玩家牌库底部，所以起始牌库为 7 张。
- 1 人：不直接套多人规则，使用后文“三傀儡单人模式”。

为方便测试，配置可接受 `seed` 和显式 `start_player_id`，正式房间默认由服务端随机数决定并写入日志。

## 回合状态机

```text
setup
  -> awaiting_action
  -> awaiting_play_options       # 双色方向、Rare/谜题声明等
  -> awaiting_eternal_choice     # 一行触发复苏且有多个目标
  -> awaiting_jewel_target       # 生成宝石后选择献给谁
  -> awaiting_ability_choice     # 海怪、美杜莎、木乃伊等多目标效果
  -> resolving_events
  -> refill_hand
  -> gatekeeper_turn?            # Stage D / B+
  -> awaiting_action | won | lost
```

任一需要选择的中间阶段都只允许指定玩家提交对应 action。不要依赖前端先后动画来决定规则顺序。

### 一个正常回合

1. 当前玩家选择且完成一种主行动。
2. 把由该行动产生的事件按规则优先级全部结算。
3. 先检查关卡胜利，再检查该行动造成的即时失败，例如取得 Game Over；同回合同时满足时胜利优先。
4. 当前玩家从自己的玩家牌库顶抽牌，直到手牌达到当前上限，通常为 3。
   - 手牌已经超过上限时不抽也不弃。
   - 牌库不足时只抽剩余张数。
   - 刚复苏取得的 8 张牌放在牌库底；若原牌库已空，它们自然成为当前牌库并可立刻补牌。
5. 进入顺时针下一位玩家；需要守门人回合时，在完整一圈玩家回合后插入。
6. 只有轮到某位玩家开始行动时，才检查该玩家是否三种主行动全都无法执行。不能在他刚打光手牌时提前判败，因为其他玩家在其下回合前仍可能给牌。

## 三种主行动

### 1. 打出一张牌

玩家选择下列一种目的地：

- 场地：普通数字牌、双色牌、Rare、骷髅或特定能力牌；
- 河流：数字牌、双色牌、Rare、未发动的能力牌；
- 发动能力：能力牌按效果进入关卡区、场地或弃牌区。

通常只打 1 张。节庆场地或飞马效果允许在同一行动打 1-2 张到任意场地行/河流组合。两张都放完后才处理复苏和第四圈奖励；河流达到第 5 张后不能再放第 6 张。

### 2. 生成宝石

前提：至少已有一个未获宝石的复苏永恒族，且所用配方仍有宝石。

普通 4 人配方：

| id | 消耗手牌 | 额外效果 |
|---|---|---|
| `any_2` | 任意 2 张 | 无 |
| `any_3` | 任意 3 张 | 无 |
| `same_color_3` | 同色 3 张 | 无 |
| `different_color_3` | 三种不同颜色 | 无 |
| `one_or_nine` | 1 张数字 1 或 9 | 无 |
| `same_number_2` | 同数字 2 张 | 无 |
| `same_number_3` | 同数字 3 张 | 无 |
| `one_five_nine` | 数字 1、5、9 各 1 张 | 同时获得星星 |

结算：

1. 校验选牌能满足尚未使用的配方；
2. 玩家选择一个没有宝石的复苏永恒族；
3. 对双色牌选择其中一色，Rare 可代表任意颜色/数字；能力牌只可用于 `any_2` 或 `any_3`；
4. 所用牌全部面朝上进入河流；
5. 移走该配方宝石并放到目标永恒族上，立即关闭其持续诅咒；
6. 如果河流达到 5 张或更多，仍只触发一次河流奖励，然后清空整条河流；
7. `one_five_nine` 同时触发一颗星。

女巫能力可以不耗数字/Rare 直接生成任一尚未使用的宝石，但不能选 `one_five_nine`。

### 3. 给队友一张牌

- 必须仍有未消耗的共享心。
- 当前玩家选择 1 张手牌与另一位玩家，牌面朝下交给对方。
- 消耗 1 颗心；接收者手牌可以超过上限。
- 只有行动玩家在回合末补牌，接收者不会立即补或弃。
- 可以交骷髅牌。
- 中行第四圈奖励会恢复全部已消耗的心。

## 场地系统

### 公共规则

- 每行 7 个位置，从左到右放牌，不能跳格。
- 普通情况下，相邻牌不能同色，也不能同数字。
- 双色牌使用朝向后，左邻只比较其左侧颜色、右邻只比较其右侧颜色。
- 场地关闭后不能再放牌。
- 活跃诅咒优先过滤可打牌型；场地规则和公共规则再判断序列。

### 普通场地牌

| id | 难度 | 额外规则 |
|---|---:|---|
| `camp` 营地 | 1 | 无，只有公共规则 |
| `forest` 森林 | 2 | 相邻数字不能连续，例如 4 旁不能放 3 或 5 |
| `lake` 湖泊 | 2 | 颜色按红→蓝→绿→黄循环，可从任意色开始；紫色可替代；紫色不能相邻 |
| `grassland` 草原 | 2 | 只允许 1、2、3、4、8、9 |
| `mountain` 山地 | 3 | 数字严格递增 |
| `cave` 洞穴 | 3 | 数字严格递减 |
| `riverside` 河岸 | 3 | 只允许奇数 1、3、5、7、9 |
| `valley` 山谷 | 4 | 只允许偶数 2、4、6、8 |
| `desert` 沙漠 | 5 | 相邻数字必须连续；1 和 9 不相邻 |
| `swamp` 沼泽 | 5 | 红→蓝→绿→黄循环，并且只允许 1-5；紫色可替代且不能相邻 |

如果一行第一张是双色、Rare 或紫色，颜色循环尚未唯一确定。合法性引擎必须保留所有可能解释，不能贪心固定第一种颜色。

### 关卡专属场地

| id | 规则 |
|---|---|
| `castle` 城堡 | 数字严格递增且整行同色；紫色可替代目标色；同色/紫色可相邻；仍不能同数字相邻 |
| `fog` 雾 | 整行同数字；同数字允许相邻；同色仍不能相邻 |
| `lost_forest` 迷失森林 | 相邻数字差 1 或 2 都禁止；整行同色，紫色可替代；同色/紫色允许相邻；同数字仍禁止 |
| `festival` 节庆 | 放置同营地；所有玩家每回合可打 1 或 2 张到场地/河流 |
| `labyrinth` 迷宫 | 本圈完整行的数字需左右镜像；若格数为偶数，中间两张数字相同；颜色无需镜像，但相邻不能同色 |

迷宫行在尚未填满时，只需保证当前前缀仍存在一种可完成的镜像解释；最后一格落下时必须得到完整镜像。

### 为什么需要约束求解器

Rare、紫色替代、双色朝向、颜色循环、骷髅覆盖和飞马连续出牌会组合出现。推荐统一实现：

```text
is_field_play_legal(state, player_id, card, row, options):
  reject closed/full row
  reject card kind or active curse
  reject unresolved-skull targeting mistakes
  build hypothetical row
  if newly played card is Rare:
    ignore common/field restrictions for this placement
    keep Rare as wildcard for future checks
  else:
    return row_has_at_least_one_valid_interpretation(hypothetical_row)
```

`row_has_at_least_one_valid_interpretation` 对最多 7 个位置做小规模动态规划/回溯，枚举 Rare 的必要值、紫色替代色和未定颜色循环即可。服务端同时返回非法原因枚举，例如 `same_adjacent_color`、`not_ascending`、`curse_number_4`，供 UI 提示和 Explain 使用。

求解时不能用“当前效果”重新审判整行历史：

- 已经合法放下的牌永远留在原位；巴隆/九尾效果后来被宝石关闭，不会让此前形成的同色/同数字相邻突然非法。
- 每次放牌要保存当时获得的公共规则豁免、场地规则版本和 Rare 豁免，后续只验证新落牌带来的约束。
- Rare 本次落位不会因公共/场地规则失败，但要保留其未定颜色/数字的潜在约束，供右侧后续牌求解。例如沙漠中的 `4 · Rare · 9` 找不到一个连续数字解释，第三张 9 不能落下。
- 诅咒只检查当前准备打出的牌，不追溯已在场地中的同类牌。

建议给每条相邻边保存 `created_under` 与 `exemptions`，同时给当前圈维护 `wildcard_constraints`；这样既能正确“坍缩”Rare 的解释，又不会因效果开关误杀历史牌列。

## 复苏、诅咒与行圈数

### 复苏

当新牌落在某行当前永恒族正左侧的格位时：

1. 若该行还有多个永恒族，行动玩家从中选择 1 个；
2. 将永恒族翻至正面，放入公共复苏区最左侧空位；
3. 将其洗好的 8 张专属牌面朝下放到该玩家牌库底部；
4. 本行已打出的牌面朝上进入弃牌区；
5. 剩余永恒族向右靠齐；
6. 该永恒族诅咒立即生效；若是一次性 E 系诅咒则立即结算后结束；
7. 若是第 9 个复苏永恒族，获得相应星星。

每行所需牌数自然为 `7 - sleeping_eternals_count`：前三圈通常为 4、5、6，第四圈为 7。

### A-C 持续诅咒

| 系列 | 永恒族 | 活跃诅咒 |
|---|---|---|
| A | 凤凰 `A1` | 数字 1 不能进入场地 |
| A | 人鱼 `A2` | 数字 4 不能进入场地 |
| A | 国王 `A3` | 数字 6 不能进入场地 |
| A | 妖精 `A4` | 数字 9 不能进入场地 |
| B | 幽灵 `B1` | 数字 5、7 不能进入场地 |
| B | 骷髅 `B2` | 数字 2、8 不能进入场地 |
| B | 女巫 `B3` | Rare 不能进入场地 |
| B | 吸血鬼 `B4` | 紫色牌不能进入场地 |
| C | 美杜莎 `C1` | 红色及红/绿双色牌不能进入场地 |
| C | 牛头人 `C2` | 蓝色及蓝/黄双色牌不能进入场地 |
| C | 海怪 `C3` | 绿色及红/绿双色牌不能进入场地 |
| C | 木乃伊 `C4` | 黄色及蓝/黄双色牌不能进入场地 |

数字、颜色或 Rare 被诅咒时，仍可进入河流或用于生成宝石。一个永恒族获得宝石后，它的持续诅咒失效；宝石若被石魔偷走，诅咒重新生效。

### D 系正面效果

D 系规则仍称其为 Curse，但它们给玩家正面能力：

| 永恒族 | 效果 |
|---|---|
| 飞马 `D1` | 当前玩家一次打牌行动可放 1-2 张到任意场地/河流组合 |
| 巴隆 `D2` | 每行允许最多两张同色牌相邻，其他数字与场地规则不变 |
| 灯神 `D3` | 回合末手牌补到 4，而非 3 |
| 九尾 `D4` | 每行允许最多两张同数字牌相邻，其他颜色与场地规则不变 |

在 Stage F，这些效果只属于对应颜色玩家；普通关卡中按公共活跃诅咒处理。

### 第四圈奖励与关闭行

一行前三次填满会复苏永恒族。第四次填满时：

- 上行：行动玩家立即把营地奖励牌放到另外两行之一，使该行剩余圈段按营地规则；
- 中行：恢复全部已消耗的心；
- 下行：获得一颗星；
- 随后该行关闭，牌留在原位；场地牌翻面放到奖励区，中行场地牌因会遮挡心而进入弃牌区。

有场地牌叠堆时，前三圈结束还要弃掉当前场地牌并翻开下一张；第四圈才关闭。

## 河流与弃牌区

- 打到河流没有放置限制，诅咒牌也可以进入。
- 第 5 张牌进入时，行动玩家取得河流奖励区顶牌，河中所有牌面朝上进入弃牌区。
- 普通模式前三次奖励是 Rare；第四次拿到 `Game Over` 并立即触发失败。
- 一次宝石行动可能把河流从不足 5 张直接推到 5 张以上，仍只拿 1 份奖励并清空全部。
- 玩家可以查看弃牌区；官方建议只查起始牌或在查看前明确说出要找的某一张牌。可提供“严格模式”配置，使弃牌区背面朝上且不可查。

## 星星与能力

### Stage A 的 6 个星星来源

1. 复苏区第 1-3 位永恒族全部获得宝石；
2. 第 4-6 位永恒族全部获得宝石；
3. 第 9 个永恒族复苏；
4. 完成 `1/5/9` 宝石配方；
5. 完成下行第四圈；
6. 打出第三张 A 系能力牌。

获得任意 4 颗即胜。上述“第 1-3 位”和“第 4-6 位”按复苏区位置判断，不按具体角色或获得宝石顺序判断。

### 能力表

| 来源 | 能力 |
|---|---|
| A 系 | Stage A 中放入关卡区，第三张给星；其他关卡每张触发一次该关卡的星星奖励 |
| 幽灵 | 全员公开手牌并可自由讨论，持续到当前回合结束 |
| 骷髅 | 恢复 1 颗已消耗的心；没有已耗心则无事发生 |
| 女巫 | 免费生成任一尚存宝石，不能生成 `1/5/9` |
| 吸血鬼 | 牌组内没有能力牌 |
| 美杜莎 | 从弃牌区把一张 Rare 放回河流奖励区；Pro 可改选紫色牌 |
| 牛头人 | 与场地任一牌交换：被换出的顶牌加入使用者手牌，牛头人进入原格并视作 Rare；不能交换营地奖励牌 |
| 海怪 | 从河流拿最多 2 张牌加入手牌 |
| 木乃伊 | 从任意玩家牌库总共抽 3 张，每抽 1 张后可改选牌库；能抽则必须抽满 |

牛头人与骷髅叠牌交互：若骷髅上已有覆盖牌，只交换最上面的数字/Rare；底下骷髅留下，牛头人盖到它上面。

## 交流规则与联网实现

### 普通关卡可说与不可说

不能直接透露自己手中数字牌的：

- 具体数字或颜色；
- 没有某数字/颜色；
- 是否持有双色牌。

可以讨论：

- 手中的 Rare、能力牌或骷髅牌；
- 已公开的场地、河流、弃牌和牌库构成；
- 某位置自己“能不能放”、希望走哪条路线；
- 诅咒、能力、规则和整体策略。

电子版无法可靠判断自然语言是否泄露信息。实现策略：

- 在游戏内文字聊天框上方常驻简短规则提示；
- Stage E/E+ 由服务器关闭普通文字聊天，仅保留预设 `Rule question` 通道；
- 普通关卡不扫描或屏蔽玩家文字，不做可能误判的内容审查；
- 游戏日志与聊天分栏，日志不可由玩家伪造。

### 交流圆片

- 每位玩家有自己颜色的 2 个圆片；
- 任意时刻、任意次数，可移动到任意场地格、河流格或收回；
- 只能移动自己的圆片；圆片不保证该位置实际可打，只表达意图；
- 移动圆片是免费操作，不改变当前玩家或主行动状态。

服务端应接受带单调序号的 `move_disc`，最后写入胜出，避免多人拖拽竞态；日志只保留最近一次位置，不为每个拖动写长日志。

## 难度与练习模式

### 练习模式

- 不使用星星；复苏全部 9 个永恒族即胜。
- 上、中、下场地固定为山地、洞穴、营地。
- A、B 各随机使用 3 个永恒族并移除其能力牌。
- 下行是 Alpha、Gamma、Delta 三个傀儡；从 40 张随机牌中各发 8 张，并各带一颗宝石。
- 玩家不能执行普通“生成宝石”。复苏傀儡时，其宝石立即献给一个已复苏且无宝石的永恒族；若此时没有合法目标，宝石留在傀儡上，之后也不能补献。
- 给队友牌不消耗心。
- 没有第四圈，三圈后关闭行。

### A-E 的四档难度

- `beginner`：按各关卡基础设置。
- `standard`：通常把森林、湖泊、草原、河岸洗成下行 4 圈场地；Stage C 使用 9 张非专属场地（不含沼泽），中下行各 4，1 张移除。
- `expert`：从 10 张普通场地中排除山地和营地，取 8 张分给中下行各 4；Stage C 改为排除营地后从 9 张分配。
- `pro`：场地同 Expert；河流奖励改为紫色星星牌 `1/5/9`，使用随机牌堆时先移除其中 4 张 Rare。

规则书另有一张图形化“关卡 × 难度”永恒族行分配表。该表未录入前，配置界面只能开放已校验的组合，不能仅依据上述场地规则宣称支持完整难度。

## Stage B：Ghost Town

目标：复苏全部 4 个 B 系永恒族，逐个取得 4 把钥匙。

设置与规则：

- 上行叠放 4 张幽灵城镇场地，每圈一张；4 个 B 系永恒族全部在上行，每个压一把钥匙；不使用上行营地第四圈奖励。
- 星星奖励：从剩余紫色 `1-9` 奖励牌中任选一张加入手牌。
- 复苏第一个 B 系时，钥匙进入获得区，永恒族暂时放到 Stage B 卡而非普通复苏区。
- Stage B 卡上的 B 系诅咒持续生效，只能用专属配方“1 张数字 4”或“任意 2 张”以及专属宝石解除，不能用普通宝石格。
- 下一个 B 系复苏时，若旧角色有专属宝石，先把宝石退回专属格；旧角色移入普通复苏区且诅咒重新生效，需日后再用普通宝石解除；新角色和新钥匙进入 Stage B 卡。
- 第四个 B 系一复苏即满足胜利。

## Stage C：Labyrinth

目标：依次完成等级 1-4 的谜题，各取得一把钥匙。

设置与规则：

- 上行 4 圈固定使用迷宫场地，随机 3 个 C 系永恒族在上行。
- 星星奖励与 Stage B 相同：从剩余紫色 `1-9` 奖励牌中任选 1 张加入手牌。
- 每级有 4 张谜题牌。分别为两个谜题堆各随机抽一张 4→3→2→1 叠放，开始公开两张等级 1。
- 谜题必须保持正向，不能旋转或镜像。
- 玩家只能在“刚打出最后一张构成图案的牌”时宣告完成；系统应自动检测并高亮，无需玩家抢按按钮。
- 两个当前谜题只需完成一个；随后同级两张都弃掉，取得该级钥匙并翻开下一等级两张。
- 双色牌可为谜题另选任一颜色，不受其场地方向影响；Rare、牛头人和营地奖励可代表任意颜色。
- 同一步既完成谜题又触发复苏时，先完成谜题，再复苏。
- 裸露骷髅不算谜题图案，骷髅上被数字/Rare 覆盖后只看顶牌。

16 张谜题的具体颜色格阵必须从正版牌面录入：

```text
PuzzleDefinition:
  id: string
  level: 1..4
  cells: [{row_offset, column_offset, required_color}]
  orientation_locked: true
```

## Stage D：Gatekeeper

目标：对守门人完成四段伤害并取得 4 把钥匙。

### 设置与守门人回合

- 守门人 HP 指示从 20 开始，钥匙阈值为累计段内伤害 5、10、15、20。
- 上行 4 圈固定山地，随机 3 个 D 系永恒族在上行。
- 每套 D 系永恒族牌恰有 3 张骷髅牌。
- 守门人牌库底为专用 Game Over；其上是洗好的 8 张后半牌，再上是前半牌。3 人使用前半全部 8 张，2/4 人移除两张“仅 3 人”牌，只用 6 张。
- 起始玩家优先红，其次蓝，再次绿。
- 每位玩家各行动一次后，守门人翻 1 张牌。2 人局是两名玩家各行动两次后守门人才行动一次，可用牌横置状态记录第一轮已过。
- 守门人牌库耗尽后，下次翻出 Game Over，全队失败。

守门人翻到彩色骷髅时，依次尝试放到上→中→下行的最左空位；每行都不合法则弃掉。第二个圆片可显示它下一次优先尝试的格位。

能力牌：

- `generate_same_2` / `generate_same_3`：若对应宝石还在，自动生成并献给复苏区最左侧无宝石永恒族；若因此获星，下一位玩家取得白骷髅星星奖励。
- `shuffle_hands`：所有手牌背面交给起始玩家，混洗后从起始玩家开始顺时针逐张发完。
- `assess`：无效果，只在 3 人局前半牌中出现。

### 攻击守门人

- 用同色数字牌覆盖最左边待处理骷髅，对守门人造成等于数字的伤害。
- Rare、白骷髅、牛头人或营地奖励覆盖造成 0 伤害。
- 到达当前钥匙阈值时取得钥匙，HP 指示重置到 20，本次多余伤害全部忽略。
- 飞马连续放两张时，先完整结算第一张伤害及重置，再结算第二张。
- 获得星星时把一张白色骷髅奖励加入手牌；只有 4 张，用尽后星星不再给额外牌。

## Stage E：Silent

目标：每种玩家颜色完成任务，推动 4 把钥匙进入获得区。

### 设置

- 上行 4 圈固定山地，随机 3 个 E 系永恒族在上行。
- 每个 E 系永恒族从洗好的 40 张随机牌中随机取 8 张为专属牌库；余牌移出游戏。
- 每位玩家获得：自己颜色的起始任务 1 张、随机 `6/7/8/9` 任务 1 张、通用任务 1 张。
- 4 人局剩余任务移出；2/3 人局剩余通用任务形成补充牌库。
- 所有玩家的交流圆片开始锁在星星奖励卡上；起始玩家优先红、其次蓝、再次绿。
- 默认禁止策略性言语，只允许规则澄清。

### 星星效果

1. 第 1 颗：每人解锁两个交流圆片，仍不能讨论。
2. 第 2 颗：公开所有任务；2/3 人局之后每抽新通用任务也立即公开。
3. 第 3、4、5 颗：全员公开手牌并可自由讨论到当前回合结束。
4. A 系能力牌在此关也触发一次“公开手牌并讨论到回合结束”。

### 任务目录

| task_id | 完成条件 | 失效时机 |
|---|---|---|
| `starting_color` | 第 3 或第 4 颗星产生的瞬间，自己手里展示本色 1-5 任一张；双色可，Rare 不可 | 第 4 颗星结算后 |
| `play_6/7/8/9` | 自己在第 3 颗星前把指定数字打到场地；Rare 不可 | 第 3 颗星产生时 |
| `gain_star` ×2 | 自己获得一颗星，A 系能力产生的星星奖励不算 | 无 |
| `specific_jewel` ×2 | 自己生成同色 3、异色 3、同数字 3 中任意一种；女巫能力可算 | 无 |
| `jewel_late_eternal` | 给复苏区第 7-9 位之一宝石；石魔在该位置偷到宝石也算 | 无 |
| `same_color_column` | 自己打出最后一张，使三行同一列都有同色牌；Rare/牛头人/营地可替代 | 无 |
| `rare_in_hand` | 第 2 或第 4 颗星产生后自己手里有 Rare；刚获奖励 Rare 也算 | 只检查这两个瞬间 |
| `rare_after_rare` | 自己把 Rare 打到场地中另一张 Rare 的正右相邻位置 | 无 |

4 人局中，每名玩家完成任意 2 个自己的 3 个任务后取得本色钥匙，并弃掉剩余任务。

3 人局中，某玩家完成 2 个任务后保留最后一个并抽 1 张通用任务；之后再完成任务会推动未使用的第四颜色钥匙。第四钥匙取得后，已达标玩家的剩余任务弃掉。2 人局采用同一逻辑，但每完成一个任务、且通用牌库仍有牌时继续补任务。

### E 系一次性诅咒

E 系诅咒只在复苏瞬间执行一次，不持续留在复苏区：

- 雪人：每位玩家将自己牌库顶 1 张面朝上弃掉；空牌库不受影响。
- 河童：弃掉河流奖励区 1 张 Rare；Pro 改弃紫色奖励牌。
- 独眼巨人：场地牌按“从右到左、上行到下行”优先级弃掉 2 张；忽略刚触发其复苏、正要清空的那一行。
- 石魔：从复苏区最左侧有宝石的永恒族偷走宝石，令其诅咒重新生效；没有目标则无效果。

## Stage F：Dragon

Stage F 是综合关，四把钥匙来自四条彼此独立的路线：手牌宝石、河流目标、个人复苏、四颗实体星星。

### 关键设置

- 放 4 张 Stage F 关卡卡、4 把钥匙、7 颗宝石、1 颗龙蛋星、1 个守门人圆片。
- 8 张守门人后半牌正面摊在星星奖励区，作为可选奖励。
- 4 个钥匙奖励为：Key Bonus Rare、恢复心能力牌、营地奖励牌、河流 Rare，任意顺序摆放。
- 另按基础规则准备 4 颗星、3 颗心和上行营地奖励；加上龙蛋上的 1 颗星，本关共有 5 颗实体星可获得。
- 上行四圈山地；中行从指定 9 张普通场地随机 4 张；下行先放 4 张幽灵城镇场地，再在上面放另 4 张随机普通场地。
- A/B/C 各随机 3 个，每行各放其中 1 个，所以每行共 3 个永恒族。
- 下行第四圈奖励区从底到顶：洗好的 40 张随机牌、4 个 E 系永恒族、龙蛋、1 颗星。
- 每位玩家有个人复苏板和对应 D 系：红=飞马、蓝=巴隆、绿=灯神、黄=九尾。以该 D 系的 8 张牌作为起始牌库并抽 3，不使用普通 `1-5` 起始牌。
- 2 人局每人还控制一个额外颜色的个人复苏格与对应交流圆片。

### 四条钥匙路线

1. **手牌宝石**：完成关卡卡上全部 3 个专属手牌配方后取得钥匙；`1/5/9` 在本关不产星。准确三个图案需从正版关卡卡录入。
2. **河流**：河流有至少 5 张时，从中选 5 张完成四种配方之一：
   - 红 + 蓝 + 绿 + 黄 + 任意；
   - 红 + 蓝 + 绿 + 黄 + 紫；
   - Rare + 任意色骷髅 + 红 + 蓝 + 任意；
   - Rare + 任意色骷髅 + 绿 + 黄 + 任意。
   同时满足多个时只能选一个。除此之外，五张均为 5/7 时直接取得这一路钥匙；两张绿色 3 加三张 8 得星；Rare + 紫骷髅 + 两张紫 + 任意牌取得守门人圆片。
3. **个人复苏**：每位玩家整局一次，可把自己复苏的永恒族放进个人区并把本色圆片固定到关卡卡；该诅咒通常只影响本人，雪人仍影响全体。凑齐四色圆片得钥匙。3 人必须取得守门人圆片，把它立即当作缺色固定；2 人每人最多放两个个人复苏永恒族。
4. **星星**：取得并摆上 4 颗实体星即得钥匙；A 系能力只给星星奖励，不算这 4 颗实体星。

上述钥匙、星星和圆片图案独立于宝石配方检查；结算完可获得的目标后，仍按基础河流规则取得一次河流奖励并清河。

取得 Key Bonus Rare 后，它永久占河流最左位且清河时不弃；此后骷髅可进入河流。Key Bonus Rare 作为万能牌使用，各彩色骷髅也可作为自身颜色参与任意河流配方。

### 星星、龙与 E 系出现

- 每次星星奖励从正面守门人牌中任选 1 张加入手牌，可选“同数字三张宝石”或“洗混全体手牌后重发”等能力。
- 下行完成第四圈时龙复苏：先获得星和选择守门人牌，再把下行 7 张顶牌与所选守门人牌洗成龙牌库，放到复苏者玩家牌库底。
- 营地奖励牌不进入龙牌库；骷髅若已被覆盖，只收入顶牌并弃掉底下骷髅，所以龙牌库可能少于 8 张。
- 龙放到河流 `Game Over` 上方且永久保留，之后河流奖励耗尽也不会因 Game Over 失败。
- 随后洗 40 张随机牌，给 4 个 E 系永恒族各 8 张，余牌移除；它们出现在下行，并依次使用之前埋在下面的幽灵城镇场地。

### 钥匙奖励

每获一把钥匙，从剩余奖励中选一项；第四把钥匙的最后一项直接弃掉、不发动：

- Key Bonus Rare：永久进入河流并解锁骷髅进河；
- Heart Ability：加入手牌并立刻恢复全部心；
- Camp：立即把任一行当前场地改成营地；
- River Rare：放入河流奖励区，不直接进手。

四把钥匙全部取得即胜。

## 进阶关卡 A+-E+

所有 `+` 关卡使用对应关卡的 Beginner 推荐设置，除非该关卡另行修改。

- **A+ Advance**：仍需 4 星，但移除两个“复苏区分段献宝石”星；河流不放 Rare，弃牌区预放 1 张 River Rare，另外 2 张移出；设置必须包含美杜莎。
- **B+ Backup**：仍需复苏四个 B 系；加入 Stage D 守门人回合和完整牌库，但无法攻击守门人；节庆改为每次打牌行动必须正好打 2 张。若回合开始时手中只有 0/1 张而无法打两张，按规则立即失败；使用能力、生成宝石或消耗心的给牌都不能凑作这两张。
- **C+ Combination**：每级两个谜题都必须同时在场地中按从左到右方向出现，允许中间有空列；同一张牌可参与两个图案。Rare、牛头人、营地奖励不能代色。
- **D+ Destiny**：四段钥匙阈值变为 10、5、0、0；当前钥匙颜色指定必须由哪位颜色玩家完成最后伤害。错误玩家的伤害最多停在阈值前 1。正确玩家超额时，除最后一把外按超额数弃守门人牌库顶牌；最后一把必须精确伤害，超额同样停在前 1。每把钥匙后掷 d4，依次对应雪人、独眼巨人、河童、石魔式攻击；石魔式宝石直接移出游戏。
- **E+ Engagement**：每人的一个圆片锁在正面朝上的起始任务上，另一个起初锁在星星卡；第 1 星解锁唯一可用圆片，第 2、3 星改为最多恢复 3 颗心，第 4 星才公开手牌。E 系牌库移除 4 张 Rare，并移除“给第 7-9 位永恒族宝石”和“手中有 Rare”两种通用任务。除起始任务外，任务必须由该玩家顺序前一位完成；起始任务本身不推动钥匙。若配置中出现 A 系，其能力改为恢复 1 颗心。先让四把钥匙全部到位，再取得第 4 星并让所有人展示本色 1-5，顺序错误或有人无法展示都立即失败。

## 单人模式

### 基础单人

- 玩家同时控制三个傀儡，按 3 人设置并使用 3 人宝石卡，所有手牌公开。
- 选一个主傀儡，手牌/补牌上限 3；两个副傀儡上限 2；主傀儡先手。
- 每个傀儡有 2 个圆片。圆片不再通信，而是任意时机一次性移出游戏并从该傀儡牌库抽 1 张；每关每个傀儡最多 2 次，不能借用他人圆片。
- “公开手牌”图标改为每个傀儡各从自己牌库抽 1 张。
- Stage E 的“公开任务”图标改为：翻开通用任务牌库并任选一张；所有傀儡任务开局即公开。

### 故事单人

- 连续游玩 A-E；除通常通关条件外，每关还必须生成 3 人宝石卡上的全部 6 颗宝石并献给 6 个永恒族。
- 固定 Alpha=红、Beta=绿、Gamma=黄，三者手牌上限均为 3，Alpha 先手。
- 女巫不出现，其能力牌从 Stage B 起作为“爱猫”特殊牌使用。
- 每个傀儡的圆片有独立升级树，例如抽更多牌、无视诅咒出牌、从河流取牌、把手牌背面当 Rare 等。升级点来自每关星星，前置关系必须按正版记录纸数据化。
- 每个傀儡每关还可执行一次第四主行动“存牌”：把 1 张数字牌或 Rare 压在自己的傀儡牌下。三名傀儡历关所存数字必须各自保持同数，Rare 可代；存牌会永久离开后续永恒族牌组。
- 每张存牌基础 2 分；Stage C 存 Rare 共 5 分，Stage D 存 Rare 共 4 分；每个傀儡存牌部分最多 15 分，三者最多 45 分。Stage A/B 存牌还能从三项专长中最多解锁两项；Stage E 存牌会生成额外傀儡宝石。
- 每关基础评分最多 8：星星最多 4、未用心最多 2、手牌/河流中未用 Rare 最多 2；第一次失败 -1，第二次失败该关记 0 后继续故事。
- 通关 E 后，未消费星星升级点最多再计 15 分。总分上限为基础关卡 40 + 未消费星点 15 + 三傀儡存牌 45 = 100；升级树的完整格位与连线需从正版记录纸录入。

故事关卡修正：

- Stage B：女巫牌组只留下能力牌作为爱猫，和一把钥匙一起放在上行；先复苏另外三个 B 系才取得爱猫与钥匙。四钥匙已齐但六宝石未齐时，爱猫移到 Stage B 卡且没有能力/诅咒。
- Stage C-E：爱猫三关合计只能使用一次；每关开始把 Stage B 专属宝石放在爱猫上，任一傀儡可用“生成宝石”行动把它献给永恒族，使用后爱猫移出。
- Stage C Expert：原推荐布局中的 E 系改放 B 系。
- Stage D：四钥匙齐但六宝石未齐时，守门人停止行动，玩家继续完成宝石目标。
- Stage E：不使用起始任务，每个傀儡准备 2 个任务；除四钥匙外还要让 9 个永恒族都获得宝石。来源是 6 个普通配方、最多 3 个存牌傀儡宝石和爱猫宝石；若三颗傀儡宝石与爱猫宝石都已献出，可把最后一个普通配方宝石献给爱猫以避免没有永恒族目标。

## Creative Mode

Creative Mode 不改变默认关卡，而是在其上增加长期成就、团队挑战称号和个人规则修正。它适合作为最后阶段的账号进度功能，不应阻塞主游戏。

- 记录维度包括：游玩人数、已取得的 A-E 牌库、用过的宝石配方、单关复苏牌库数、单关最大手牌数，以及 A-F 各难度/进阶通关情况。
- 团队挑战示例：同一玩家取得全部星/钥匙、Stage A 继续取得第 5/6 星、Stage B 不用 Rare 复苏四个幽灵城镇永恒族、Stage C 全程禁言、Stage D 四次精确伤害、Stage E 完全不用言语/手势/圆片。
- 个人正面修正包括：随机牌作起始牌库、能力牌背面当 Rare、手牌补到 4、红牌生成宝石时自定颜色/数字、特定蓝牌背面当 Rare、特定绿牌免费给人、黄牌无视诅咒。
- 个人限制包括：不能参与策略讨论、不能打 Rare 到场地、能力无效、不能花心、手牌只补到 2、只能靠圆片交流。
- 自定义关卡允许组合关卡、永恒族、场地与称号。联网房间必须把所有修正显示为可读选项并写进 `config`，不能让房主输入 JSON；非官方组合应标为 `Custom`，不计标准通关。

建议把成就判断做成只读事件订阅器。它可以观察 `RuleEvent` 并授予记录，但不能修改正在结算的规则状态。

## 事件结算顺序

建议所有关卡共享事件队列，并明确如下优先级：

1. 放牌进入目标位置，记录朝向；
2. 结算覆盖骷髅与伤害；
3. 检测刚刚形成的 Stage C 谜题或 Stage E 任务；
4. 一次多牌行动全部放完后，按打出顺序处理各行复苏/第四圈；
5. 处理复苏选择、一次性诅咒、专属牌库归属和场地牌更新；
6. 处理宝石、星星、钥匙、河流奖励及对应奖励选择；
7. 重复处理新事件，直到队列为空；
8. 检查胜利；若未胜，再检查本次结算产生的 Game Over 等即时失败；
9. 补牌并结束回合；必要时插入守门人回合；切换到下一位玩家后，才检查其是否完全无主行动可做。

每个事件写成纯函数或小型 handler，并留下结构化日志。动画只消费 `PublicEvent[]`，不得反过来控制服务器结算。

## 隐藏信息与序列化

发给当前查看者的状态必须裁剪：

- 自己手牌：完整 `CardDefinition`；
- 他人手牌：通常只给张数，不因 Rare、能力牌或骷髅“允许口头提及”就自动公开真实 ID；
- 玩家牌库：只给张数，不给顺序；
- 沉睡永恒族的角色和其公开牌组构成可见，但洗牌顺序不可见；
- Stage D 守门人牌库只给剩余数与半组阶段；
- Stage E 未解锁任务对非持有者隐藏，第二颗星后按规则公开；
- 幽灵/星星临时公开手牌时，服务端设置 `hands_revealed_until_turn_end=true`，所有客户端重序列化；回合结束立即关闭；
- 游戏结束可以公开最终牌库供复盘，但仍不应发送未来随机种子推导信息。

建议实现：

```text
serialize_state(state, viewer_id):
  public = build_public_snapshot(state)
  public.players[viewer_id].hand = full_cards(...)
  for other in players:
    public.players[other].hand = redact_or_reveal(...)
  return public
```

### 交互

- 点手牌后，只高亮服务器判定的合法目标；非法格仍可在 Explain 模式查看原因。
- 再点同一张牌或桌面空白取消选择，不提供额外 `Clear Selection`。
- 点击宝石配方进入多选模式，实时显示 `2/3 selected` 与颜色/数字匹配状态；不要求输入 JSON。
- 多个永恒族可选时用不遮挡桌面的底部 sheet；Esc 退出尚未提交的选择。
- 交流圆片支持拖拽，也提供“点圆片→点格位”的无障碍方式。
- 长日志必须可滚动；复苏、关卡阶段变更和最终结算应暂停动画队列，所有玩家点 `Continue` 后再进入下一展示段，符合仓库的阶段结算可查看要求。
- Stage E 禁言不能只隐藏聊天框；服务端也要拒绝普通聊天事件，并在顶部显示 `Silent rule active`。

### Help 与 Explain

- Help：显示当前关卡规则、场地规则、活跃诅咒、胜负条件、交流限制和卡牌词典。
- Explain：进入后有说明的按钮显示虚线高亮和问号光标；无说明按钮不触发原动作；disabled 按钮仍可通过坐标命中查看“为何不可用”；点击一次说明或按 Esc 退出。
- 对每个不可打格，Explain 应展示服务器 reason code 的本地化文本，例如“洞穴必须递减”“女巫诅咒禁止 Rare”“需先覆盖本行最左骷髅”。

## 测试与验收用例

### 初始化与牌流

1. Stage A 4 人开局各有 3 张手牌、玩家牌库各余 2 张，总计各 5 张起始牌且不重复。
2. 2 人副色牌随机移除 3、牌库底加入 2，两个玩家实例互不共享。
3. 相同 seed、玩家顺序与配置产生完全相同的牌库和布局。
4. 复苏者得到正确 8 张牌且顺序不可被其他客户端看到。
5. 手牌超过上限时不抽不弃；牌库不足时只抽剩余牌。

### 场地求解

6. 普通同色、同数字相邻被拒绝，并返回准确 reason code。
7. 双色牌翻转后左右邻颜色判断不同，放下后不能更改。
8. Rare 当前落位绕过山地/洞穴/公共规则，后续牌仍能把它解释为合适数字。
9. 山地 9 和洞穴 1 后可继续放多张 Rare。
10. 湖泊/沼泽第一张为双色或紫色时保留多个合法颜色相位。
11. 迷宫的奇数、偶数长度镜像都正确，未完成前缀不会被过早拒绝。
12. 巴隆只放宽同色，九尾只放宽同数字，不误放宽场地限制。

### 复苏、资源与胜负

13. 三圈所需长度为 4、5、6；第四圈为 7，之后行关闭。
14. 复苏后诅咒立即生效；献宝石关闭；石魔偷宝石后恢复。
15. 第 1-3 / 4-6 位献宝石星只各触发一次。
16. `1/5/9` 宝石把牌送入河流并同时得星；河流越过 5 只触发一次奖励。
17. 第四次河流奖励拿到 Game Over 会失败。
18. 同一行动同时取得第四星和 Game Over 时判胜。
19. 当前玩家三类主行动都无合法选项时失败，其他玩家能行动不影响此判断。
20. 给牌消耗心，中行第四圈恢复全部心，接收者超手牌上限不弃牌。

### 关卡

21. Stage B 新 B 替换旧 B 时，专属宝石归位，旧 B 进入复苏区并恢复诅咒。
22. Stage C 只在最后一张落下的瞬间完成谜题，且谜题先于同格触发的复苏。
23. Stage D 守门人骷髅严格按上中下优先放置；2 人计数两轮后才行动。
24. 多个骷髅必须从左向右覆盖，覆盖牌颜色正确，Rare 伤害为 0。
25. 守门人跨钥匙阈值时忽略溢出并重置 HP。
26. Stage E 的任务在正确事件窗口完成，过期任务不会晚触发。
27. Stage E 第二颗星前他人看不到任务，临时公开手牌在回合末重新隐藏。
28. Stage F Key Bonus Rare 清河后仍在，并且取得后才允许骷髅入河。
29. Stage F 龙牌库正确排除营地和被覆盖骷髅，龙永久盖住 Game Over。
30. A+-E+ 的阈值、前序玩家任务与星星顺序分别有独立回归测试。

### 联网与安全

31. 非当前玩家不能提交主行动，但任意玩家可移动自己的交流圆片。
32. 玩家不能用伪造 `card_id` 操作别人手牌或发送自己看不到的目标。
33. 重复 action id 不会重复扣牌、得星或复苏。
34. 重连后看到与自己权限一致的手牌/任务，不泄露牌库顺序。
35. Stage E 服务端拒绝普通聊天事件，规则澄清通道仍可用。

## 开发前必须完成的数据验收

规则引擎可以先写，但要把对应模式标成可选之前，必须满足：

1. 牌表由两人对第四版实体或授权清单逐张核对；
2. 每套永恒族牌恰好 8 张，A-D 总计 128 张，随机牌恰好 40 张；
3. 16 张谜题均有等级、固定朝向和格阵测试；
4. 守门人前/后半牌数量及 3 人专用标记测试通过；
5. 各关卡 × 难度布局与规则书设置图逐格一致；
6. 所有素材来源和许可记录在 `static/assets/eternal_decks/README.md`；
7. Help 文本明确显示当前采用的规则版号与未实现扩展。

这样可以先交付一个规则正确、可测试的 Stage A，再逐关扩展，而不会因为缺少图形化组件数据而把猜测固化进公共规则引擎。
