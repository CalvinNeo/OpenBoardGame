# Task 105 — 灵迹岛 / Spirit Island

## 目标与范围

在现有 FastAPI / Socket.IO 房间系统新增 `spirit_island`，支持 1–4 人合作、真人与机器人混合、断线重连和保存恢复。先完成官方入门玩法的完整对局：四位低复杂度精灵、对应独特能力与固定 Power Progression 成长路线、标准版图、基础恐惧牌、入侵牌，以及合作胜负判定。

四位精灵为 Lightning's Swift Strike、River Surges in Sunlight、Vital Strength of the Earth、Shadows Flicker Like Flame。开局由玩家选择不同精灵。前七次通常获得力量使用固定进阶，用尽后从完整基础公共牌库抽四留一；Gift of Power 和 Entwined Power 按其规则直接抽牌。包含 16 张专属力量、36 张次级力量、22 张高级力量及 15 张恐惧牌。此版本不提供另外四位基础精灵、从开局即随机成长的模式、对手、情景、荒芜卡、主题地图或扩展；主界面标明 INTRODUCTORY GAME，Help 详细列出范围，不以自创卡牌代替实体组件。

规则以[发行商游戏页与所链接规则书](https://shop.greaterthangames.com/products/spirit-island)、[官方规则 FAQ](https://querki.net/u/darker/spirit-island-faq/)及[荒芜池勘误](https://querki.net/raw/darker/spirit-island-faq/one-more-blight-errata)为依据。组件机制从发行商链接的 [Spirit Island Wiki](https://spiritislandwiki.com/)交叉核对，转录数值及原创简短中文摘要，记录到 `designs/spirit_island_sources.md`。不加载商业卡图、版图、Logo 或 UI 素材。

## 规则模型与流程

- 每人一块八区域版图；按官方规则书图例固定为单人 A、双人 A/C、三人 B/C/D、四人 A/B/C/D。地形包括山地(⛰️)、湿地(💧)、丛林(🌿)、沙地(🏜️)，海岸(🌊)为额外属性。邻接图同时服务于探索、射程、聚集／推动和荒芜连锁，跨板块连接必须在前端可查。
- 开局设置探索者(🚶)、城镇(🏠)、城市(🏰)、达汉(🛖)、荒芜(🟤)与存在(🔮)。无荒芜卡的可用荒芜池按最新勘误为 `5 × 人数 + 1`；版图原有荒芜从供应取，不扣池。
- 入侵牌分三阶段，依规则移除牌后分层洗牌；开局执行探索并移至建造。阶段二没有对手时不执行升级效果，阶段三同时涉及两种地形。公共状态只给已揭示牌和剩余数量。
- 精灵阶段：选择成长，按轨道放置存在、获得能力、回收牌或能量，再获得本轮能量并选择支付出牌；元素来自本轮已打出的牌和已开启轨道，不因使用能力消耗。
- 快能力阶段：玩家可自行决定合作行动顺序。逐张选择能力与合法目标；适用时选择伤害分配、推动／聚集、重复和目标精灵。天赋依元素门槛启动，特殊规则独立实现。
- 入侵者阶段：依次处理已获得恐惧牌、蹂躏、建造、探索并推进牌列。城镇／城市摧毁产生 1／2 恐惧；移除和推动不产生摧毁恐惧。每累计 `4 × 人数` 恐惧获得一张恐惧牌，跨越分隔线立即提高恐惧等级。
- 恐惧结算中再赚取的恐惧牌加入本次结算末尾；全岛持续恐惧效果按行动时的棋子状态判断。玩家可选择多个蹂躏土地的处理顺序；每个动作先完成其触发效果，再检查胜负，重复力量是后续独立动作。
- 蹂躏对土地和达汉分别造成入侵者伤害，防御同时保护二者；土地伤害达到 2 才增加一枚荒芜。达汉每个 2 生命，存活者每个反击 2 伤害。新加荒芜摧毁该地每位精灵各一存在；已有荒芜时额外向相邻土地连锁，合法分支由玩家选择。
- 建造只发生在有入侵者的匹配土地，城镇数多于城市数则建城市，否则建城镇；探索需海洋／本地或相邻建筑作为来源，探索者本身不提供来源。
- 慢能力阶段完成后时间流逝：已出能力进入弃牌，临时防御／伤害等重置。进入 `round_end` 保留本轮结果、牌列变化与日志，所有玩家分别点击 `Next Round` 才进入下一轮。机器人只确认自己的席位。
- 恐惧等级 I 要清除全部入侵者，II 要清除城镇与城市，III 只需清除城市；恐惧牌全部获得即恐惧胜利。荒芜池耗尽、任一精灵失去全部存在、需要探索却没有入侵牌时失败。胜负及时结算，不设置任意回合上限。

## 服务端与动作协议

新增 `game/spirit_island.py`、`game/spirit_island_data.py` 和独立扩展效果模块 `game/spirit_island_extra.py`，沿用 `init_game`、`get_legal_actions`、`apply_action`、`get_public_view`、`bot_move`、`serialize`、`deserialize`。所有动作服务端验证阶段、执行者、资源、距离和实际选项；拒绝动作不修改状态。使用多步待决选择避免要求客户端构造复杂组合或 JSON。

公共视图输出独立复制的版图、玩家、已知牌列、精灵及能力定义、阶段、待决选择和 `action_options`。每个选项附完整动作、显示文案和可选土地／卡牌 ID，前端以地图及卡牌选择提交；未来牌序和 seed 不外泄。合作手牌公开，方便团队协作。机器人只根据同一公开视图选择合法动作，支持所有等待阶段和回顾确认。

注册导出、游戏名称、合作／策略标签、开发顺序及页面脚本接入现有结构。`app.js` 仅加面板切换和渲染分发，主要交互全部放入 `static/games/spirit_island.js` 的私有 IIFE。房间配置广播隐藏 seed。

## 前端要求

遵守 [FRONTEND.md](../FRONTEND.md) 与 [task40.md](task40.md)。采用原创海蓝、林绿、暖沙色的岛屿桌面，每个土地清楚显示编号、地形与棋子数量；颜色之外同时显示文字／Emoji。桌面地图与当前操作并列，手机按可读尺寸重排，无横向页面滚动、文本溢出、遮挡或极小字号。对与视觉位置不一致的图邻接必须明确列出，不让地图误导射程。

- 顶部提供轮次、阶段、恐惧进度／等级、荒芜池和三格入侵牌列；主界面只给简短操作提示，大段规则全部放 Help。
- 精灵选择、成长、存在轨道、能力卡、目标和可选分支均用可见控件完成。选择后显示合法目标；空白或 Esc 取消本地选择，不放 Clear Selection 按钮。非游戏内容 UI 用英文。
- Help 覆盖规则、胜负、符号、模式范围和轮间暂停。Explain 用捕获阶段阻止普通按钮执行，仅有解释的控件加虚线和问号；禁用按钮也能按坐标命中说明，解释一次自动退出，Esc 也退出。对话框支持 Close、Esc 与遮罩关闭。
- 资源、地形、状态和元素提供名称＋图标说明，例如能量(⚡)、恐惧(😱)、火(🔥)。桌面悬停和键盘聚焦显示，手机点击浮动说明三秒，连续点击更新为最新说明。说明操作不会提交游戏动作。
- 地图如需平移，限制手势在地图内并使用 pointer capture，拖动结束不误触。日志／回顾限制高度并在容器内滚动，长玩家名和大量棋子能换行。
