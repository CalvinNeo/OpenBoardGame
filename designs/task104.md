# Task 104 — 世界巡游（澳洲） / Boomerang: Australia

## 目标与依据

在现有房间中新增 `boomerang_australia`，支持 2–4 个席位、真人与机器人混合、四轮完整对局、断线重连及保存恢复。先完成本方案，再直接实现。采用澳洲版，不混入 2018 年旧版、欧洲版、美国版或中国版的规则。

规则来源：[Grail Games 官方页面](https://www.grailgames.games/our-games/boomerang-australia)、[官方规则书入口](https://www.grailgames.games/s/Boomerang_Rules_12pp_WEBVIEW.pdf)、[同版规则书镜像](https://cdn.1j1ju.com/medias/f9/c5/91-boomerang-australia-rulebook.pdf)、[官方计分纸入口](https://www.grailgames.games/s/score-card.jpg)。BGA 的帮助页只用于交叉检查；其中活动的两个图标得分存在前后矛盾，实施时以计分纸核实，不能直接抄错。

前端严格遵守 [FRONTEND.md](../FRONTEND.md) 和 [task40.md](task40.md)。地图、卡片和标记采用原创 CSS / SVG / Emoji，不复制商业卡面、地图扫描件或商业 UI 素材。28 张卡的地点、地区、数字和图标必须逐张有出处；核实过程记录到独立数据来源文档，不用随机生成的牌表冒充原版。

## 规则与计分

- 一局四轮；每轮各发七张。第一张是秘密投掷牌 Throw，自己始终可看；其他玩家到本轮结束才能看到。其余牌每次向左传，各人同时选一张公开；最后剩下的一张传给下家后自动成为 Catch，不增加无意义的确认步骤。每人最终七张都参与计分。
- 每次选牌先秘密锁定，全部席位提交后原子揭示并传牌，避免响应快慢带来信息优势。只公开是否提交，不提前公开选了哪张。
- 四人局每轮重洗全部 28 张。二／三人局下一轮将上轮未发的牌保留在顶部，将上轮使用的牌洗好放在其下，保证此前未发的牌进入下一轮；不能每轮简单重洗全部牌。
- 默认全程向左。可配置官方方向变体：三／四人局第 2、4 轮向右，其余向左；两人方向相同，不改变规则。
- Throw & Catch：两张数字的绝对差；数字相同时为零。
- 景点：全局累计不同地点，每个只计 1 分。七个地区各四个地点；首次在同一轮完成某地区的所有玩家各得 3 分，之后不再颁发。必须按全员本轮结果统一判断，不能由提交先后决定奖励。
- 收藏品：叶子(🍃) 1、野花(🌼) 2、贝壳(🐚) 3、纪念品(🎁) 5。每轮求和，1–7 翻倍，8 以上原值，0 为 0。
- 动物：袋鼠(🦘) 3、鸸鹋(🐦) 4、袋熊(🐾) 5、考拉(🐨) 7、鸭嘴兽(🦆) 9。每轮同类每两只计一次对应分值；落单不计，四只计两对。Emoji 只是原创识别符，配名称说明，不宣称图标是物种精确写实。
- 活动：游泳(🏊)、徒步(🥾)、原住民文化(🪃)、观光(📷)。每轮可以选择一种本局尚未计分的活动，也可以 Skip。每种活动整局最多记录一次；选零分仍占用该种活动。已核实官方计分纸：1／2／3／4／5／6 个图标依次得到 0／2／4／7／10／15 分；无图标记为 0。分值落入单一常量。
- 总分为四轮 Throw & Catch、收藏品、动物、活动，加累计不同景点及地区奖励；避免每轮重复加入累计景点。最高分获胜，同分比较四轮 Throw & Catch 总分，再相同并列。

## 状态、协议与信息边界

引擎实现标准 `init_game`、`get_legal_actions`、`apply_action`、`get_public_view`、`bot_move`、`serialize`、`deserialize`。

状态机：`draft` → `choose_activity` → `round_end` → 下一轮 `draft`；第四轮仍保留 `round_end`，全员确认后进入持续展示的 `game_over`。轮内五次公开选牌加最初秘密选牌共六个提交批次，末张自动接收。活动选择完成前不得开始下一轮。

动作均带 `round`；选牌另带 `pick`，由服务端校验身份、阶段、轮次、手牌归属、是否已提交及活动是否已用。动作建议为 `draft_card(card_id, round, pick)`、`choose_activity(activity|null, round)`、`next_round(round)`。严格 Schema 拒绝未知字段／类型；非法请求不修改原状态，重复回顾确认幂等，旧轮次请求不能误操作新牌。前端只用点选与按钮，不要求用户输入 JSON。

每轮结算展示完整七张牌、每项增分、地区共同获奖者、活动选择及等待名单；所有真人分别点击 `Next Round` 才继续。机器人只代自己确认；断线不自动确认，不以倒计时跳过回顾。最后一轮按钮仍保留回顾确认语义，之后展示胜者和完整计分纸。

内部保存：稳定玩家顺序、当前轮／批次、各手牌、已选牌、待提交选择、未发牌、服务端随机状态、累计景点、地区归属、已用活动、逐轮分数、回顾确认和胜者。恢复不重洗、不漏掉已提交选择。

公共视图使用白名单：所有人可看公开牌、过去计分、进度和已提交状态；仅本人可看当前手牌、秘密 Throw、自己的尚未公开选择和合法操作。旁观／未知身份无私人数据和可执行动作。未发牌、随机状态、其他人的手牌与未揭示 Throw 不出现在视图、事件、DOM、日志或机器人动作广播；房间配置也过滤测试 seed。所有缓存／数据随视图深拷贝隔离。

机器人先获取与真人相同的玩家视图，决策函数不接触他人秘密牌或牌库。选牌综合新地点／地区接近程度、收藏翻倍临界值、动物配对、尚未使用活动、Throw 与可推测 Catch 的差值；允许利用公开牌，但不读取真实未来发牌。所有阶段都有合法终止动作。

## 前端方案

- 新建 `static/games/boomerang_australia.js`（IIFE）和独立 `static/boomerang_australia.css`；只导出 `BoomerangAustralia` 专属前缀接口。`static/app.js` 仅做显示和渲染注册。
- 以米白旅行手册、海蓝和桉树绿为主色，橙色强调投掷数字。主区为可点选的手牌与本轮已获牌；相邻区域是七地区旅游记录和当前计分预览，顶部紧凑显示玩家、轮次、传牌方向与提交状态。地区记录用原创示意布局，地点字母、名称和已访问勾选同时呈现，不用纯颜色承载状态。
- 手牌同时清楚显示投掷数字、地点／地区、收藏品绿色圆标、动物金色标和活动蓝色标。点选显示高亮；`Confirm` 提交。点击周围空白或 Esc 取消本地选择，不添加 Clear Selection。提交后锁定并显示 Waiting，保留当前手牌供查看。
- 活动阶段显示四类活动本轮数量、预期分数和已用状态，点选再 Confirm 或 Skip；不可重复使用的活动仍可解释。结算详情直接位于主区，避免自动消失的弹窗。
- 桌面卡牌区与计分区相邻；手机改紧凑单列／双列卡片，320、375、768、1440px 均无横向滚动、内容溢出和面板重叠。长地名／玩家名正常断行。日志和历史有最大高度并在内部滚动。按钮成行、输入标签同行、合理留白。
- 所有通用 UI 用英文，包括 Help、Explain、Confirm、Cancel、Skip、Next Round、Close、Waiting。游戏规则和地点可中英并列。主画面只保留短指示，长规则进入 Help。
- Help 包含所有计分、地区并列、低人数发牌、信息边界与全员回顾约定；名称和图标一起列出。Explain 采用捕获阶段阻断操作；只有能解释的控件有虚线和问号，没说明的按钮不执行原功能，disabled 控件用坐标命中仍能解释；解释一次自动退出，Esc 可退出，Help/Explain/关闭按钮保留功能。
- 数字徽标、字母、图标及缩写都有即时短说明：桌面 hover／focus；手机点击显示三秒浮动提示，再点显示最新说明。独立说明入口不得提交选牌。提示保持在视口内，切换游戏／关闭弹窗清理计时器和浮层。布局不需要拖拽地图；如果后续加入平移，地图内部必须 `touch-action: none`、捕获指针并正确处理取消和防误点。
