# Task 115：诈赌巫师 / Cheaty Mages!

## 实现范围与规则依据

新增 `cheaty_mages`，支持 3–6 人、机器人、断线重连及三轮完整对局。采用经典版 72 张咒语、10 张斗士、8 张裁判，依据[经典规则译本与完整卡表](https://www.ludism.fr/regles_files/fr/upload/cheaty_mages_french_rules.pdf)、[中文版组件与规则整理](https://mj9981168.pixnet.net/blog/posts/8226871246)交叉核对。AEG 2013 修订版的全员退场处理与经典版不同，本实现使用经典版加赛规则，详见 [版本与规则裁定](cheaty_mages_sources.md)。

- 每人持 2 金币(💰)，3–4／5／6 人分别起手 8／6／5 张。每轮五名斗士(👹)和一位裁判(⚖️)，秘密选择 1–3 个不同号码押注，无需支付押金。命中时一注获双倍赏金、两注原额、三注一半向上取整。
- 从起始玩家顺时针行动：施放一张咒语、弃一张手牌窥探某斗士全部暗牌，或永久 Pass。直接(☀️)法术公开，赋予(🌙)暗置，支援(✨)按效果处理；禁咒(🚫)受当前裁判限制。机器人只用自己的公开视图决策。
- 所有人放弃或用完手牌后翻开暗牌，先判罚再比强度(⚔️)。总魔力(🔮)超过上限才触发解除或退场；平手比较斗士印刷强度。处理反转强度、改变赏金、特殊裁判及全部退场的取消比赛。
- 每轮保留完整结果、所有押注与判罚，所有席位点击 **Next Round** 后才离开。保留手牌并按所选版本补牌；斗士重新洗牌、裁判更换、金币最多者先手。三轮有效比赛后金币最高者胜，同币比较剩余手牌，再同则并列。
- 全部 36 种咒语实现其对应效果，包括窥探、驱散、抽牌、遗忘、换注、换裁判、忽略裁判、隐身、棱镜、变形、转移、反魔法、反射。实际卡牌数据独立存放，不借用商用图片或 UI 素材。
- 默认启用经典可选规则 Foul Play：最后一轮可为每张禁牌支付 2 金币(💰)，通过带费用的施法选项明确确认。棱镜只提供直接法术暗置选择，不改变其类别；隐身才豁免禁牌类别。

## 后端与信息边界

新增 `game/cheaty_mages.py` 和 `game/cheaty_mages_data.py`。实现标准 `init_game / get_legal_actions / apply_action / get_public_view / bot_move / serialize / deserialize` 接口，配置默认为基础规则。阶段为 `betting → casting → round_end → betting / game_over`；需要指定玩家弃牌时暂入 `discarding`，补牌超上限时使用 `refill`。

- 内部保存玩家手牌、秘密押注、窥探知识、咒语牌库／弃牌、裁判牌库、斗士、法术实例及附件、轮数／行动序号、确认名单、公开日志与结算快照。每张牌有稳定独立 ID。
- 公共视图固定字段：`game_id, you, config, phase, round, turn, total_rounds, current_turn, start_player, game_over, winner, next_ready, legal_actions, legal_moves, players, fighters, judge, effects, your_hand, your_bets, discard, round_summary, final_results, log, deck_count`。`players` 包含 ID、姓名、座位、机器人标记、金币、手牌数、公开押注张数、已押注／已放弃状态，未揭示的他人押注号码为 null。`fighters` 包含 `slot`(1–5)、斗士属性、`spells`、已知强度与魔力。暗法术只下发匿名槽位、施放者和公开附件，施放者或已窥探者才见牌面；轮末全部揭示。未揭示暗牌不参与公共精确总数。旁观者无手牌、押注或窥探内容。
- `legal_moves` 给本人可提交的完整合法动作，客户端用卡牌与目标控件选择，绝不让用户输入 JSON。动作至少含 `type, round, turn`（轮末确认只要求 `round`），施法含 `card_id` 及相应斗士／法术／玩家目标。秘密押注包含 `slots`；窥探包含 `card_id, target`；弃牌包含 `cards`。服务端先验证全部字段、权限、目标与时序，再修改状态；拒绝重复提交与旧轮请求。
- 公共事件和机器人行动日志隐藏押注、暗牌身份与私人选择。活动对局加入现有存档下载／克隆保护。公开视图与序列化使用深拷贝。
- 在 `game/__init__.py`、`game/definitions.py`、`game/tags.py` 注册；运行 `python3 scripts/gen_dev_order.py` 更新开发顺序。不改动工作区已有的其他游戏修改。

## 前端方案（遵守 FRONTEND.md 与 task40.md）

新增 `static/games/cheaty_mages.js`、`static/games/cheaty_mages.html`、`static/cheaty_mages.css`。游戏逻辑封装 IIFE，只导出 `renderCheatyMagesGameState` 和 `showCheatyMagesHeaderActions`。`static/index.html` 仅添加空 `cheatyMagesPanel` 及头部占位，在 `GAME_ASSETS` 注册脚本／样式／模板，更新相关版本号。

- 紫蓝竞技场配金色押注，使用原创 CSS 卡牌和 Emoji；桌面斗士紧凑排列、行动区紧邻手牌；窄屏改为自适应网格。320px／390px／桌面均无横向滚动、文字溢出或互相覆盖；日志有独立滚动高度。
- 点斗士选择押注，最多三注并显示倍率。施法时点手牌再选合法目标，必要时选择组合牌／目标法术／对手，清楚显示可见与隐藏信息；不依赖颜色单独表达状态。空白点击或 Esc 清除未提交选择，不添加 Clear Selection。
- 通用 UI 使用英文（Help、Explain、Cast、Pass、Confirm Bet、Next Round 等）。非交互图标同时提供桌面悬停／键盘焦点提示与手机点击 3 秒浮动提示，连续点击替换；规则和解释同时写出名称与 Emoji。
- **Help** 模态框集中完整规则与特殊牌参考；主面板只留必要状态。**Explain** 按 task40 捕获交互，只有有解释元素虚线高亮；无解释按钮也拦截原动作，disabled 按钮可通过 pointerdown 坐标识别，解释后或 Esc 退出。弹窗支持 Esc／背景关闭并归还焦点。不逐区放 i 图标。
- 轮末展示斗士强度、魔力、判罚、赢家、公开押注和每人收入；显示全员确认进度，机器人只确认自己。最终轮也保留结算供查看。
- 初始化兼容按需加载发生在 DOMContentLoaded 之后；注册监听后同步 currentRoomState，并通过现有首状态回放接入。
