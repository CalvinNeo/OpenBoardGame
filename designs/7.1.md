# Design 7.1: 出包魔法师（Abraca...what?）

## Rule Summary (MVP)
- 2–5 人，目标 8 分；每轮起始生命 6。
- 36 张魔法石（1–8 对应数量），玩家只能看到他人手牌，看不到自己。
- 每回合至少施放 1 次；可连招，后续法术编号必须 ≥ 前一次。
- 失败：扣 1 生命并立即结束回合；巨龙失败用骰子伤害替代（不额外 -1）。
- 猫头鹰获得“秘密卡”（不可用、不可公开），本轮存活时每张 +1 分。
- 轮末计分：
  - 击杀者 +3，其他存活者 +1，死亡者 +0。
  - 若有人打空手牌：该玩家 +3，其余 +0。
  - 再加秘密卡分数（仅存活者）。
- 2 人：秘密卡池 12 张；3 人：6 张；4–5 人：4 张。

## Data Model

### SpellType
- DRAGON(0), GHOST(1), DREAM(2), OWL(3), LIGHTNING(4), SNOW(5), FIRE(6), POTION(7)

### Card
- id: int (0–35)
- type: SpellType (映射按 1..8 数量展开)

### PlayerState
- player_id: str
- name: str
- seat: int
- hp: int (0–6)
- score: int
- hand: list[int] (card ids, 自己不可见)
- secret_cards: list[int] (猫头鹰获得)

### GameState (AbracaWhatGame)
- round: int
- phase: WAIT_USE | WAIT_GOON | WAIT_DICE | WAIT_SEE | WAIT_DRAW | ROUND_END | GAME_OVER
- current_turn: player_id
- last_spell: SpellType | null
- last_action: {player_id, spell, success, dice, hp_delta}
- deck: list[int]
- discard: list[int]
- secret_pool: list[int]
- players: dict[player_id -> PlayerState]
- config: {target_score: 8, hand_size: 5, secret_pool_by_players: {2:12,3:6,4:4,5:4}}

## Actions
- cast_spell {spell_type}
- roll_dice {} (用于 DRAGON/DREAM)
- take_secret {} (用于 OWL，随机抽 1 张秘密卡)
- end_turn {} (补到 5 张并切换回合)
- start_next_round {} (自动或房主触发)

## Validation & Rules
- 仅当前回合玩家可行动。
- WAIT_GOON 时，spell_type 必须 >= last_spell。
- cast_spell 验证玩家手牌是否包含该法术；失败则扣 1 生命并进入 WAIT_DRAW。
- 生命上限 6，下限 0。
- 轮末触发时立即结算，不再补牌。

## Turn Flow
1. **WAIT_USE**：玩家选择施法。
2. **cast_spell**：
   - 成功：执行效果。
   - 失败：扣 1 生命 → **WAIT_DRAW**。
3. **需要骰子**：进入 **WAIT_DICE** → roll_dice → 处理结果 → **WAIT_GOON** 或 **WAIT_DRAW**。
4. **猫头鹰**：进入 **WAIT_SEE** → take_secret → **WAIT_GOON**。
5. **继续或结束**：
   - 继续：回到 **WAIT_GOON** 并限制法术编号。
   - 结束：**end_turn** 补牌至 5 → 下一位玩家 **WAIT_USE**。
6. **Round End**：若有人死亡或打空手牌，进入 **ROUND_END** 结算并重置。

## Scoring & Round Reset
- round_end_type: KILL | SELF_DEATH | EMPTY_HAND
- 基础加分：
  - KILL：killer +3，其他存活 +1。
  - SELF_DEATH：存活 +1。
  - EMPTY_HAND：打空者 +3。
- 追加：存活玩家 + secret_cards.length。
- 若任一玩家 score >= target_score：GAME_OVER（同分可共同胜利或按当轮得分判定）。
- 重置：回收全部卡牌、清空秘密卡、生命恢复到 6，重新发牌与秘密池，回合轮转。

## Views & Hidden Info
- 公共：牌堆数量、弃牌区（按法术分类统计）、秘密池数量、当前回合、最后行动、各玩家分数/生命/秘密卡数量。
- 私密：
  - 自己手牌显示为背面或“未知卡”。
  - 其他玩家手牌显示真实法术。
  - 自己的秘密卡可见内容，别人只见数量。

## UI (MVP)
- **公开区域**：计分塔（0–8）、弃牌区（按 8 种法术分列/叠放）、牌堆剩余、秘密池剩余。
- **玩家区域**：
  - 每位玩家：名字、分数、生命、手牌展示、秘密卡数量。
  - 自己：手牌背面 + “我不知道的牌”，秘密卡私密区。
- **行动区域**：
  - 法术按钮（1–8），带禁用状态与连招限制提示。
  - 掷骰按钮（1–3）与结果提示。
  - 抽取秘密卡按钮与提示。
  - “结束回合/停止施法”按钮。

## Bot (Optional MVP)
- 优先施放“确定自己有”的法术（根据公开信息与排除法）。
- 低血量时优先治疗类（梦/药水）。
- 若能击杀则优先攻击类。
