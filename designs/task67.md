## 一、游戏概览

`官方规则 + 交叉确认`

- 类型：社交推理 + 语言联想 + 团队猜测。
- 人数：常见为多人分成 `2` 队，轮流出题与猜测。
- 核心机制：
  1. 当前队伍的“心灵感应者（Psychic）”知道一个隐藏目标在光谱上的位置。
  2. TA 只能给出“位于本轮光谱两端概念之间”的一个线索。
  3. 队友旋转刻度盘进行落点。
  4. 对手队再猜“真正中心点在你们落点左边还是右边”。
  5. 揭晓并双方计分。
- 胜利目标（对抗）：通常先到 `10` 分，或按平局加赛规则决胜。

## 三、标准对抗模式：完整流程

## 1) 开局

`官方规则 + 实现约定`

1. 分成 `2` 队（人数尽量均衡）。
2. 初始化分数：
   - 先手队：`0`
   - 后手队：`1`（追赶平衡机制）
3. 各队指定首轮心灵感应者。
4. 洗混卡池并进入首轮。

## 2) 每轮四阶段

`官方规则`

### A. Psychic Phase（出题阶段）

当前队伍的心灵感应者执行：

1. 抽 `1` 张光谱卡，可从双面中选一面（若卡是双面设计）。
2. 公布两端概念（让所有人知道本轮光谱是什么）。
3. 随机生成本轮隐藏目标位置（实体版是转轮随机）。
4. 仅心灵感应者可见目标位置。
5. 给出一个线索（需符合出题限制，见第五章）。
6. 给完线索后必须停止沟通（不得追加解释、不得表情暗示）。

### B. Team Phase（本队讨论拨盘）

1. 仅当前队伍（不含沉默中的心灵感应者）讨论线索。
2. 队伍可反复调整刻度位置。
3. 确认后“锁定落点”。

### C. Left/Right Phase（对手左右竞猜）

1. 对手队基于当前队落点，做二选一：
   - `LEFT`：认为真实中心在落点左侧
   - `RIGHT`：认为真实中心在落点右侧
2. 对手锁定竞猜。

### D. Scoring Phase（揭晓与计分）

1. 揭示真实目标区域。
2. 当前队按“落点命中的分区”得分（常见是 `2-4` 分区）。
3. 对手队若左右猜中，得 `1` 分。
4. 特例：若当前队命中最中心高分区（4 分区），对手本轮不能拿左右竞猜分。
5. 更新总分。

## 3) 连续追分规则（Catch-up Rule）

`官方规则`

- 若当前队本轮拿到 `4` 分，且本轮结算后仍落后，则该队立即再进行一轮（更换心灵感应者）。
- 该机制允许落后方连续行动追分。

## 4) 轮转与结束

`官方规则 + 实现约定`

- 正常情况下，下一轮换另一队行动。
- 任一队达到 `10` 分后检查结束条件：
  - 若领先则直接获胜。
  - 若平分，进入“平局加赛”：双方各再进行一轮，比较该轮总得分（含左右竞猜分）；仍平则继续加赛循环，直到分出高低。

## 四、计分模型（电子版可直接落地）

## 1) 对抗模式单轮计分

`官方规则 + 实现约定`

设：

- `t` = 真实中心坐标
- `g` = 当前队最终落点
- `band(t, g)` = `g` 落入的目标分区（`MISS/2/3/4`）

规则：

1. `active_team_points = score_of(band)`，其中 `MISS=0`。
2. 若 `active_team_points == 4`，则 `other_team_points = 0`。
3. 否则对手按方向判断：
   - 若 `t < g` 且对手猜 `LEFT`，得 `1`
   - 若 `t > g` 且对手猜 `RIGHT`，得 `1`
   - 其他得 `0`
4. 边界判定（实体规则常见）：若指针压在两区边线上，当前队取更高分区。

## 2) 几何实现建议

`实现约定`

- 使用归一化线段 `[-1, +1]`。
- 定义目标区宽度：
  - 4 分区半宽 `w4`
  - 3 分区半宽 `w3`
  - 2 分区半宽 `w2`
- 判定顺序：
  1. `|g - t| <= w4 => 4`
  2. `|g - t| <= w3 => 3`
  3. `|g - t| <= w2 => 2`
  4. 否则 `0`

> 若你要 1:1 复刻实体盘面，建议使用角度制 + 扇区边界数组，而不是抽象宽度。

## 五、出题规则（线索合法性）

`官方规则 + 交叉确认`

1. 单一想法：线索应表达单个概念，不应拼接两个独立线索。
2. 不得临时发明不存在实体：可用虚构作品中的事物，但不能为本局临时杜撰。
3. 必须与本轮光谱相关：不能借词语双关绕开题面。
4. 不能直接使用题面词及同词族表达。
5. 禁止数字引导（专有名中的数字可酌情放行）。

## 2) 建议性约束（房规）

`交叉确认 + 实现约定`

- 线索尽量简洁（建议 `<= 5` 词）。
- 避免“很/稍微/几乎”等修饰词引入二阶解释。
- 若题面是“___ person”类，更鼓励专有名词而非长句定义。

## 3) 违规处理策略（可配置）

`实现约定`

- `warn_only`：提示但继续
- `redraw`：本轮重抽并重来
- `forfeit_round`：当前队本轮 `0` 分

推荐默认：

- 好友房：`warn_only`
- 匹配房：`redraw`

## 六、电子版状态机

`实现约定`

```ts
type Phase =
  | "ROUND_INIT"
  | "PSYCHIC_PREPARE"
  | "PSYCHIC_CLUE_LOCK"
  | "TEAM_DISCUSS"
  | "TEAM_LOCK_DIAL"
  | "OTHER_TEAM_SIDE_GUESS"
  | "REVEAL_AND_SCORE"
  | "CATCH_UP_CHECK"
  | "ROUND_END"
  | "GAME_END";
```

推荐状态转移：

1. `ROUND_INIT -> PSYCHIC_PREPARE`
2. `PSYCHIC_PREPARE -> PSYCHIC_CLUE_LOCK`
3. `PSYCHIC_CLUE_LOCK -> TEAM_DISCUSS`
4. `TEAM_DISCUSS -> TEAM_LOCK_DIAL`
5. `TEAM_LOCK_DIAL -> OTHER_TEAM_SIDE_GUESS`
6. `OTHER_TEAM_SIDE_GUESS -> REVEAL_AND_SCORE`
7. `REVEAL_AND_SCORE -> CATCH_UP_CHECK`
8. `CATCH_UP_CHECK -> ROUND_END`
9. `ROUND_END -> ROUND_INIT`（下一队或同队追分再来）
10. 达到结束条件转 `GAME_END`

## 关键权限与可见性

`实现约定`

- `PSYCHIC_PREPARE` 时只有心灵感应者客户端可见目标坐标 `t`。
- `TEAM_DISCUSS` 阶段锁死心灵感应者输入通道（聊天/表情/语音可选禁言）。
- 揭晓前，任何非 psychic 客户端都不能拿到真实目标值（包括通过调试字段）。

## 七、合作模式（Co-op）

`官方规则 + 交叉确认`

核心差异：

1. 全体玩家共同对抗分数目标。
2. 开局放入固定数量随机光谱卡（常见规则为 `7` 张）形成“本局轮数池”。
3. 每轮无对手左右竞猜阶段。
4. 计分与对抗类似，但中心高分区通常记为 `3` 分（而非 `4` 分），并触发“奖励卡”：往轮数池再加入 `1` 张卡，等于多一轮机会。
5. 卡池耗尽则游戏结束，根据最终总分查评价档位。

电子版建议：

- `mode = "versus" | "coop"`
- coop 下禁用 `OTHER_TEAM_SIDE_GUESS` 相位
- coop 下提供 `score_table` 可配置，以适配不同本地化文本

## 九、AI/服务端判定要点

`实现约定`

1. **目标随机性**
   - 服务器生成 `hidden_target.center`，客户端只接收必要可见字段。
2. **边界一致性**
   - 前后端共用同一分区判定函数，避免显示得分与服务端得分不一致。
3. **并发锁**
   - `TEAM_LOCK_DIAL`、`OTHER_TEAM_SIDE_GUESS` 采用幂等提交 + 版本号校验。
4. **断线恢复**
   - 每个 phase 存快照，重连后按可见性回放（不泄漏隐藏信息）。
5. **审计日志**
   - 记录每轮 `card_id`、`clue_text`、`g`、`t`、score 结果，便于复盘争议局。

## 十、测试清单（最小可发布）

`实现约定`

## 1) 规则正确性

- 命中 2/3/4/未命中四种分区都能正确计分。
- 对手左右竞猜在“4 分命中”时必定不给分。
- 边界压线时取高分。
- 追分规则触发与不触发分支都正确。

## 2) 权限与防泄漏

- 非 psychic 端在揭晓前无法通过任意接口拿到 `t`。
- spectator 模式不会泄漏隐藏目标。

## 3) 流程稳定性

- 心灵感应者掉线、重连后仍可继续本轮。
- 队伍同时提交操作不会出现双写。
- 平局加赛可连续多轮且不会死循环。

## 4) 合作模式

- 初始 `7` 张卡耗尽后正确结算。
- 命中中心高分区时能正确加卡并延长局数。
