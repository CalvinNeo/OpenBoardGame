# Task 131：电力公司 / Power Grid

## 范围与规则

实现 `power_grid`：经典版德国地图、2–6 人、真人与机器人混合、存档与重连。保留完整经济循环和 42 张基础电厂；本次不包含美国地图、Recharged 折扣规则或扩展。规则依据为 [Rio Grande / 2F 经典规则书（2009 修订、2010 印刷）](https://cs.uwaterloo.ca/~dtompkin/archive/dtlib/base/Power%20Grid.pdf)，组件数值交叉核对 [德国地图数据](https://github.com/gummyboars/lunboks/blob/master/powerplant/cities.py)和[经典电厂数据](https://github.com/gummyboars/lunboks/blob/master/powerplant/plants.py)，界面地图自行绘制，不使用商业美术素材。

- 起始资金 50 Elektro（💰）。按人数使用 3／3／4／5／5 个相连区域，每区 7 城；默认选择连续区域，配置可改选并由服务端验证连通性。随机初始顺序；后续按城市数、最高电厂编号降序排列。
- 每轮依次竞拍电厂（🏭）、逆序买资源、逆序建设城市（🏠）、顺序供电（⚡）并领取收入。首轮每人必须买一座电厂，首轮竞拍后重新确定顺序。竞拍叫价按座位顺时针进行；放弃一次竞价与放弃本轮购买分开处理；每人每轮最多买一厂。
- 完整现货／未来市场、13 号置顶、Step 3 牌置于底部、人数对应暗移除电厂、无人购买淘汰最低厂、落后电厂淘汰、轮末最高厂沉底。Step 3 在抽出后的下一阶段生效，市场缩为 6 张。Step 2 在建设阶段结束后生效，不让后手提前使用第二个城市格。
- 煤（🟤）、油（⚫）、垃圾（🟡）、铀（🔴）各自使用动态价格和有限总量；严格执行双倍燃料储存、混合厂煤油共享容量、满额耗料和每厂每轮至多发电一次。资源可自由调配，因此后端使用等价的公司资源池与各厂兼容容量约束。换厂时允许玩家决定保留哪些资源，超额退回供应堆。
- 城市建设费用为 10／15／20 加从已有网络出发的最便宜线路费用；允许经过未占领或已满城市，禁止经过未启用区域，不把历史付费线路视为永久免费。使用 Dijkstra 计算预览与最终支付。
- 按规则书人数表设置电厂上限、Step 2 和终局门槛；达到终局门槛仍完成整段建设，然后按现有资源最多可供电城市数决胜，依次以现金、已连接城市数破平。终局不额外发收入。普通轮收入与补货后停留结算，所有玩家点击 **Next Round** 才开始下一轮。

## 后端方案

新增 `game/power_grid_data.py`（卡表、德国 42 城和线路、人数参数、补货与收入表）和 `game/power_grid.py`（状态机、校验、视图、机器人）。实现仓库标准接口：`init_game / get_legal_actions / apply_action / get_public_view / bot_move / serialize / deserialize`。

阶段：`auction → resources → building → bureaucracy → round_end`；换厂暂入 `replace`，终局为 `game_over`。动作带 `round` 和 `revision` 防止重复提交、延迟请求及重连重放；轮末确认使用轮号、允许所有人同时确认。所有参数先在副本验证成功再提交，非法动作不得改状态。

视图公开顺序、地图、各公司城市／电厂／燃料、市场库存与价格、正在进行的拍卖、轮末结果。现金只向本人展示，终局揭示；牌库顺序、暗移除牌和随机种子始终隐藏。客户端获得建设报价、可买数量、可用供电组合等必要数据，不能修改规则数值。公共事件不泄漏现金余量或牌库；机器人只根据公开视图和自己的信息行动。注册游戏名称、标签、资源和分发，更新 `game/dev_order.json`；活动存档保护防止旁观者通过下载或克隆读取隐藏信息。

## 前端方案（FRONTEND.md / task40.md）

新增 `static/games/power_grid.{html,css,js}`，使用 `GAME_ASSETS` 按需加载；首页只保留空游戏面板、配置和头部占位。JS 封装 IIFE，仅暴露 `PowerGrid` 专用前缀函数；初始化兼容 DOMContentLoaded 已触发及首状态回放。更新资源与加载器版本。

- 深绿电网、暖白卡牌与橙黄供电强调色，原创 SVG 线路图和 CSS 电厂卡。桌面地图／市场邻接，操作台紧邻相关内容；手机重排为单列、紧凑双列卡牌，页面无横向滚动。地图支持受限缩放／拖动，`touch-action: none`、指针捕获和拖动后点击抑制，地图之外正常滚动；另有城市列表供精确选择。
- 每段线路直接显示费用，包括 0 费用，缩略视图和手机也始终可见。费用用浅橙色矩形标签，城市用圆形编号，通过颜色、形状和图例区分；密集位置错开标签并用引线指回对应线路，避免遮挡城市和其他费用。标签支持两端城市与金额提示、Explain，并随选中最短路径高亮。
- 操作包含选厂出价、加价／Pass、资源数量步进与费用预览、选城查看最短路和 Build、换厂与资源保留、点选供电电厂与混合耗料。Bid 使用「− / 金额 / +」，每次调整 1 💰，默认最低合法叫价，限制最低价与本人余额，不需打字。不让用户输入 JSON；空白／Esc 取消选择，不加 Clear Selection。
- 通用 UI 使用英文。名称与 Emoji 在 Help／Explain 同时列出；静态图标有悬停／焦点提示与手机点击 3 秒浮层，连续点击替换。日志和轮末明细有高度限制及内部滚动。
- Help 弹窗集中完整玩法；Explain 用捕获阶段拦截操作，有解释目标才显示虚线与问号；无解释按钮也不触发动作，disabled 按钮支持 pointerdown 坐标命中。解释后退出，Esc 退出／关闭弹窗并归还焦点。不逐区放 i 图标。
- 结算明确展示每人供电、收入、全员确认进度；断线真人不能由机器人代为确认。最终结果保留供查看。
