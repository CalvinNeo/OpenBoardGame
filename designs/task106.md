# Task 106 — 神秘小地 / Terra Nova

## 目标与规则来源

新增 `terra_nova`，实现 Andreas Faul 的 2022 年《Terra Nova》（中文亦称大地新秘境、神秘小地），接入现有 2–4 人房间、机器人、保存恢复和断线重连。按基础版五轮游戏实现十个非对称种族、地形改造、建造与升级、航运、桥梁、魔力循环、城镇、奖励片和终局计分。

规则以 [KOSMOS 官方规则 PDF](https://cms.kosmos.de/game-instructions/4002051683382_TerraNova_Manual_DE_160522_web.pdf) 为准，参考 [Capstone 英文规则旧地址](https://capstone-games.com/wp-content/uploads/2022/06/Terra-Nova-Rules.pdf) 和 [中文发行商介绍](https://www.swanpanasia.com/products/terra-nova)。英文旧链接直接下载返回 404，因此实际下载、渲染并核对官方德文规则。具体组件数值、地图转录及来源核对见 [terra_nova_sources.md](terra_nova_sources.md)。游戏页面只使用原创 CSS/SVG/Emoji，不使用商业版图、卡图、Logo 或 UI 素材。首版采用官方基础主地图；双人背面地图、变体和扩展不作为基础玩法替代。

## 游戏流程和规则模型

- 准备：玩家依次选不同颜色的种族，初始化金钱、三碗魔力、航运及建筑供应；依规则顺序放置初始房屋并逆序选奖励片。随机确定五轮计分片和本局奖励片供应，所有当前使用的计分片公开可查。
- 收入：根据已建房屋、贸易站、宫殿、种族和当前奖励片获得金币及魔力。魔力先由 I 碗全部转入 II，再由 II 转入 III；支付从 III 返回 I。
- 行动：按当前顺位轮流执行一次主要行动。地块可达性区分直接邻接、桥梁连接与通过连续河流格的航运距离。非原生地形按地形环计算一／两铲，付费改造成原生地形，可选择同时建房。
- 建筑：房屋升级贸易站，贸易站升级左右宫殿；建筑回收至个人供应，贸易站按是否邻接对手采用对应费用，左右宫殿分别激活种族能力。相邻玩家按规则获得魔力，必须正确区分桥梁邻接与航运可达。
- 航运、付费桥梁、公共魔力行动、种族宫殿能力、奖励片特殊行动均通过可见选项执行。共享行动每轮只使用一次，个人行动独立记录；魔力兑金币为额外选项，不消耗主要行动。
- 城镇：由直接邻接／桥连接的建筑构成，满足建筑数量及力量要求时立即触发；已计入城镇的建筑不得重复创镇。让玩家选择自己的剩余城镇奖励，处理触发的魔力、金币、航运及分数。
- 退出：兑现种族／奖励片退出计分，选择不同的奖励片并领取片上积币；本轮第一个退出者成为下一轮起始玩家。无人持有的奖励片在轮末累积金币。第五轮退出仍须换片并领取积币，只跳过下一轮准备。
- 轮末：完整保留当前版图、分数变化与日志，进入 `round_end`；每位玩家独立点击 `Next Round` 后才开始下轮，机器人只确认自己。第五轮同样保留回顾，全员确认后展示最终计分。
- 终局：依官方规则结算剩余资源和最大连通区域，处理并列名次；显示总分构成和共同获胜者。无隐藏的任意回合上限。

## 服务端和协议

新增 `game/terra_nova.py`、`game/terra_nova_data.py` 与固定桥位表 `game/terra_nova_map.py`，实现现有 `init_game`、`get_legal_actions`、`apply_action`、`get_public_view`、`bot_move`、`serialize`、`deserialize` 接口。公开视图使用深拷贝，包含当前地图、玩家资源／建筑、阶段、轮次计分、奖励供应、待决选择、日志及 `action_options`（完整动作、文案、相关地格）。种子不向房间公开配置泄漏。

服务端验证执行者、阶段、费用、库存、邻接、行动次数和选择是否仍合法；非法输入不得部分修改状态。复杂复合行动使用分步选择或服务端提供的完整合法选项，不要求客户端打字输入 JSON。机器人从同一合法选择集中采用公开信息启发式，可完成设置、主要行动、待决选项、轮末及终局。

## 前端设计

严格遵守 [FRONTEND.md](../FRONTEND.md) 与 [task40.md](task40.md)。主要逻辑放 `static/games/terra_nova.js` 私有 IIFE，仅导出带 `TerraNova` 前缀的接入函数；新增独立 CSS，`app.js` 只处理必要的游戏切换与渲染分发。

- 原创纸质棋盘风格，地形同时使用颜色、图标和名称；房屋(🏠)、贸易站(🏪)、宫殿(🏰)、金币(💰)、魔力(🟣)、航运(⛵)、桥梁(🌉)、铲子(⛏️)在 Help／Explain 中同时列明。
- 桌面地图与行动区并排，个人资源、种族能力和五轮计分紧凑呈现；移动端重排，地图在自身区域缩放／平移，禁止页面横向滚动、文字或图标溢出及面板互相遮挡。拖动使用 `touch-action: none` 和 pointer capture，结束后不误触格子。
- 点击地图显示可执行动作，合法目标高亮；种族、建筑升级、奖励及城镇选项使用卡片和确认按钮。空白区域／Esc 取消选择，不增加 Clear Selection。非游戏内容控件用英文。
- Help 集中展示完整规则与范围，主界面只留简短当前指引；Explain 捕获事件后屏蔽原动作，仅可解释元素显示虚线和问号，禁用控件仍可查看说明。解释后自动退出；对话框支持 Close、Esc、遮罩关闭。
- 非交互图标有桌面悬停／焦点说明，手机点击显示浮动提示并于三秒后消失，连续点击替换旧提示。日志和轮末回顾限制高度，容器内部滚动。
