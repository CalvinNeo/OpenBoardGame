# 《印象花语》游戏说明书

## 游戏规则

配置文件在 game/assets 中。支持多种规则，目前是默认规则。

作画规则：
- 只可以使用规定数量的印章作画。印章分为圆、三角、正方形、长条四种。
- 印章的颜色是固定的，通过配置文件来指定。默认配置是：红、绿、蓝、黄。
- 印章的大小是固定的，通过配置文件来指定。默认配置是：圆的直径、正方形和三角形的边、长条的长相等。
- 应该允许印章在超出画布的范围盖下，此时，只会留下它在画布之内的印迹。
- 玩家可以选择使用一张较小的废纸进行辅助。此时，他可以将废纸拖到作图纸的上方，保护住已经作出的画。废纸支持旋转与缩放。印章盖下后，废纸会立即被丢弃。
- 可以选择印章的轻重，对应就是透明度，一次按压决定透明度（可用按住时长计算），落印后不再持续加深。
- 印章可以重叠盖印，此时，重叠区域的颜色应当根据它们的透明度，按照色彩学原理进行混合。
- 印章支持旋转，不需要支持缩放。

游戏规则：
- 游戏支持 3-6 人游玩。
- 假设有 P 个人参加游戏，那么第一个玩家成为猜题者，其他玩家作为出题者。
- 猜题者需要猜 X 关。每一关都随机抽取 P + 1 张词卡，将其中 P - 1 张词卡分给出题者，剩余的  2 张作为干扰项存在。然后进入作画阶段。
- 每一关的作画阶段，每个出题者分别只能选择 N、N-1、N-2、N-3，直到 N-(X-1) 个印章进行作画，其中 X 和 N 在配置文件中指定。
- 每个人都画完之后，这 P - 1 张画会被呈现给猜题者，猜题者需要准确将它们对应的词找到。正确一个，猜题人 +当前轮次 分，出题人 +当前轮次 分。猜题阶段不需要隐藏画作者身份。
- 每一轮结束后，可以选择要不要继续游戏。
- 当 X 关都结束后，可以选择第二个玩家开始继续闯关，由此类推。

UI 关注点：
- 你需要支持 Undo 功能。
- 猜题者通过拖动词条的方式完成匹配。
