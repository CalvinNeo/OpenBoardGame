# Task 190：给我！还是他？（Give Me! Or Him?）

## 1. 游戏概述

- **中文名**：《给我！还是他？》 ｜ **线上版 game_id**：give_me_or_him
- **人数**：3–6 人 ｜ **时长**：约 20 分钟 ｜ **适龄**：10 岁以上 ｜ **机制**：合作 + 匿名提示 + 反向猜词
- turn_mode = "turn"（顺时针轮流行动，猜词是被他人点名触发的插入步骤）

这是一款**全队合作**的猜词游戏，走的是“反向猜词”路线：**所有人都知道你的词，只有你自己不知道**。
每位玩家面前立着一块编号立牌，上面插着自己的词语卡——卡面朝向其他人，背朝自己。
每回合轮到的人只能二选一：要么打出一张提示卡，为卡背编号对应的那位玩家写一个提示词；
要么拿一个金色问号(❓)点名任意一位玩家立刻猜词。提示卡正面朝上摊在桌面中央，
**谁写的大家都看得见，但写给谁谁都不知道**。被点名的玩家要从一堆提示里推理出“哪几条是给我的”，
猜对就把立牌翻到 ✔ 一侧，猜错则消耗掉一个金色问号。全队一共有 3 个金色问号，
在它们全部碎掉之前让所有人猜出自己的词，全队获胜。

## 3. 组件

### 3.1 词语卡（线上版自建词库）

视频未展示词语卡总张数，线上版在 game/give_me_or_him_data.py 中自建 **230 个**具体名词，
全部为 2–3 字、可被“一个提示词”指向的日常词（动物、身体、食物、场所、物件、自然等）。
开局从中随机抽取“人数”张，保证同一局不重复。

### 3.2 编号立牌

每位玩家一个编号（1..N，按座位顺序分配）。立牌正面是编号与词语卡插槽，背面是编号 + ✔。
线上版用“玩家卡片”表达：卡片头部显示编号(🔢)，词位对他人显示词语、对自己显示 ❓，
通关后翻转为 ✔ 并公开词语。

### 3.3 提示卡

- 背面印玩家编号，**每个编号 3 张**，N 人局共 3N 张。
- 开局洗匀后**全部发完**，每人 3 张；打出的牌进入桌面中央，**不补牌**。
- 正面是白板，线上版改为输入一个提示词（1–12 字）。

### 3.4 金色问号(❓)

全队共享 3 个，代表 3 次容错。猜对后回到中央可再次使用，猜错则永久碎掉一个。

## 4. 回合流程

座位顺序即行动顺序，顺时针轮流，**轮到谁谁行动**，行动结束后交给下一位。

轮到某位玩家时，**必须且只能**执行下列两个行动之一：

1. **写一个提示(✍️)**
   - 从手牌打出一张提示卡，卡背编号决定这张牌写给谁。
   - 若卡背编号是**自己**，或该编号对应的玩家**已经通关**，这张牌成为**万能提示卡**，可以写给任意一位尚未通关的玩家。
   - 写好后正面朝上放到桌面中央：提示词所有人可见，**写给谁保密**。
2. **点名猜词(❓)**
   - 从中央拿一个金色问号，放到任意一位**尚未通关**的玩家面前（可以是自己）。
   - 该玩家必须立刻根据桌面上的全部提示猜出自己的词。

猜词结算后进入**结算暂停**：所有玩家点击 Continue 后才继续下一位玩家的回合。

### 4.1 提示词的五条禁忌

视频 01:03 给出的原文：

1. 不能交流提示卡是给谁的
2. 不能用高关联词（近义词）提示
3. 不能用符号提示
4. 不能用外语单词提示
5. 不能用场上可见字提示

线上版把**可机器判定**的部分做成硬校验（见 §5），其余（近义词、口头交流）作为玩家自律条款写进 Help。

### 4.2 猜词判定

- 猜对：立牌翻到 ✔，金色问号**回到中央**。
- 猜错：金色问号**碎掉一个**（永久），该玩家仍未通关，之后可以继续收到提示并再次被点名。

### 4.3 胜负

- **胜**：所有玩家都猜出自己的词。
- **败**：3 个金色问号全部碎掉，且仍有玩家未猜出。

## 5. 线上版实现约定

以下为视频未覆盖、为了让规则在服务器上可判定而做的决定：

| 项 | 约定 |
| --- | --- |
| 提示卡发牌 | 3N 张全发，每人 3 张，永不补牌（与视频自洽） |
| 提示词长度 | 1–12 字，去首尾空白后判定 |
| 提示词硬校验 | ①不得为空或纯符号；②不得等于场上任何一位玩家的词；③不得包含场上任何词语里出现过的字（对应禁忌 5）；④不得与桌面上已有提示词重复 |
| 猜词输入 | 单个词，去空白与标点后与目标词比较，忽略大小写 |
| 猜错记录 | 记录该玩家猜错的词，UI 置灰，规则上允许重复猜同一个词 |
| 结算暂停 | 每次猜词结算后进入 reveal 阶段，**所有玩家**点击 Continue 才推进回合 |
| 已通关玩家 | 仍正常轮到自己，可以继续写提示，也可以点名让别人猜 |
| 词语卡 | 每局重抽；结束页面提供 Play Again，全员确认后重开 |
| 隐私 | get_public_view 永远不返回 viewer 自己的词（除非该玩家已通关或游戏结束） |

## 6. Bot

机器人策略**内联在 game/give_me_or_him.py** 的 _bot_choose_action 中，是一个**非策略型**机器人：
写提示时从词库里挑一个能通过全部硬校验的词，猜词时在“排除掉别人已公开的词和自己猜错的词”之后随机选。
机器人只允许读取公开信息（他人词、桌面提示、自己手牌），猜词时从“场上仍在局的词的集合”里等概率抽取，
因此不会利用“哪一个才是自己的词”这条信息。

因为它只是随机合法策略，**不单独建 *_ai.py 模块**（tests/test_ai_metadata.py 规定有专用 AI 模块的游戏必须标记为策略型），
game/ai_metadata.py 的 STRATEGIC_AI_GAME_IDS 也**不收录** give_me_or_him，Select Game 页面不标 🤖。

- 布局：顶部状态条（金问号 + 阶段）→ 玩家立牌网格（主体）→ 桌面提示区 → 手牌/行动托盘。
- 交互：点手牌 → 原地蒙版确认（写提示 / 取消）；点名猜词用玩家卡上的蒙版确认；点空白处取消选择。
