# Task 137：面具摔跤手 / Maskmen

## 规则依据与范围

实现 Oink Games 的 60 张牌版本 `maskmen`，2–6 人，支持房间机器人、重连与存档。依据 [出版方游戏说明](https://oinkgames.com/en/games/analog/maskmen/)与 [Oink Games 英文规则书 v1.1（公共图书馆镜像）](https://content.cmpl.org/bg/Maskmen.pdf)，已逐页检查原版规则与强弱关系示例。使用原创 CSS 面具，不使用商业卡图。

六种面具各 10 张：橙色（🟠）、粉色（🩷）、灰色（⚪）、蓝色（🔵）、紫色（🟣）、绿色（🟢）。2–4 人各发 15 张、5 人各发 12 张、6 人各发 10 张；剩余牌暗置不用。每赛季重新洗全套牌，清空强弱关系；首季随机首家，后续赛季由上季末名首出。

每次出同一种面具，最多 3 张。空桌首出时，本赛季尚未出现过的面具只能出 1 张；已出现过的面具可出 1–3 张。接牌时，已知更强者必须出相同张数；强弱未知者必须恰好多出 1 张，并建立其胜过前一面具的关系。同种或已知更弱者不能接牌。强弱具有传递性，但没有路径的两个面具仍是未知，不能按图上高度强行比较。关系用有向无环图保存。

可以主动 Pass；Pass 后退出当前小轮，清场后重新参与。玩家出完手牌立即获得名次，剩余玩家继续，直到只剩一人有牌。第一名 +2、第二名 +1、末名 −1、其他 0；两人时记录赛季胜场（并显示 +2／−1）。3–6 人共 4 赛季，总分最高获胜；两人先赢 3 赛季获胜。多人同分先比较冠军数，再优先最近一次赢得赛季的玩家；若并列者从未夺冠，以最后赛季出完牌顺序裁决。后一项是规则书未覆盖边界的线上约定，Help 中明示。

小轮仅剩一位未 Pass 且仍有牌的玩家时，由其下一轮首出。如果最后出牌者出完且所有仍有牌者已经 Pass，按顺时针选择下一位有牌者首出；这是对离场边界的明确处理。小轮结束保留桌面，所有玩家点击 **Next Round** 才清场；赛季结束保留名次、得分与剩余手牌数量，所有玩家点击 **Next Season** 后再发牌。AI 只替自己确认，断线真人仍需重连确认。最终结算永久保留，使用房间 Restart 重开。

## 服务端与 AI

新增 `game/maskmen.py` 与 `game/maskmen_ai.py`，接入现有 registry。状态机：`playing → round_review → playing`，赛季结束进入 `season_review`，最终进入 `game_over`。服务端统一产生合法组合，验证回合、手牌数量、强弱、Pass、确认权限和输入类型。动作携带 `game_token / season / bout / turn_number`，过期包不能跨轮、跨赛季或重开作用；重复确认幂等。JSON 存档回读无信息损失。

公开视图只含自己的手牌、各人剩余张数、累计分／冠军数、公开出牌、强弱关系和确认状态。隐藏对手手牌、未发牌与随机种子。沿用活动私密牌局存档保护，禁止下载／克隆活动存档，原座位 token 可冷启动重连。

AI 仅接收 `get_public_view` 的结果。枚举合法组合，评估出牌数量、清掉一种面具、剩余牌所需步数、建立关系对自己后续牌的价值，以及根据公开剩余牌数估算对手接牌概率；优先立即出完，考虑临近出完的对手，必要时保留整组牌并 Pass。属于无需模型或外部服务的启发式练习 AI，不能查看对手手牌或暗置牌。

## 前端（遵守 FRONTEND.md / task40.md）

新增 `static/games/maskmen.{html,css,js}`；IIFE 私有作用域，仅暴露 Maskmen 前缀入口。首页只增空面板、页头与弹窗占位，在 `GAME_ASSETS` 中注册按需加载，修改公共资源后递增对应 URL 版本。初始化兼容 DOMContentLoaded 已触发，同步最新房间和游戏状态。

暖白背景、深色擂台、亮色原创面具。桌面双栏显示牌桌与强弱关系；手机紧凑单栏。手牌按六种颜色分组显示数量，点选面具后在同一区域选择合法张数并 Play，点击空白或 Esc 取消；不设 Clear Selection。Pass 与 Next 按钮直接执行，不增加二次确认。当前回合、已 Pass、出完名次、积分与赛季胜场清楚区分。

强弱区逐项显示“胜过谁”，同时提供带颜色与名称的关系矩阵，`?` 明确代表未知，避免把并列排版误认作等强。长名字自动换行，日志与规则内部滚动，320px 起无横向滚动、溢出或遮挡。面具同时有颜色、文字与形状信息，非游戏 UI 使用英文。

Help 集中完整规则、出牌例子、计分、两人模式及边界约定。Explain 按 task40 的捕获阶段拦截所有操作，仅高亮有解释目标，支持禁用按钮，解释后自动退出，Esc 可退出。静态图标／缩写均有悬停和键盘焦点提示，手机点按提示 3 秒，新提示替换旧提示。Help／Explain 同时列出名称与 Emoji，不添加逐区 i 按钮。
