# 《极速画猜：硬核盲猜版》(Blitz Sketch: Hardcore Edition) 游戏设计文档

## 1. 游戏核心概念 (Core Concept)
这是一个考验**瞬间反应**与**短期记忆**的极限绘画游戏。
* **挑战**：60秒内完成20张画（3秒/张）。
* **噩梦**：随后打乱顺序，在**没有任何备选词库**的情况下，看着自己潦草的线条，手动输入猜测自己当时画的是什么。

---

## 2. 详细游戏流程 (Game Loop)

### 2.1 阶段一：极速作画 (The Blitz Phase)
* **规则**：
    * 总时间：60秒。
    * 题目数：20个。
    * 每题时限：**3.0秒** (无情倒计时)。
* **操作流**：
    1.  屏幕出现词汇（如“香蕉”）。
    2.  玩家在画布上狂画。
    3.  **T+3s**：系统强制保存当前画布快照 -> 清空画布 -> 立即显示下一题（如“月亮”）。
    4.  循环直到20题结束。
* **UI 特性**：
    * 无橡皮擦、无撤销、无颜色选择（仅黑色单线条）。
    * 任何犹豫都会导致画出一张白卷。

### 2.2 阶段二：硬核盲猜 (The Blind Recall)
此阶段不再提供词汇列表，玩家必须依靠记忆和识别能力。

* **数据处理**：
    * 将刚才的 20 对 `(Image, Answer)` 数据顺序彻底打乱。
* **玩法逻辑**：
    1.  屏幕中央显示一张刚才的画作（可能是几根抽象的线条）。
    2.  **输入框**：玩家必须手动输入答案。
    3.  **提交**：按下回车键或点击“确定”。
    4.  **判定**：
        * **正确**：显示“回答正确！”，切到下一张。
        * **错误**：输入框抖动，提示“不对哦”。
    5.  **放弃/跳过**：实在猜不出，可点击“我看不到懂”/“跳过”，系统公布正确答案，判为错误。

## 4. 核心算法逻辑 (Core Algorithms)

### 4.1 模糊匹配 (Fuzzy Matching)
盲猜模式下，必须允许玩家有轻微的输入误差，否则体验极差。

* **标准化 (Normalization)**：
    * 忽略空格（`赛 车` = `赛车`）。
    * 忽略大小写（英文模式）。
* **同义词库 (Synonyms)**：
    * 题目若是“单车”，玩家输入“自行车”应判对。
    * 题目若是“电脑”，玩家输入“计算机”应判对。
    * *数据结构示例*：
        ```json
        {
          "id": 12,
          "primary": "自行车",
          "synonyms": ["单车", "脚踏车", "bike"]
        }
        ```
* **容错 (Levenshtein Distance)**：
    * 针对英文：允许 1-2 个字母的拼写错误（如 `Piza` -> `Pizza`）。
    * 针对中文：通常要求精确，或仅允许同音字（实现较复杂，通常建议仅做同义词匹配）。

### 4.2 评分规则 (Scoring)
* **基础分**：每题 100 分。
* **连击加成 (Combo)**：连续答对加分。
* **错误扣分**：
    * 一次猜中：100分。
    * 错误1-2次后猜中：80分。
    * 错误3次以上猜中：50分。
    * 点击“认输”：0分。

## 5. 词库设计规范 (Word Dataset Constraint)
因为是盲猜，词库的难度控制是游戏生死的关键。

* **Tier 1 (极简具象)**：
    * 苹果、伞、剪刀、鱼、花、云、眼镜。
    * *特点*：3秒内能画出特征，且特征具有唯一性。
* **Tier 2 (稍微抽象 - 慎用)**：
    * 风、火、爱心、鬼、外星人。
    * *风险*：容易和别的搞混（例如“火”和“草”在3秒画出来很像）。
* **禁区 (绝对禁止)**：
    * **动作**：跑、跳（3秒画不出动态）。
    * **具体地名/人物**：北京、成龙。
    * **复杂机械**：挖掘机、直升机。
