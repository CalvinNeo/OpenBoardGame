# 喜爱标签

支持 Filter 菜单，其中包含不同的 filter 项目：
- Players，即支持游玩人数
- Favor，即标注的喜欢的游戏
- Types，即游戏的标签，一个游戏可以有多个标签。

在游戏列表的右边，增加一个星星的图案，存在选中和非选中两种情况，表示是否喜欢这个游戏。这个记录存在本地，支持在 Settings 里面复制备份到剪贴板、从剪贴板粘贴导入，和玩家是解耦的。

## 实现

- Select Game 顶部保留搜索和 Sort，Filters 下拉菜单统一提供 Players、Favor（Favorites only）和 Types，无需再次展开 Types。菜单显示启用的人数、收藏和类型标签总数；收藏、人数、搜索、Types 标签按交集筛选，现有排序不变。Players、Favor、Types 的选中状态实时保存在当前浏览器 `localStorage` 的 `openboardgame:game_filters`，重新打开、刷新或同浏览器重新进入页面后恢复；取消选择也会保存。搜索词仍在重新打开时清空，菜单默认收起，排序沿用原有独立记忆。
- 筛选偏好与玩家身份解耦，不随改名或退出登录清除，也不写入收藏备份。无记录或记录损坏时使用默认筛选；非法人数、非布尔收藏标记和当前目录已不存在的类型标签不会生效。浏览器存储不可写时仍保留当前标签页内的选择，不影响筛选操作。
- Filters 展开区域桌面端最大宽度为 560px，手机端占满控件区域可用宽度，Types 按三列排列。展开区域限制高度并支持内部滚动，避免遮出弹窗或横向溢出。
- 每个游戏右侧提供独立的 ☆ / ★ 按钮，收藏操作不会触发游戏选择或创建房间。按钮支持 Tab、Space、Enter 与 `aria-pressed`，使用游戏名称提供可访问标签；取消收藏后立即更新仅收藏列表，并保留合理的键盘焦点。普通列表切换收藏不重建列表、不改变滚动位置，手机滑动星标区域只滚动、不切换收藏。
- Filters 点击菜单外关闭；Escape 优先关闭 Filters，再次 Escape 关闭 Select Game。Settings 保留 Escape、遮罩关闭和键盘焦点循环。
- 收藏存放于 `localStorage` 的 `openboardgame:favorite_games`，内容为去重后的 game_id 数组，与姓名、房间凭证、玩家 ID 无关；改名、退出登录不会删除收藏。同源其他标签页的收藏变化会同步到当前打开的游戏列表。
- Settings → Favorite games 提供 Copy backup 与 Paste & import。备份直接将 JSON 写入剪贴板，导入优先直接读取剪贴板；浏览器不支持或拒绝读取时展开粘贴框，支持快捷键或手机长按粘贴后点击 Import，不要求 HTTPS 或 localhost 才能导入。无文件下载或选择，仅包含收藏，不包含身份、凭证或其他设置。格式如下：

```json
{
  "type": "openboardgame:favorites",
  "version": 1,
  "game_ids": ["azul", "cabo"]
}
```

- 导入采用合并语义，不删除原有收藏，重复 ID 自动去重。空备份不清空已有收藏；尚未出现在当前游戏目录中的合法 ID 保留，便于跨版本恢复。
- 剪贴板内容最多 1 MiB、最多 10000 个 ID；ID 必须是长度 1–100 的小写字母、数字、下划线或连字符，且以字母或数字开头。空剪贴板、格式错误、版本不支持或内容非法时提示错误，不修改现有收藏。
- 复制复用公共剪贴板兼容逻辑，支持浏览器复制回退；自动读取是否可用由浏览器决定，不可用时进入手动粘贴流程。两条导入路径共用格式校验和合并逻辑；Cancel 或关闭 Settings 清空粘贴框，导入失败保留已有收藏。
- 损坏的本地记录按空收藏处理。浏览器存储不可写时，收藏继续保存在当前标签页内存中，并在 Settings 提示备份，避免影响游戏和房间操作。
