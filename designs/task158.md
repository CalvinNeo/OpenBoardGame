# Task 158：柯尔特快车（Colt Express）

## 实现范围

实现基础版标准 3–6 人玩法，每人控制一名匪徒，支持真人与机器人混合房间。完整进行五轮「策划 → 执行 → 事件 → 回顾」，最终以战利品加神枪手奖励决定胜负。本次不含扩展、专家弃牌模式与双人双角色变体；Help 明确说明人数和范围。使用原创 CSS 列车、颜色和 Emoji，不使用商业插画。

## 玩法

- 六名角色各不重复：Ghost、Doc、Tuco、Cheyenne、Belle、Django；落实隐藏首张行动、多抽手牌、垂直射击、可选偷取钱袋、目标保护、击退等能力。使用对应角色颜色与 Emoji，Ghost 首个策划机会选择抽牌就失去本轮隐藏能力。
- 车头加与玩家人数相等的车厢，均分车顶和车内；警长从车头开始。匪徒交替从末节与倒数第二节车内出发，各持一个 $250 钱袋及十张行动牌、六发子弹。
- 每轮重新洗混自己的行动牌与已收到的子弹，抽六张（Doc 七张）。3–4 人、5–6 人各有七张普通回合牌，从对应牌组随机取四张，再加随机一张终点牌。按回合牌逐回合策划：打出行动牌或抽三张；包含公开、隧道隐藏、双行动与逆序回合。子弹占手牌但不能打出；策划结束后未打出的手牌放回自己的牌库。隐藏牌在执行前任何人都不能重新查看。
- 策划完成后依照打牌顺序逐张执行。玩家在执行时选择合法目的地、射击目标、战利品或拳击对象与击退方向；无合法目标时显式确认落空。行动涵盖移动、爬升／下降、抢劫、射击、拳击、移动警长。允许且必须执行的动作不能任意跳过。
- 车内移动一节、车顶移动一至三节；车内射击相邻车厢、车顶只击中每侧最近有人的车厢；警长使同车厢内的匪徒收到中立子弹并逃上车顶。拳击使对手掉落指定类型的战利品并移到相邻车厢。
- 钱袋金额保持私密；宝石 $500、保险箱 $1,000。牌库顺序、他人手牌、未公开行动和未来回合牌不得泄漏到视图、机器人事件或存档加载入口。机器人只依据自己的个人视图选择行动。
- 第五轮结束后加上 $1,000 神枪手奖励；开枪最多者并列均获奖励。总钱数相同按收到子弹较少者优先，仍平则共享胜利。
- 普通事件包括愤怒的警长、紧急刹车、全部拿走、乘客反抗、摇臂吊车；终点事件包括警长的复仇、扒窃、劫持列车长。扒窃先让符合条件的玩家逐人选择当地钱袋或放弃，再进入回顾。警长复仇将最低金额钱袋掉到原车顶。中立子弹总计十三张，不够给同一批所有目标时该批都不发子弹，驱赶照常执行。

## 回合与交互

所有执行步骤单独广播，展示行动者、当前行动、结果日志与下一位玩家。每轮结算后保留棋盘与本轮事件摘要，突出与本人有关的记录；全部玩家点击 Next Round 后才开始下一轮，最后一轮同样先回顾再公布总榜。机器人自动确认，但不能越过真人屏障。

动作带游戏标识和递增行动窗口，拒绝跨局与过期请求；非法动作不得改变状态。所有随机结果由服务器生成并随存档保存，重连保留完整进度。

## 前端要求

严格遵守 `FRONTEND.md` 与 `designs/task40.md`：

- 新建 `static/games/colt_express.js`、`.css`、`.html`；脚本使用 IIFE，公开入口带独有前缀。通过 `static/game_assets.js` 注册独立 CSS、模板和脚本，首页仅留空挂载点，更新加载器版本。
- 主界面以列车为中心，暖木色车厢、夜蓝车顶、角色色与 Emoji 表示位置。桌面棋盘与操作区相邻，手机将车厢分行重排且标明前后顺序，保证 320px 宽度无溢出。行动队列与日志局部滚动。
- 主面板仅放简短当前阶段提示；完整规则集中在 Help。Explain 拦截原动作、支持灰色按钮、无说明按钮不执行，解释后退出，Esc 退出。
- 图标与文字在说明中配套，如钱袋（💰）、宝石（💎）、保险箱（🧳）、子弹（🔫）、警长（⭐）。无动作的指标支持鼠标悬停／手机点击三秒浮动提示。
- 手牌及目标点选后在原位置确认；空白与 Esc 取消，不引入 Clear Selection。Next Round 不重复确认。通用界面控件使用英文，游戏内容中文。
- 轮到玩家且 Room Controls 隐藏时显示红色提醒；初始化兼容 DOMContentLoaded 已发生，并同步当前房间及最新游戏状态。

## 核对资料与数据边界

- [官方产品页](https://www.ludonaute.fr/en/produit/colt-express/)链接的[英文基础规则](https://www.data.ludonaute.fr/Colt_Express/RULES/Colt_Express_Rules_2016_EN.pdf)：基础流程、角色、事件、神枪手、平局以及专家与双角色变体的区别。
- [官方卡牌文件](https://www.data.ludonaute.fr/Colt_Express/CONTENTS/CARDS/Colt_Express_Cards_BACK.pdf)第 110–126 页：逐张核对十四张普通回合牌及三张终点牌的回合类型与事件。所有终点牌的序列均为公开、公开、隧道、公开。
- [官方六车厢展示图](https://www.data.ludonaute.fr/Colt_Express/SPREAD_DISPLAY/Colt_Express_6WAGONS_Train.png)：逐厢核对地板标记。六种车厢的（钱袋数、宝石数）为 `(1,0)、(1,1)、(0,3)、(3,0)、(4,1)、(3,1)`，合计十二个钱袋、六颗宝石；开局随机选取与人数相同的车厢并排列。
- 官方规则可核实十八个钱袋、金额为 $250–500，但公开材料未能逐枚确认各面额频数。因此本实现明确采用线上配比：$250×8，$300／350／400／450／500 各两枚；先扣本局玩家各一个 $250 起始钱袋，再从余下钱袋随机放入车厢。该配比不宣称为已核实的实体逐枚复刻，游戏 Help 同时说明。
- [BGG 条目](https://boardgamegeek.com/boardgame/158899/colt-express)已加入查询脚本。2026-10-15 运行 `python3 scripts/bgg_weight_scrape.py --timeout 3 --out build/colt-express-weights.json`，查询到 `averageweight = 1.8335`，目录显示 `1.83`。
