# Design 3.1: Draw & Guess (Telestrations-style)

## Rule Summary
- Each player receives a random prompt (word or short phrase).
- Round 1: everyone draws their prompt and submits a drawing.
- Round 2: everyone guesses the drawing they receive and submits a word.
- Round 3: draw again from the new word; repeat the same pattern.
- After each round, each booklet passes to the next player in seat order.
- The final round must be even (a guess round). The final guess is compared to
  the original prompt.

## Round Count Logic
- Let N be the number of players. Round 1 is always a draw round.
- total_rounds = N if N is even, else N - 1.
- Round parity: odd => draw, even => guess.
- When N is odd, each booklet skips the last seat so the last round is a guess.

## Draw & Guess State

### State (DrawGuessGame)
- players: {player_id -> {}} (per-player status)
- turn_order: list[player_id] (seat order)
- round: int (1..total_rounds)
- total_rounds: int
- phase: draw | guess | review | game_over
- submissions: {player_id -> Submission}
- books: {owner_id -> Book}
- config: {language?, prompt_pool?}
- player_meta: {player_id -> {name, seat, is_bot}}

### Book
- owner_id: player_id
- entries: list[Entry]

### Entry
- round: int (0 for initial prompt)
- type: prompt | guess | drawing
- author_id: player_id
- text: string | null
- image_data: data URL string | null
- hint: string | null (server-only, not exposed in public view)

### Submission
- type: drawing | guess
- text: string | null
- image_data: data URL string | null

### PromptEntry
- text: string (displayed to players; can be zh or en)
- quickdraw: string | null (English category alias used by bots)

### Prompt Pool Additions
- Expand default prompts with more common nouns (animals + objects).
- Add matching zh translations in `game/draw_guess_prompts.py` for the same items.

### Book Assignment Rule
At round r, the player at seat index i works on the booklet owned by:
- owner_index = (i - (r - 1)) mod N
- book_id = turn_order[owner_index]

## Actions
- submit_drawing {type:submit_drawing, image_data}
- submit_guess {type:submit_guess, text}

### Validation
- The action must match the current phase (draw or guess).
- Only one submission per player per round.
- image_data or text must be non-empty.

## Flow
1. init_game:
   - Load and shuffle prompt pool based on config.language (default en).
   - Assign one prompt per player and create a book per player.
   - Each book starts with Entry(round=0, type=prompt).
   - round=1, phase=draw, submissions={}.
2. submit (draw/guess):
   - Store the submission under submissions[player_id].
   - When all players have submitted:
     - Append each submission to its current book.
     - For drawing entries, capture the source text as hint for bot recognition.
     - If round == total_rounds, phase -> review, game_over=true.
     - Otherwise round += 1, phase toggles, submissions cleared.
3. review:
   - Public view includes the full book chains.
   - Compute final_guess vs original prompt (trim + casefold equality).

## Public View
- phase, round, total_rounds, you
- current_task: draw | guess
- current_input:
  - draw: prompt text (round 1) or previous guess text
  - guess: image_data for the current drawing
- submitted: bool for the viewer
- players: list[{player_id, name, seat, submitted}]
- review (only in phase review):
  - books: [{owner_id, owner_name, entries, final_guess, prompt, final_match}]

## Bot Behavior (MVP)
- Draw phase: use the Quick, Draw! dataset via the `quickdraw` library to fetch
  a random line drawing for the closest category match. QuickDraw categories
  are English-only, so bots use the PromptEntry.quickdraw alias (or English
  prompt text) when language=zh. If no category matches or the library is
  unavailable, fall back to a simple SVG template sketch.
- For unknown zh prompts, attempt offline zh->en translation (Argos Translate
  or similar) before matching QuickDraw categories. If translation is not
  available, fall back to the SVG template sketch.
- Prompt salting: inject random adjectives/actions into the prompt (e.g.
  "jumping chubby cat") to vary the random seed, leading to different drawings
  and placement/rotation.
- Guess phase: attempt to recognize drawings using the stored hint from the
  drawing entry, with a small chance to guess randomly to keep it imperfect.

### Offline Translation Setup
- zh->en translation uses Argos Translate (offline). Models must be installed separately.
- Option A (if `argospm` is available): `argospm update && argospm install translate-zh_en`
- Option B (Python):
  ```python
  import argostranslate.package

  argostranslate.package.update_package_index()
  packages = argostranslate.package.get_available_packages()
  package = next(p for p in packages if p.from_code == "zh" and p.to_code == "en")
  download_path = package.download()
  argostranslate.package.install_from_path(download_path)
  ```
