# 问题1

我有几个需要确认的问题，避免实现时跑偏：

- 多人局里 current_round 是全局轮次（每人走一回合才+1），还是每个玩家各自的回合计数？
- 总分相同如何处理？允许平局，还是加赛/其他判定？
- Yahtzee 计分项如果曾被记为 0 分，之后再掷出 Yahtzee 时：是否完全按“普通回合”处理（无 100 奖励、无 Joker 规则）？
- “5 个全同也算葫芦”这条是否适用于非 Joker情况下的正常计分选择？
- 小顺/大顺是否允许有重复点数（例如 1,2,2,3,4 算小顺）？大顺是否必须 5 个点数全不同？
- Joker 规则里“对应上半区为空则必须填该项”是否是强制（不能改选别的项）？如果下半区全满，填 0 分是任选上半区空项吗？

# 回答1

以下是针对你提出的问题的标准官方规则解答，可以直接作为你代码逻辑的依据：

### 1. `current_round` 是全局轮次还是个人回合？
* **标准逻辑**：`current_round` 通常作为**全局轮次**来处理。
* **实现建议**：游戏固定进行 13 个全局轮次。在每 1 轮中，按顺序遍历玩家列表，每个玩家完成自己的一个回合（Turn）并填入一个计分项。当最后一个玩家完成回合后，`current_round` 才加 1。这样设计更符合真实的轮流掷骰体验。

### 2. 总分相同如何处理？
* **标准逻辑**：**允许平局**。
* **实现建议**：官方规则中并没有规定所谓的加赛（Tie-breaker）或优先级判定。如果游戏结束时有多人总分完全相同，直接判定为并列第一（Draw / Co-winners）即可。在结算 UI 支持显示多个胜者。

### 3. Yahtzee 曾记为 0 分，再掷出 Yahtzee 怎么处理？
* **标准逻辑**：**完全按“普通回合”处理，无奖励、无百搭（Joker）。**
* **实现建议**：如果你之前因为实在凑不出牌型，在“快艇 (Yahtzee)”项填了 0 分，意味着你主动放弃了本局触发快艇奖励的资格。之后即使掷出 5 个相同的骰子：
    * **不能**获得 100 分额外奖励。
    * **不能**触发 Joker 规则。
    * 它只是一个普通的骰子组合。玩家可以选择把它记入上半区（得分 = 点数 x 5），或是下半区的“三条”、“四条”、“机遇”（得分 = 点数 x 5），甚至是“葫芦”（官方允许 5 个相同算葫芦）。

### 4. “5 个全同也算葫芦”适用于非 Joker 时的正常计分吗？
* **标准逻辑**：**适用**。
* **实现建议**：官方规则明确指出，只要满足“3个相同 + 2个相同”，哪怕这 5 个点数全部一样，也是合法的“葫芦”（得 25 分）。所以，在正常回合中，掷出 `3,3,3,3,3` 绝对可以填入“葫芦”。
    * *算法提示*：在判断葫芦时，条件应当是“去重后的骰子点数种类数 == 2 **或** == 1”。

### 5. 顺子的重复点数与大顺的判定
* **标准逻辑**：
    * **小顺 (Small Straight)**：**允许有重复点数**。5 个骰子中，只要包含 4 个连续的点数即可。例如 `1, 2, 2, 3, 4` 算小顺（30 分）。
    * **大顺 (Large Straight)**：要求 5 个点数完全连续。因为一共只有 5 个骰子，所以**必然不能有任何重复点数**（只能是 `1,2,3,4,5` 或 `2,3,4,5,6`）。

### 6. Joker 规则的填表强制性与填 0 逻辑
* **标准逻辑**：**强制顺序，不能随意改选。**
* **优先级 1（强制上半区）**：如果该点数对应的上半区计分项**为空**，你**必须强制**填入该项。
    * *例子*：掷出 5 个 4，触发 Joker。如果你的上半区“四 (4s)”还没填，你只能乖乖把这 20 分填在“四 (4s)”里，不能去拿大顺的 40 分。
* **优先级 2（任选下半区）**：只有当对应上半区计分项**已被填过**（不管之前填的是正分数还是 0 分），你才能解锁下半区的百搭权限。你可以**任选**下半区的一个空项填满分。
* **优先级 3（被迫填 0）**：如果对应的上半区满了，且下半区也**全部填满**，你必须在上半区剩下的空置项中**任选一项填入 0 分**。
