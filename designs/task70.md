# 桌游《问非所答》(Dumb Questions to Ask Your Friends) 电子版实现设计文档

你好！我已经学习了《问非所答》这款欢乐派对桌游的规则。这是一款通过“倒推问题”来考验朋友间默契与脑洞的游戏。为了方便你进行电子版（如网页端或微信小程序）的开发，我将规则拆解成了极其详细的系统逻辑和状态机。

## 1. 游戏核心设定
* **支持人数**：3 - 8 人（电子版可灵活支持至多人，但 4-8 人体验最佳）。
* **游戏类型**：社交推理、聚会、问答。
* **获胜条件**：游玩指定轮数（例如每人轮流当 1 次或 2 次“猜题者”），最终总分最高的玩家获胜。

## 2. 电子版数据模型 (Data Models)

### 2.1 玩家 (Player)
* `player_id`: 唯一标识
* `nickname`: 玩家昵称
* `role`: `GUESSER` (猜题者) 或 `ANSWERER` (答题者)
* `score`: 玩家当前总得分
* `current_answer`: 当前回合提交的答案（仅限答题者）

### 2.2 卡牌与题库 (Card & Category)
* **六大分类**：玩家 (Player)、数字 (Number)、生物 (Creature)、食物 (Food)、物品 (Item)、名人 (Celebrity)。
* `card_id`: 卡牌唯一标识
* `category`: 所属分类
* `question_text`: 问题文本（例如：“如果在场的人必须吃掉其中一个人，大家会先吃谁？”）

### 2.3 分数板 (Score Board)
* 长度为 5 的数组，索引对应分值 `0, 1, 2, 3, 4`。
* `0` 代表“最不可能是这道题”，`4` 代表“最可能是这道题”。
* 状态：每个槽位初始为空，被放入卡牌后即 **锁定(Locked)**。

## 3. 游戏阶段与玩法流程 (核心状态机)

电子版的游戏进程可严格按照以下状态机运转：

### State 1: 房间准备阶段 (Lobby)
* 房主创建房间，其他玩家加入。
* 人数满足条件后，房主点击“开始游戏”。
* 系统初始化玩家分数，决定本局的轮数，并随机选定第一回合的 `GUESSER`（猜题者）。

### State 2: 选题阶段 (Category Selection)
* **UI 展示**：只有 `GUESSER` 的界面可以操作，其他玩家显示“等待猜题者选择题目类型...”。
* `GUESSER` 从六大分类中选择 1 个分类。
* **系统后台**：从选定分类的题库中，随机抽取 **5张卡牌** 组成“本轮回合牌库 (Round Deck)”。系统将其中的 **第1张** 标记为“目标问题 (Target Question)”。

### State 3: 答题阶段 (Answering)
* **系统动作**：向所有 `ANSWERER` 展示“目标问题”。`GUESSER` 界面进入黑屏或遮挡状态（显示“大家正在作答，请闭上眼睛/耐心等待”）。
* **玩家动作**：所有 `ANSWERER` 必须诚实地根据自己的真实想法，在输入框中输入答案并提交。
* **注意**：游戏规则强调必须说出真实想法，用真实的奇葩逻辑去引导（或误导）猜题者。
* 当所有 `ANSWERER` 均提交答案后，系统自动进入下一阶段。

### State 4: 猜题与放置阶段 (Guessing & Ranking) - 核心机制！
* **系统动作**：
  1. 将“本轮回合牌库”的 5 张卡牌 **彻底打乱 (Shuffle)**。
  2. 在界面上方展示所有 `ANSWERER` 提交的答案。
  3. `GUESSER` 界面恢复可视。
* **玩家动作 (GUESSER)**：
  1. `GUESSER` 点击“翻开下一张牌”。系统从打乱的 5 张牌中展示 1 张。
  2. `GUESSER` 结合上方朋友们的答案，判断这张牌是“目标问题”的概率。
  3. `GUESSER` 必须将这张牌拖拽或分配到分数板 `0, 1, 2, 3, 4` 的一个**空槽位**中。
  4. **硬性规则**：一旦放置，**不可更改！**（这就构成了推断与风险评估的博弈，比如玩家觉得这张很像，放在了4，结果下一张翻出来更像，但4已经被占用了）。
  5. 重复上述步骤，直到 5 张牌被一一翻开并填满 5 个槽位。

### State 5: 结算阶段 (Scoring)
* **系统动作**：
  1. 揭晓真正的“目标问题”是哪一张卡牌。
  2. 检查“目标问题”被 `GUESSER` 放置在了哪个槽位。
  3. **计分**：`GUESSER` 获得该槽位对应的分数（0分、1分、2分、3分 或 4分）。（可选变体规则：如果放在了 4 分，答题者也能获得 1 分奖励以鼓励认真作答，但原版规则仅猜题者得分）。
* 结算页面展示几秒后，轮换下一位玩家成为 `GUESSER`，回到 State 2。
* 当所有人都当过指定次数的 `GUESSER` 后，游戏结束，展示最终排行榜。

## 4. 无法获取的游戏资源清单

作为 AI，我为你梳理了规则并设计了系统架构，但在你的实际开发中，你必须自行准备以下资源（我无法直接提供）：

1. **原版卡牌题库数据 (Question Text DB)**
   * 你需要自己撰写脑洞大开的问题（例如：“最不适合在葬礼上播放的歌曲是什么？”“如果世界上所有动物体型都一样大，哪种动物最可怕？”）。
2. **游戏美术与视觉素材 (Art Assets)**
   * 包含六大分类的图标（玩家、数字、生物、食物、物品、名人）、卡牌背面图案、0-4分的分数板 UI 设计、以及游戏内背景音效和动画特效。
