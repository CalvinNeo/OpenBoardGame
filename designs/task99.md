# Task 99 — 永恒牌 / Eternal Decks

## 范围与依据

在现有房间系统中新增 `eternal_decks`，直接实现一个可从开局玩到共同胜负的 Stage A / Beginner。规则以本仓库 `designs/task83.md` 的整理为依据，交叉参考[作者规则文件页](https://boardgamegeek.com/filepage/289015/eternaldecks-english-rulebooks)和[发行商页面](https://www.pixiegames.fr/jeux-connaisseurs/2208-eternal-decks-3701358301708.html)。

数据边界必须在房间配置、游戏桌面和 Help 中明确：`Prototype card data`。公开资料未能核实第四版每套永恒族的八张牌，本次使用独立、明确标注的测试牌表，不能称为正式完整复刻。开放 2 或 4 个席位（可加机器人）；3 人专用六宝石图尚未核实，因此拒绝三人开局。Stage B–F、进阶难度和实体单人故事模式本次不开放，不放无效入口。后续可替换独立数据文件而不改规则引擎。

## 规则与状态机

- 四色起始牌各 1–5，开局手牌三张；两人局各增加两个随机副色牌到牌库底。每次回合末补到三张，不洗回弃牌、不强制弃掉超额手牌。
- 开局可以看自己的手牌、用两个交流圆片表达意图、选择起始玩家；全员 Ready 后开始依座位轮转。
- 山地／洞穴／营地三行各七格，普通相邻牌不同色、不同数；山地严格递增、洞穴严格递减。双色牌落地固定方向；Rare 本次落位不受场地限制，以后按能满足限制的通配牌处理，9／1 后允许继续 Rare。历史已合法的牌不被追溯移走。
- 场地、河流或能力三种出牌目的地；另外可以消耗一心暗中给队友一张牌，或使用未消耗的宝石配方。服务端验证所有权、阶段、资源、目标和组合，错误动作不改变状态。
- 每行前三圈分别填四、五、六张，当前玩家选择复苏该行一个永恒族，得到其八张牌到个人牌库底；行内牌弃掉，诅咒立即激活。第四圈七张后关闭，依上中下获得营地、恢复三心、星星。营地奖励可更换另一未关闭行的场地。
- 实现九个 A1–C3 的诅咒与能力：A 系收集三张得星；幽灵公开手牌直到全员点击 End Discussion（该窗口仍属于使用者回合）；骷髅恢复一心；女巫免费生成非 1/5/9 宝石；美杜莎回收弃牌 Rare；牛头人换取场地牌、自己作 Rare；海怪取回河流最多两张。
- 八种宝石配方，含双色／Rare 的颜色数字匹配；用掉的牌进入河流并给复苏者宝石、停用对应诅咒。河流达到五张只结算一次并全部清空，前三次得 Rare，下一次 Game Over。生成宝石可越过五张。
- 六个星星来源分别只触发一次，取得四星获胜；同回合胜利优先于河流失败。只在当前玩家开始行动时判断其无主行动可做，不因其他人暂时空手提前失败。
- 每一整圈，以及复苏、河流奖励、星星和第四圈奖励后进入 `round_end`，保存结算展示（已清理的牌仍能回顾）；所有真人和机器人分别点击 Next Round 后才开始下一轮。掉线玩家不自动确认。最终共同胜负持续展示。

## 联网、隐私与机器人

使用仓库接口 `init_game` / `get_legal_actions` / `apply_action` / `get_public_view` / `bot_move` / `serialize` / `deserialize`。牌实例采用随机无语义 ID；他人只见手牌数量，所有牌库只见数量；不发送 seed、洗牌顺序、暗中传递的牌或私有动作参数。沉睡角色的牌组构成公开，但没有实例 ID 或顺序。幽灵公开窗口结束后立即收回视图权限。深拷贝保存和恢复，确定性 seed 用于回归。

机器人仅通过与真人相同的裁剪视图决策，优先复苏、解咒和场地推进，必要时入河或传牌；只确认自己的 Ready / Next Round。交流圆片是免费动作，可以随时移动自己的两个圆片，附递增序号，不能修改别人圆片，不刷日志。

## 前端（遵守 FRONTEND.md 与 task40.md）

- 新增 `static/games/eternal_decks.js`（IIFE 私有作用域，仅导出 EternalDecks 前缀接入函数）与 `static/eternal_decks.css`；`app.js` 只接入面板与渲染分发。
- 原创深绿／米白桌面、数字牌、Emoji 和颜色：🔴🔵🟢🟡🟣、💎、⭐、❤️；不使用商业图片。卡牌有文字颜色说明，双色牌显示方向。
- 桌面三行棋盘加侧边行动区；手机每行仍保留七格关系，缩短格内内容，角色详情移到下方换行排列。所有网格允许收缩，长名字换行；禁止页面横向滚动、内容溢出和容器重叠。
- 单击选牌再点目标并确认；宝石自动列出合法选牌组合，能力选择目标也全部使用可读按钮，无 JSON 输入。空白／Esc 取消，没有 Clear Selection。通用 UI 使用英文。
- Help 使用原生 dialog，Esc／遮罩／Close 退出；Explain 捕获并阻止其他操作，仅有说明控件显示虚线和问号，disabled 按钮通过 pointerdown 坐标仍可解释；解释后退出。
- 手牌、当前玩家、心、星星、河流奖励危险状态和诅咒清楚可见；日志和弃牌区限高滚动；结算区域原位展开，显示确认人数与等待玩家。
