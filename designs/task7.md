# 实现《出包魔法师》

## Subgoal 1

- 搜索互联网，找到《出包魔法师》（Abraca...what?）基础版的游戏规则。你不需要包含任何 DLC。你需要将规则输出到 7.rule.md。
- 规则需明确：游戏人数/时长/目标、组件清单与数量、8 种法术的名称/数量/效果、骰子点数范围、生命上限、回合流程（喊招、连招限制、反噬、补牌）、回合结束与计分/胜利条件、平手处理、回合结束后的重置逻辑（魔法石回收/洗牌、生命值恢复、猫头鹰结算等）、玩家数差异（如有）。
- 你需要设计：
    + 公开区域：计分塔/层数、弃牌区（按法术分类或统一）、牌堆剩余、备用猫头鹰/特殊区域
    + 玩家区域：生命值、分数指示物、面前可见魔法石、自己不可见信息的展示方式、已获得的猫头鹰魔法石
    + 行动区域：选择法术喊招、是否继续连招、掷骰/结算提示
- 你需要明确隐藏信息与视角规则：玩家只能看到他人手牌，自己的手牌应为未知/背面；服务端与前端如何区分。
- 如果无法找到法术图片素材，需要用简化图标/文字版样式占位。

## 2026-11-24 Activity 与轮末 / 终局结算

- 服务端保存每轮全部施法猜测：玩家、法术、成功 / 反噬、骰子结果和回合序号。骰子结算更新原猜测，不重复增加记录；非法行动不写入。每轮结束将猜测与计分、剩余手牌快照归档，新轮仅清空当前记录。
- Activity 保持次要、可折叠、限高滚动；按轮分组，每位玩家的猜测按时间顺序排成一行，长行只在自身内部横向滚动，不撑宽页面。法术编号、图标、颜色与主板一致，✓ / × 分别表示成功 / 反噬，🎲 表示骰点。玩家采用颜色 + 形状 + 姓名，自身条目加深；悬停 / 手机轻点提供完整法术与回合说明，拖动滚动不会触发提示或行动。
- 每轮结束切换为内联结算页，隐藏施法区，公开所有玩家的剩余手牌（含自己的手牌），显示轮末生命、基础奖励、存活秘密卡奖励、本轮合计、累计总分。秘密卡内容仍仅本人可见；已公开的历史手牌不会泄露新轮手牌。
- `start_next_round` 改为个人确认：全员确认后才重置手牌与生命、从结束本轮玩家的下家开始。Bot 自动确认；纯 Bot 对局由本轮行动者完成最后一次自动推进。重复确认、旁观者确认和结算阶段非法行动均被拒绝，刷新重连与 JSON 存取保留确认进度。
- 终局结算保留亮牌，并逐轮列出基础奖励、秘密卡分与累计总分，标出胜者，说明达到目标分者按末轮得分破同分。旧存档没有的逐轮明细不补造，已知明细之外的分数标为 Earlier rounds (legacy save)。
- `play_again` 先记录每位真人的 Confirm Results；全部确认后仍停留终局，才启用 Play Again。再次点击才以原配置重开。Room Control 的 `room:start` 在本游戏终局同样走确认流程，不能绕过全员确认。Bot 在终局自动确认，不依赖已停止的房间 Bot 循环。
- Help / Explain 更新说明；Next Round 不增加二次确认；结算是内联页面而非强制弹窗，不影响 Help / Explain 的 Escape 行为。

## 专用 AI 与游戏目录标记

- `game/abraca_what_ai.py` 只接收当前座位的 `get_public_view`：利用其他玩家公开手牌、弃牌计数和自己的秘密卡扣除已知牌，不读取自己的暗牌、牌堆顺序、公共秘密池内容或他人的秘密卡。
- 根据不放回抽样的超几何分布推断施法成功率。本回合成功施放的公开记录 `turn_spells` 作为条件，通过组合数动态规划计算连续施法的后验概率，避免把成功出牌后剩余手牌误当成全新的随机抽样。记录在换人、轮末和新一轮重置；旧存档没有记录时兼容使用最近一次公开成功记录。
- 在当前回合内搜索最多五次后续施法，与主动停手比较：遵循法术编号不递减的限制，计算所有法术效果、巨龙反噬及治疗的三个骰面、邻座伤害、击杀、打空手牌、猫头鹰存活奖励和达到目标分后的本轮得分平手规则。
- 非终局评价兼顾生命、秘密卡收益、对手领先程度和补牌机会；这是有界回合内期望搜索，不是全局最优求解。搜索中的未来猫头鹰只估算得分，实际拿到秘密卡后用新的合法视图重新推断。
- 策略确定性运行，不修改游戏状态或全局随机数状态；支持掷骰、查看秘密卡、补牌结束回合和下一轮等阶段。
