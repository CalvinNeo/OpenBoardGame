# Task 188：女巫坩埚（Witch's Cauldron）

## 1. 游戏概述

- **中文名**：《女巫坩埚》 ｜ **英文名**：Witch's Cauldron
- **设计师 / 发行**：甄大爆 ZDBgames（摩点众筹，2026 年 8 月开众筹，10 月结束，11 月发货）
- **人数**：2–7 人 ｜ **时长**：15–20 分钟 ｜ **机制**：轮抽（Drafting）+ 手牌管理 + 心理博弈
- `game_id = witch_cauldron` ｜ `turn_mode = simultaneous`（圈内心跳按顺位推进，但每位玩家的提交互不可见）

玩家是一群炼药的女巫。每圈先从中央牌库轮抽一张药材，再从两张手牌里打一张——**可以放进自己的坩埚，也可以塞进别人的坩埚**。红色药材烈性高，蓝色药材毒性高；一锅汤药红蓝越接近越好喝，差值太大就会**炸锅**（红过高）或**中毒**（蓝过高）。累计两次就出局。

## 4. 开局准备

1. 选一位"看起来最有秘药炼制经验"的玩家作为起始玩家。
2. 洗混**全部**卡牌（药材 + 特殊卡混在一起），给每位玩家发 2 张。
3. 每位玩家从 2 张里选 1 张**正面朝上**放在自己面前，作为自己坩埚牌堆的"汤底"；另一张作为起始手牌。
4. 其余卡牌面朝下放在中央，作为"中央牌库"。

## 5. 回合流程

游戏由若干**轮（Round）**构成，每轮由若干**圈（Circle）**构成：

- **2–5 人局：每轮 4 圈**
- **6–7 人局：每轮 3 圈**

### 5.1 一圈

1. **卡牌轮抽**：从中央牌库顶翻开 `当前存活玩家人数 + 1` 张牌正面朝上摆开；从起始玩家开始顺时针，每位玩家选 1 张加入手牌。最后剩下的 1 张进入弃牌堆。轮抽结束后每位玩家手上应有 2 张。
2. **下锅**：从起始玩家开始顺时针，每位玩家从 2 张手牌里打 1 张，**可以放进自己的坩埚牌堆，也可以放进任意一名对手的坩埚牌堆**；可选择正面朝上或暗置。
3. 一圈结束，起始玩家标记顺时针传给下一位玩家，开始下一圈。

### 5.2 明牌图标

卡面左上角有两种图标：

- **强制明牌图标**（除变色龙尾巴外的所有特殊卡）：这张牌打进**任何**坩埚都必须正面朝上。
- **箭头图标**（数值 4、5 的药材卡）：这张牌打进**其他玩家**的坩埚时必须明牌；打进**自己**的坩埚不受限制，可以暗置。

其余牌（数值 0–3 的药材）可以自由选择明置或暗置。玩家**不能随时查看自己面前暗置的牌**，所以带记忆要素。

### 5.3 轮末结算

1. **加不加**：每位玩家手上还剩最后 1 张，可以选择加入自己面前的坩埚牌堆，或放入弃牌堆。

2. **换不换**：多名玩家达成口头协议，可以相互交换面前的整个坩埚牌堆。
3. **衔尾蛇结算**：在结算阶段开始前，所有坩埚里含衔尾蛇的玩家按顺时针交换坩埚牌堆。
   > 官方只说「结算阶段前」。电子版把它放在「换不换」之后、「喝不喝」之前，这样玩家是在看到最终归属的那一锅之后才决定喝不喝。
4. **喝不喝**：每位玩家公开宣布喝还是不喝。
   - **不喝**：面前所有卡牌直接进入弃牌堆，并拿取 1 枚拒绝指示物。**每场游戏每位玩家只有 1 次拒绝机会**，跳过后续结算。
   - **喝**：进入计分。
   - 坩埚里有**真名血契**的玩家必须喝，不能拒绝。

> **规则书未写明的部分（电子版采用的解释）**：官方规则图把「放置汤底牌」写在游戏流程 02，但只说明了开局那一次。如果第二轮开始时锅里是空的、手上也是空的，那么每圈轮抽后手上只有 1 张，「从两张手牌里打出一张」和轮末的「加不加」都会退化。因此电子版规定：**每一轮开始时，每位存活玩家重新拿两张牌，选一张正面朝上作为本轮的汤底，另一张作为起始手牌**，与开局的流程完全一致。这样每一圈的「二选一」和轮末的「加不加」在每一轮都成立。

## 6. 计分

同时翻开面前所有暗置的牌。

- 🔴 红色值 = 坩埚内所有红色药材数值之和
- 🔵 蓝色值 = 坩埚内所有蓝色药材数值之和
- 差值 = |红色值 − 蓝色值|

| 情况 | 条件 | 结果 |
| --- | --- | --- |
| 完美汤药 | 差值 = 0 | 坩埚内**所有药材**（红 + 蓝 + 中性）各记 1 分 |
| 安全红汤 | 差值 ≤ 3 且 🔴 > 🔵 | 所有**红色**药材 + 中性药材各记 1 分 |
| 安全蓝汤 | 差值 ≤ 3 且 🔵 > 🔴 | 所有**蓝色**药材 + 中性药材各记 1 分 |
| 炸锅 | 差值 ≥ 4 且 🔴 > 🔵 | 拿 1 枚 💥 爆炸指示物，不计分 |
| 中毒 | 差值 ≥ 4 且 🔵 > 🔴 | 拿 1 枚 ☠️ 中毒指示物，不计分 |

> 阈值以教学视频画面为准：红 7 / 蓝 4（差值 3）是安全红汤；红 9 / 蓝 4（差值 5）是炸锅。

**打扫厨房**：把计分的卡牌面朝下放在玩家面前作为计分牌堆（每张 1 分），不计分的卡牌进入弃牌堆。

**淘汰**：同一种指示物（爆炸或中毒）累计 2 枚即淘汰。1 枚爆炸 + 1 枚中毒仍然存活。

## 7. 游戏结束

达成以下三种条件之一时，游戏立即结束：

1. 其他玩家都因拿到 2 枚中毒或爆炸指示物而淘汰 → **唯一幸存的玩家获胜**。
2. 某一轮中所有存活玩家同时淘汰 → **无人获胜**（"大锅胜利"）。
3. 一轮结束后有玩家达到指定胜利分数 → 获得胜利。
   - **2–5 人局：≥ 7 分**
   - **6–7 人局：≥ 5 分**
   - 多人同时达标则分数高者获胜，分数相同则共享胜利。

## 8. 无法获取的资源与重建说明

1. **每种卡牌的具体张数**：官方只公布"基础药材 56 张 / 特殊卡 16 张"的总数，没有公布每种的张数。教学视频开箱画面里牌是扇形堆叠的，只能大致看出"数值越小张数越多、5 最少、衔尾蛇最多"。
   - 本实现按这个可见规律重建为：红蓝各 `1×6 / 2×6 / 3×5 / 4×4 / 5×3`（每色 24 张），虚空幽质 × 8，合计 56 张；特殊卡 `衔尾蛇×3 / 换汤不换药×2 / 变色龙尾巴×2 / 锅盖×2 / 真名血契×2 / 预言触须×2 / 潮汐引力石×1 / 噬火巨龙鳞×1 / 巨鲸凝毒脂×1`，合计 16 张。
   - 张数表集中在 `game/witch_cauldron.py` 的 `INGREDIENT_COUNTS` / `SPECIAL_COUNTS`，拿到实物后改一处即可。
2. **美术资源**：不使用官方插画（草木灰、炽热荆棘等卡面均为原创美术）。前端一律用 Emoji + CSS 自绘。
3. **众筹解锁的整活卡**（英语课本 English Book、狗狗罐头 Dog Food）与联动卡（《小鱼岛》《飞龙秘境》）不在基础版内，不实现。

## 9. 电子版实现要点

### 9.1 状态机

- `phase`：`setup`（同时选汤底）→ `playing` → `game_over`
- `stage`：
  - `draft`：轮抽阶段，`display` 是本圈翻开的 `n+1` 张，`draft_turn` 指向当前该选牌的玩家
  - `play`：下锅阶段，`play_turn` 指向当前该出牌的玩家，`pending` 记录本圈已出的牌
  - `add`：轮末"加不加"，所有玩家同时提交最后一张牌的去向
  - `swap`：轮末"换不换"，需要双方确认的交换
  - `drink`：轮末"喝不喝"，所有玩家同时公开宣布
  - `scoring`：结算展示，全员点 Next Round 后进入下一轮

### 9.2 结算顺序

喝下之后按固定顺序结算，任何一步都不会被跳过：

1. 变色龙尾巴：选择把红色值或蓝色值 −1（可以减到 −1）。
2. 计算红色值、蓝色值与差值，得出这锅原本的颜色（红 / 蓝 / 完美）。
3. 换汤不换药：如果不是完美汤药，红蓝对调。
4. 噬火巨龙鳞 / 巨鲸凝毒脂：按对调之后的颜色判定；两张同时存在则互相抵消。
5. 判定完美 / 安全 / 炸锅 / 中毒，并统计得分牌。

### 9.3 关键判定

- 服务端全量校验：轮抽只能选展示区里还没被拿走的牌；下锅只能打自己手上确实有的牌；锅盖封存后任何人都不能再加牌；拒绝指示物每人每局只能用一次。
- 明牌图标：`must_reveal`（特殊卡）与 `reveal_to_others`（数值 4/5）。服务端强制，玩家不能违反。
- 私有信息：手牌只有本人可见；暗置的牌对所有人（包括本人）都只显示背面；预言触须查看的结果只回给使用者。
- 交换（换不换）需要双方都提交同一对 `(from, to)` 才生效，服务端不代替玩家做决定。
- 种子只留在服务端：`witch_cauldron` 需要加入 `app.py` 的 `game_config` 过滤白名单。

### 9.4 Bot

本游戏不开发专门 AI（规则简单但强依赖心理博弈与记忆，Bot 收益低），因此 Select Game 页面不加 🤖 标记。
