# Task 182 — Chromino（缤纷多米诺）

## 范围与规则依据

- 实现标准 Chromino，支持 1–8 人、本地房间联机、机器人、重连与存档；单人使用相同放置规则练习。不加入 Junior / Expert 计分变体。
- 规则依据：[Board Game Arena 规则说明](https://en.doc.boardgamearena.com/Gamehelpchromino)。采用 BGA 经典规则版：保留可出的新抽牌、禁止万能末牌、末轮到最后一席。另已核对 [2025 英文官方规则书](https://cdn.svc.asmodee.net/production-zygomatic/uploads/2025/04/CHRO06EN_RULES_web.pdf)，其措辞与经典版有所不同，不混用新版结束轮/抽牌规则。共 80 枚直线三格牌：五种颜色所有首尾反转等价的 75 种普通组合，以及 5 枚中央为万能格的 Chameleon（变色龙）牌。
- 随机选一枚变色龙牌横放在中央，其余入袋；每人随机获得 8 枚隐藏手牌，随机先手，之后按固定顺序轮流行动。
- 每次放置一整枚牌，允许绕中格旋转 0° / 90° / 180° / 270°；不能重叠。与旧棋盘至少形成两条正交接触边，所有接触都必须同色或接触万能格。对角接触不计；两条边可以接触同一枚旧牌。万能格逐边匹配，不会永久变成某个颜色。
- 只有现有手牌完全无合法落点时才可抽 1 枚。抽到的牌可立即放置，也可保留并结束回合；此时不能改出原有手牌。抽到不可放的牌时自动保留并换人。袋空且无合法落点时可以 Pass。
- 仅剩 1 枚手牌时公开给全桌。变色龙牌不能作为最后一枚打出；只剩变色龙时必须抽牌（无牌可抽则 Pass）。
- 首位出完手牌者触发末轮，继续至当前轮最后一席，保证各玩家行动次数相同；本轮其他出完者并列获胜。最后棋盘保留，不自动重开。
- 防死局线上约定：袋空、连续所有席位均未放牌时结束，以剩余手牌最少者获胜（可并列）；单人此情形视为未完成练习。Help 和终局说明明确标注该约定。

## 服务端设计

- 新增 `game/chromino.py`，提供 `init_game`、`get_legal_actions`、`apply_action`、`get_public_view`、`bot_move`、`serialize`、`deserialize` 及 JSON Schema。
- JSON 状态包含牌目录、手牌 ID、牌袋、以 `x,y` 为键的稀疏棋盘、已放牌的中点/方向、行动序列、抽牌阶段、连续跳过次数、末轮标记、历史与结果。坐标允许负数，棋盘不采用固定边界。
- 服务端独立校验类型、所有权、当前回合、抽牌阶段、朝向、坐标、接触数及颜色；即使跳过 Schema 校验也不可绕过规则。拒绝的行动不修改状态。
- 枚举旧棋盘邻格及三个牌格对应的候选中点，复用同一校验器生成完整合法落点；发送给当前玩家，其他玩家和旁观视角不获得隐藏手牌与牌袋顺序。
- 抽牌事件只公开谁抽牌，不广播牌 ID / 颜色。最后一枚牌通过公开视图单独揭示。结算时公开剩余手牌。
- 机器人只根据自身手牌和公开棋盘行动，优先处理变色龙及难出牌、选择更多接触的紧凑落点；无牌可出时按规则抽牌或跳过。

## 界面与交互

- 按 `DEV_GUIDE.md` / `designs/task40.md` / `designs/room_control.md`：新增独立 `chromino.js` / `.css` / `.html`，在 `GAME_ASSETS` 按需加载，首页仅新增空面板并更新资源版本。
- Game 主体直接呈现彩色三格棋盘。桌面棋盘 + 侧边手牌；手机紧凑纵排，将手牌与落子确认紧邻棋盘，不引入横向页面滚动。牌使用 CSS / SVG 自绘，不使用商业美术。
- 五色同时带独立几何符号，万能格用星形；Help 同时列出颜色名与符号。玩家条显示轮到谁、手牌数、公开末牌；边缘显示袋中余量与可折叠、可滚动日志。
- 选手牌 → Rotate（以中格为重心）→ 点合法中点预览 → 原地 Confirm；点棋盘空白或 Esc 取消。不能出牌时 Draw / Pass；抽到可出牌时提供 Keep & Pass。
- SVG 棋盘支持 Fit / 放大 / 缩小 / 指针拖动；`touch-action: none` 仅限棋盘，拖动阈值区分点击与平移，pointer capture 处理区域外松手和取消，拖后不误选。其余页面保留正常滚动。
- Help 展示完整规则，Explain 采用捕获阶段拦截，解释目标虚线高亮，disabled 控件亦可解释；一次解释后退出，Esc 退出；无解释的操作在 Explain 模式不执行。弹窗可 Esc 关闭。
- 无交互的状态/颜色图标支持桌面悬停及手机轻触 3 秒提示；交互控件不弹普通提示。RC 保持公共机制处理，轮到自己时沿用回合提示。
- 全局导出仅使用 Chromino 独有命名；脚本使用 IIFE 隔离，异步加载后同步最新房间状态；断线和错误释放等待状态，切换房间/游戏清理选中、提示和弹窗。
