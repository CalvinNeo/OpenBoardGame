# Flip 7 桌游规则详解与开发指南

本文档旨在详细拆解《Flip 7》桌游的规则逻辑，以便于程序化实现。该游戏的核心机制是“Push Your Luck”（碰运气/贪婪机制）与“Set Collection”（集合收集）。

---

## 1. 游戏组件 (Game Components)

游戏由 **94 张卡牌** 组成。在电子版中，你需要创建一个包含以下卡牌对象的牌库（Deck）。

### A. 数字牌 (Number Cards) - 共 79 张
核心规则：**牌面数字 = 该牌在牌库中的总数量**（0除外）。
数字牌用于凑齐 7 张不同数字以达成 "Flip 7" 胜利条件，同时也代表基础分值。

| 牌面数字 (Value) | 数量 (Count) | 备注 |
| :--- | :--- | :--- |
| **0** | 1 张 | 特殊：虽然是数字牌，但分值为0，有助于达成 Flip 7 |
| **1** | 1 张 | |
| **2** | 2 张 | |
| **3** | 3 张 | |
| **4** | 4 张 | |
| **5** | 5 张 | |
| **6** | 6 张 | |
| **7** | 7 张 | |
| **8** | 8 张 | |
| **9** | 9 张 | |
| **10** | 10 张 | |
| **11** | 11 张 | |
| **12** | 12 张 | |

### B. 功能牌 (Action Cards) - 共 9 张
抽到时必须立即指定目标（可以是自己或对手）使用。

| 卡牌名称 | 数量 | 效果逻辑 |
| :--- | :--- | :--- |
| **Second Chance (再来一次)** | 3 张 | **防御牌**。保留在玩家面前。当玩家抽到重复数字导致爆牌(Bust)时，强制消耗此牌与导致爆牌的那张卡，免除本次爆牌，回合继续。每个玩家面前上限持有 1 张。 |
| **Freeze (冻结)** | 3 张 | **攻击/防御牌**。目标玩家强制结束本轮游戏（Bank），立即结算当前分数并移出本轮，不能再抽牌。 |
| **Flip Three (连抽三张)** | 3 张 | **攻击/强制牌**。目标玩家必须连续抽 3 张牌（除非中途爆牌或达成 Flip 7）。 |

### C. 分数修正牌 (Modifier Cards) - 共 6 张
这些牌**不是**数字牌，不计入 Flip 7 的计数，也不会导致爆牌。

| 卡牌名称 | 数量 | 效果逻辑 |
| :--- | :--- | :--- |
| **+2 Points** | 1 张 | 结算时总分 +2 |
| **+4 Points** | 1 张 | 结算时总分 +4 |
| **+6 Points** | 1 张 | 结算时总分 +6 |
| **+8 Points** | 1 张 | 结算时总分 +8 |
| **+10 Points** | 1 张 | 结算时总分 +10 |
| **x2 Multiplier** | 1 张 | 结算时**数字牌总和**翻倍（先乘倍率，再加修正分） |

## 2. 游戏流程 (Game Loop)

### 2.1 初始化 (Setup)
1.  **洗牌**：将所有 94 张牌洗混形成牌库。
2.  **发牌**：发牌员给每位玩家发 1 张底牌（面朝上）。
    * *特殊处理*：如果在发底牌阶段翻出了**功能牌 (Action Card)**，必须立即结算（例如指定某人获得 Second Chance，或者对某人使用 Freeze）。
3.  **起始玩家**：通常由发牌员左手边的玩家开始，顺时针进行。

### 2.2 玩家回合 (Player Turn)
当前玩家面临两种选择（除非被 Freeze 或已爆牌）：

#### A. 停手 (Stay / Bank)
* 玩家选择保分。
* **状态变更**：该玩家本轮结束，状态标记为 `Inactive` (或 `Safe`)。
* **分数锁定**：计算当前面前所有卡牌的分数，计入总分。

#### B. 抽牌 (Hit / Flip)
* 玩家从牌库顶抽取 1 张牌。
* 根据卡牌类型触发逻辑：

    1.  **数字牌 (Number Card)**：
        * **检查重复**：检查玩家面前的区域（Tableau）是否已有相同数字。
            * **无重复**：放入玩家区域。检查是否达成 **Flip 7**（见 2.3）。
            * **有重复 (Bust)**：
                * *判定 Second Chance*：玩家是否有 `Second Chance` 卡？
                    * **有**：移除 `Second Chance` 卡和刚抽到的重复数字卡（放入弃牌堆）。玩家继续回合。
                    * **无**：**爆牌 (Bust)**。玩家本轮得 0 分，移除面前所有卡牌至弃牌堆。状态标记为 `Busted`。

    2.  **分数修正牌 (Modifier Card)**：
        * 直接放入玩家区域。不会导致爆牌。

    3.  **功能牌 (Action Card)**：
        * 玩家必须选择一个**活跃玩家 (Active Player)** 作为目标（可以是自己）。
        * **执行效果**（详见第 3 部分）。

### 2.3 轮次结束条件 (End of Round)
一轮游戏在满足以下任一条件时立即结束：
1.  **Flip 7 达成**：任意一名玩家集齐了 **7 张不同的数字牌**（0-12中的任意7个，不含修正牌）。
    * 该玩家获得 **Flip 7 Bonus** (+15分)。
    * 该轮**立即结束**。所有未爆牌的其他玩家直接结算当前分数（无需等到他们的回合）。
2.  **全员结束**：所有玩家的状态都变为 `Stay` 或 `Busted`。

### 2.4 弃牌与洗牌 (Discard & Reshuffle)
* 一轮结束后，场上所有卡牌（包括玩家面前的）移入弃牌堆。
* **关键规则**：通常情况下，**不洗回弃牌堆**，直接用剩余牌库开始下一轮。
* **洗牌触发**：只有当牌库抽干时，才将弃牌堆重洗形成新牌库。

### 2.5 游戏胜利 (Game End)
* 通常设定为竞速制：谁先达到 **200 分** 获胜。
* 如果平局，继续加赛一轮。

## 3. 复杂逻辑判定细节 (Implementation Logic)

### Flip Three (连抽三张) 的逻辑堆叠
当玩家被指定为 `Flip Three` 的目标时，进入一个子循环：
1.  该玩家**必须**连续执行 3 次“抽牌”动作。
2.  **中途判定**：
    * 如果在抽这 3 张的过程中，玩家达成了 **Flip 7**，操作立即中止，该玩家获胜，回合结束。
    * 如果在抽这 3 张的过程中，玩家 **Bust (爆牌)**，操作立即中止，结算爆牌。
3.  **嵌套功能牌**：
    * 如果在 `Flip Three` 过程中抽到了另一张功能牌（如 `Freeze` 或另一个 `Flip Three`）：
        * 通常规则：先将这 3 张牌抽完，**之后**再结算新出现的功能牌。
        * *电子版建议*：建立一个 `ActionQueue` (动作队列)。抽牌过程中产生的新动作加入队列，待 3 张牌强制抽完后，若玩家未爆牌，则按顺序执行队列中的动作。

### Second Chance (再来一次) 的持有逻辑
* **唯一性**：每个玩家面前只能有 1 张 `Second Chance`。
* **强制转移**：如果你已经有一张 `Second Chance`，又抽到一张，你**必须**把它给另一位活跃玩家。
* **全员满载**：如果所有活跃玩家都已经有了 `Second Chance`，这张新抽到的牌直接弃掉。

### 0 号牌的特殊性
* 它是一张数字牌。
* 它计入 Flip 7 的计数（是第 7 张牌的合法候选）。
* 它的分值是 0。
* 它在牌库中只有 1 张，所以永远不会导致爆牌（除非你自己通过特殊手段复用了它，但在标准规则下它是唯一的）。
