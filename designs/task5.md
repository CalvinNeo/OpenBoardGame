# 实现《璀璨宝石》

## Subgoal 1
- 搜索互联网，找到璀璨宝石经典版的游戏规则。你不需要包含任何 DLC。你需要将规则输出到 5.rule.md。
- 你需要列出所有的宝石卡牌和贵族卡牌。你需要尝试从 Github 或者其他公开网站上，找到这些牌的图片资源。如果你无法找到，就自己绘制简单的，能体现出宝石的颜色和类型即可。
- 你需要设计：
    + 公开区域：包含硬币池、市场和贵族区
    + 私人区域：当前已经购买的，或者预定的卡牌
    + 排行榜：可以看到每个玩家现在有多少分，有多少硬币，已经有了哪些卡牌和哪些贵族
- 你需要注意人数不同情况下规则的变化
