# Design 6.1: 退出/重连机制（Token-Based）

## Goals
- 提供房间列表面板，显示当前所有房间与状态。
- 支持掉线重连（恢复到原玩家身份和手牌信息）。
- 已开始的游戏禁止新玩家加入，但允许原玩家重连。
- 防止同名/恶意冒充导致的“撞号”。
- 支持清理“全是 Bot / 全员离线”的房间，并给出阻塞提示。
- 刷新后自动回填上次输入的名字，提供 Logout 清除本地凭证。

## 核心改进
- 不再依赖“同名”作为重连凭证，改为 **player_id + reconnect_token**。
- reconnect_token 由服务端生成（随机不可猜），客户端持久化保存，用于重连认证。

## 数据结构调整
### Player
- player_id: string
- name: string
- seat: int
- socket_id: string | null
- connected: bool
- reconnect_token: string
- last_seen: timestamp

### Room List Item
- room_id
- game_type
- status (lobby | in_game | game_over)
- player_count / max_players
- players: [{name, connected, is_bot}]

### 客户端本地存储
- room_auth_map: {room_id: {player_id, reconnect_token, name}}
- last_name: string（用于刷新后自动回填）

## 客户端流程
1. room:create / room:join 成功后，服务端返回 {room_id, player_id, reconnect_token}。
2. 客户端保存到 localStorage（按 room_id 归档），并缓存 last_name。
3. 断线后重连：客户端发送 room:reconnect {room_id, player_id, reconnect_token}。
4. 若重连成功，服务端重新绑定 socket_id 并推送最新 game:state。
5. 页面刷新后自动回填 last_name；可点 Logout 清空本地凭证与名字。

## 服务端流程
### disconnect
- 标记 player.connected=false，socket_id=null，last_seen=now。
- 广播 room:state / game:state 更新。

### session 切换（room:create / room:join / room:reconnect）
- 在进入新房间前，若该 socket 已绑定旧房间，先按 room:leave 逻辑清理旧会话：
  - lobby：移除玩家；若房间空则删除。
  - in_game：标记为离线并保留 player_id。
- 清理动作应在新请求的基础校验通过后执行，避免非法请求误踢现有会话。

### room:reconnect
- 验证 room_id 存在。
- 验证 player_id 与 reconnect_token 匹配。
- 若该 player 仍 connected=true，返回错误（避免多端占用）。
- 通过后：设置 socket_id、connected=true，加入 room，并推送 state。

### room:join
- 若 room.status == in_game：
  - 仅允许带有效 reconnect_token 的重连（否则拒绝新加入）。
- 若房间内已有同名玩家且 connected=true，则拒绝。

### room:remove_bot
- 仅 lobby 时可用。
- 移除一个 Bot（默认从后往前找最后一个 Bot），并重排 seat。
- 广播 room:state / room:list_update。

### room:delete
- 允许清理“无在线真人”的房间：
  - 房间内全是 Bot，或真人全部 connected=false。
- 若有在线真人，返回阻塞名单（blocking_players）。
- 成功后广播 room:list_update，并回传 room:delete_result。

## Room 列表面板
- 新事件：room:list -> 返回所有房间概要信息。
- 服务端在 room:create / room:state 变更后广播 room:list_update（可选）。
- 前端左侧显示房间列表，支持点击进入/重连。
- 列表区域提供滚动条（房间过多时可滚动）。
- 每个房间提供“垃圾桶”清理入口：
  - 若存在在线真人，弹出气泡提示“还有谁在”。
  - 否则发送 room:delete。

## Room 面板
- 增加 Remove Bot 按钮：仅 lobby 时可移除一个 Bot。

## 创建房间交互
- 点击 Create Room 后显示游戏下拉框（默认隐藏）。
- 选择游戏后立即发送 room:create {name, game_type} 并收起下拉框。
- 若 name 为空则提示并不进入选择流程。

## Logout
- 客户端提供 Logout 按钮：
  - 主动发送 room:leave（若在房间内）。
  - 清空 room_auth_map 与 last_name。
  - 重置本地玩家状态与 UI。

## 边界处理
- 多标签页重连：若同一 player_id 再次重连，默认拒绝新连接（或配置为踢掉旧连接）。
- reconnect_token 丢失：允许在 lobby 时用 name 重新加入；在 in_game 时拒绝（避免冒充）。
- 长时间离线：可选择保留玩家直到 round_end，或超时清理（配置项）。
