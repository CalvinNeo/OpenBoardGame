# Task 145：爆炸猫（Exploding Kittens）

## 目标与规则版本

在现有房间系统中接入 2–5 人爆炸猫，支持真人、机器人、断线重连及服务端存档。先写本方案，再直接实现。保留工作区现有未提交修改。

采用 [发行方原版规则入口](https://www.explodingkittens.com/pages/rules-kittens) 与 [2022 Original Edition 规则书](https://dumekj556jp75.cloudfront.net/exploding-kittens/English.pdf)。实现原版 56 张牌：爆炸猫 4、拆弹 6、否决 5、攻击／跳过／索取／洗牌各 4、预知未来 5、五种猫咪各 4。采用该版本的同名两张／三张组合，不混入旧版五种不同牌组合或扩展牌。

## 玩法和状态机

- 每人先领 1 张拆弹及 7 张普通牌；再向抽牌堆加入人数减 1 张爆炸猫和剩余拆弹。2–3 人时仅放回 2 张额外拆弹。起始玩家随机，之后按座位顺序行动。
- 自己回合可以连续出牌，最后抽 1 张结束一个回合；跳过替代一次抽牌。攻击将剩余受攻击回合加 2 交给下一位；普通回合首次攻击只产生 2 回合。即使攻击债务只剩 1，继续攻击仍应转交 3 回合。
- 抽到爆炸猫，有拆弹时进入拆弹／秘密插入阶段，位置可选牌顶、牌底或中间任意间隙；无拆弹则淘汰，弃掉全部手牌。最后存活者获胜，结果一直保留。非最终淘汰后暂停，所有玩家点击 `Next Round` 才继续，机器人自动确认。
- 出牌进入公开否决响应窗口。出牌者默认确认；其他存活玩家（无论是否持有否决）点击 `Pass`。窗口尚未结束时任何存活玩家可打否决，包括已确认者；每次否决翻转原效果并重置确认，否决者默认确认。全部确认才执行或取消，弃牌不会退回。抽牌、爆炸猫、拆弹及效果开始后的选择不能否决。
- 预知未来只给本人看牌顶至多 3 张，先暂停等本人 `Continue`，确认后保留当前有效的私人预览；抽牌、插入或洗牌使预览失效。索取在否决结束后由目标自行选牌交给出牌者。两张同名牌随机偷取，三张同名牌公开指定牌名，有则取得一张。
- 阶段：`playing`、`reaction`、`favor`、`future`、`defuse`、`reinsert`、`elimination_review`、`game_over`。

## 服务端与接入

新增 `game/exploding_kittens.py`，实现初始化、合法动作、权威验证、个人视图、序列化和机器人。动作携带本局随机 token 与窗口编号，防止重复出牌、旧阶段点击和重开后的过期请求；同一响应窗口的确认可以并发提交。非法动作在任何修改前完整校验。

牌使用独立不透明 ID；公开视图只含自己的手牌、自己的预览、公共弃牌和手牌数量，不传牌堆、种子、偷到的牌、索取交出的牌或插入位置。公共日志和机器人动作广播同样脱敏。未结束的存档禁止下载／克隆；服务端重连恢复保留隐藏状态。机器人仅依据个人视图决策，并覆盖否决、索取、拆弹、插入及回顾阶段。

注册游戏名称、人数、动作 schema、标签和开发顺序；接入现有资源清单及房间状态分发。共享代码只做必要接入，不重构其他游戏。

## 前端（FRONTEND.md / task40.md）

新增 `static/games/exploding_kittens.{html,css,js}`，通过 `GAME_ASSETS` 按需加载。首页仅增加空游戏面板、页头和弹窗挂载点；脚本 IIFE 隔离，必要公开函数使用 `ExplodingKittens` 前缀，支持加载后同步最新房间状态。

视觉使用原创 CSS、Emoji 和颜色：珊瑚红危险牌堆、奶油色卡片、青绿拆弹、紫色否决。桌面上方为玩家席位，中间是牌堆／弃牌与当前决策，下方手牌紧贴操作栏；手机采用紧凑双列卡片和可换行控件，320px 起不横向溢出，长名字可换行，手牌和日志限制高度并内部滚动。

点选手牌后显示紧邻的组合、目标和确认控件；点空白或 Esc 取消选择，选择多张时保持手牌滚动位置。所有一般界面文案用英文，游戏名与牌名可中英对照。仅 Help 展示完整规则；Explain 模式拦截原操作，只高亮可解释目标，禁用按钮也支持解释，查看一次或 Esc 退出。不添加各处 i 图标。静态图标有悬停／键盘提示，手机点击的提示 3 秒后消失，连续点击替换提示。弹窗支持 Esc、点击外部关闭和焦点返回。
