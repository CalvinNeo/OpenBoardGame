# Task 141：幽港迷城 / Gloomhaven

## 目标与版本范围

新增 `gloomhaven`，支持 1–4 位玩家、房间机器人、存档与断线重连。实现可完整打完的**战术遭遇版**：六种初始职业、三个原创双房间遭遇、可选择难度、双卡行动、先攻、六角格移动、怪物自动行动、攻击修正、状态、元素、拾取、道具、短休／长休、失去卡牌抵伤与耗尽。单人控制两名佣兵，多人各控制一名；胜利后全员确认推进下一遭遇，失败后全员确认重试。

规则骨架以 [初版规则书](https://online.flippingbook.com/view/642368833/) 第 16–32 页为准，区别于 2025 第二版。本次不是 95 个商业剧情关卡的完整战役移植：使用原创关卡、重新编写的职业精简能力牌，不复制商业卡图、地图、剧情。保留六职业的起始生命与手牌容量（蛮族 10／10、工匠 8／12、织法者 6／8、恶棍 8／9、裂岩者 10／11、心灵窃贼 6／10）；未实现召唤物、职业升级、退休、城镇事件、商店和遗产解锁。入口副标题及 Help 明示此范围。经验与金币记录为遭遇系列成绩，关卡间恢复卡牌、生命和道具。

## 游戏流程与规则

- 准备阶段选择职业，单人选择两名不同职业；房主选择三个遭遇之一作为起点、难度（0–2）。全员 Ready 后开战。
- 每轮秘密选两张手牌，第一张为先攻牌；提交可撤回，所有存活佣兵提交后一起公开。先攻小者先行动；玩家与怪物同值玩家先，同玩家先看另一张牌，再按座位／佣兵顺序稳定裁决。长休先攻 99。
- 每名佣兵在行动时自由选择一张牌的上半和另一张牌的下半，先上后下或先下后上均可。每半的技能按顺序执行，可跳过；可改成基础 Attack（⚔️）2 / Move（👣）2，基础动作不烧牌。卡牌用完立即进入弃牌或失去区。
- 六角地图以轴坐标建模；移动支持逐格及提前结束，穿过友军但不能在友军格结束，敌军和障碍阻挡。关闭的门可由角色移动开启，揭示下一房间；新怪物按本轮先攻规则加入。陷阱造成伤害、困难地形多耗 1 移动力。墙和关门阻挡视线；原创新地图不设计角点视线争议。
- 攻击按射程、视线、护盾、穿刺、中毒及 20 张标准攻击修正牌计算；远程贴身攻击劣势，优势／劣势取两张较好／较差，互相抵消。翻到 ×0／×2 后轮末洗回。每名角色独立牌堆，怪物共享牌堆。
- 支持中毒（☠️）、创伤（🩸）、缴械（⛔）、定身（⛓️）、晕眩（💫）、困惑（🌀）、强化（✨）。负面持续状态按角色回合结束时限移除；中毒／创伤由治疗清除，带中毒的治疗不恢复生命。产生的六元素在行动者回合结束变强，轮末强→弱→消失，不能在生成它的同一回合消费。
- 短休在轮末回顾期间进行：随机失去一张弃牌，可付 1 点生命重抽一次，随后回收其余弃牌；长休占整回合，选择失去一张弃牌、治疗 2 并恢复已横置道具。两种休息均要求至少两张弃牌。
- 每次角色受伤时暂停：承受伤害，或失去一张手牌／两张弃牌抵消该次伤害；本轮选定但未执行的牌不能用于抵伤。攻击附加状态仍然生效。生命归零或轮初无两张手牌且无法休息则耗尽，所有角色耗尽失败。
- 守卫、弓手、活骸自动按怪物能力牌行动；同类精英先、普通后。聚焦按到攻击位置所需步数、距离、先攻排序；优先不踩陷阱的路线，远程尽量摆脱劣势。每只怪物有独立回合／状态，怪物能力同类共用。
- 击杀掉落金币（💰），回合结束拾取脚下金币，Loot 按范围拾取；支持治疗药水（一次性）和疾行靴（长休刷新）。经验（⭐）、金币和击杀数在结算展示。
- 每轮全部行动完成进入 `round_review`；所有玩家（包括耗尽角色的控制者）点击 **Next Round** 后继续。短休尚未处理完不能确认。机器人只确认自己的席位。遭遇结算同样全员确认，再推进／重试，第三关胜利显示最终结果。

## 服务端与接入

`game/gloomhaven_data.py` 存放职业／卡牌／怪物／地图数据；`game/gloomhaven.py` 负责规则、合法动作、私有视图与基于公开视图的练习 AI。状态可 JSON 往返，随机过程用可恢复计数器，动作携带 `game_token / scenario_attempt / round / revision`。单人两佣兵通过 `hero_id` 区分；服务端校验控制权、参数类型、阶段、距离、选牌与目标，拒绝动作不产生任何状态变化。版本过期明确拒绝，客户端收到新状态后重新操作。

公开视图隐藏未揭示房间、怪物能力牌／攻击修正牌顺序、随机种子、他人手牌和未公开选牌；合法交互选项由服务端生成，AI 也只读取本人公开视图。接入 registry、中文名、标签、开发顺序、按玩家广播、活动私密存档保护及凭座位 token 的冷启动恢复；不改动其他游戏的现有逻辑。

## 前端（FRONTEND.md / task40.md）

- 新建 `static/games/gloomhaven.{html,css,js}`，IIFE 私有作用域，公开入口带 Gloomhaven 前缀。登记 `GAME_ASSETS` 按需加载；首页仅空面板、页头和弹窗挂载位，更新修改资源的版本号。兼容 DOMContentLoaded 后加载并回放最新房间状态。
- 原创 CSS／SVG／Emoji：暖灰羊皮纸外框、深蓝石室、铜金先攻标识；角色／怪物同时显示符号、名称与生命。桌面地图、行动和卡牌相邻，手机纵向重排、手牌双列。地图自适应尺寸，无拖拽或横向页面滚动；长日志内部滚动，长名字换行。
- 点选两张牌时保留列表滚动；按顺序显示 1／2，点击选中牌撤销。行动半区、基础动作、格子、目标、休息与抵伤均使用按钮，不输入 JSON。空白／Esc 取消本地选择，弹窗支持 Esc 与焦点返回。
- Help 集中完整规则、范围和线上约定；Explain 捕获所有操作，仅可解释对象显示虚线和问号，禁用按钮仍支持，解释后自动退出。静态 Emoji／缩写可悬停或聚焦提示，手机点按 3 秒自动消失、新提示替换旧提示。Help／Explain 同列文字与 Emoji。不新增逐区 i。
- 游戏无关 UI 使用英文。Next Round／End Turn 等明确按钮不重复确认。避免文字、Emoji、卡牌或地图重叠，检查 1440／768／390／320px。
- 轮末逐佣兵汇总行动，突出自己控制的佣兵；他人回合公开显示正在使用的牌／技能和地图变化。RC 隐藏时，若有需要本人处理的操作，用红色边框提示。
