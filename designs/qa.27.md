# 回答1

## 1. 神器卡处理逻辑 (Artifact Handling)

### Q1: 多人同时离开时，神器如何处理？
**定案：直接移除出游戏 (Remove from Game)。**
* **逻辑**: 如果只有 **1名** 玩家选择离开，他获得路径上的所有神器。如果有 **>1名** 玩家选择离开，神器被视为“由于争抢而损坏”或“无人能顾及”，直接移出游戏。
* **代码行为**:
    * 检查 `leaving_players.count`。
    * 若 `> 1`: 将路径上的神器卡对象标记为 `removed` 或移入 `trash_pile`（不再回到牌库）。
    * 若 `= 1`: 将神器卡移入该玩家的 `collected_artifacts` 列表。
    * 若 `= 0`: 神器保留在路径上。

### Q2: 回合结束时未被拿走的神器？
**定案：直接移除出游戏 (Remove from Game)。**
* **逻辑**: 神器是每个回合的独特机会。如果回合结束（无论是大家安全回家还是灾难爆发）神器还在路径上，说明本回合无人成功带走它，它将永久消失。
* **代码行为**: 回合清理阶段，检查路径上是否还有神器卡，如果有，全部移入 `trash_pile`，**绝对不要**洗回牌库。这意味着全场游戏最多只会出现5个神器。

## 2. 神器分值设定 (Artifact Values)

### Q: 采用变动分值还是固定分值？
**定案：采用 [5, 5, 5, 10, 10] 模型。**
* **逻辑**: 增加游戏后期的紧张感和翻盘点。
* **数据结构**:
    * 建立一个全局神器队列: `Artifact_Stack = [5, 5, 5, 10, 10]`。
    * **Round 1**: 放入第1张 (Value 5)。
    * **Round 2**: 放入第2张 (Value 5)。
    * ...
    * **Round 4**: 放入第4张 (Value 10)。
    * **Round 5**: 放入第5张 (Value 10)。

## 3. 余数宝石分配规则 (Remainder Distribution)

### Q: 多人离开时，余数是“逐张分配”还是“汇总平分”？
**定案：逐张卡分别分配 (Card-by-Card)。**
* **逻辑**: 物理桌游中，宝石是物理放置在每一张卡牌上的。玩家离开时，是顺路捡走每一张卡上的宝石。数学上 `Floor(Sum / N)` 并不等于 `Sum(Floor(x / N))`。汇总平分会导致玩家获得比规则允许更多的宝石。
* **算法实现**:
    ```python
    # 假设 leaving_count 是离开的玩家数
    total_loot = 0
    
    for card in path_cards:
        if card.type == TREASURE and card.gems_remaining > 0:
            # 计算这张卡能分多少
            share_per_player = floor(card.gems_remaining / leaving_count)
            # 玩家拿走的部分
            total_loot += share_per_player
            # 卡上剩下的部分（更新余数）
            card.gems_remaining -= (share_per_player * leaving_count)
            
    # 每个离开的玩家获得 total_loot
    ```

## 4. 牌库抽空处理 (Empty Deck Edge Case)

### Q: 若牌库抽空，仍在洞穴的玩家怎么办？
**定案：视为“安全回家” (Safe Return)。**
* **逻辑**: 虽然极罕见（通常会在抽空前遇到灾难），但如果牌库所有卡都被翻完且没有触发灾难，探险自然结束。
* **状态更新**:
    * 所有 `status == In_Cave` 的玩家执行 `Bank` 操作（手牌分转入安全分）。
    * 回合正常结束，进入结算。

---

## 5. 平局规则 (Tie-Breaker)

### Q: 平局怎么算？
**定案：神器数量多者获胜 (Most Artifacts Wins)。**
* **优先级**:
    1.  **总宝石数 (Total Gems)**: 最高的赢。
    2.  **神器数量 (Artifact Count)**: 若宝石数相同，持有神器卡数量多的赢。
    3.  **绝对平局 (Shared Victory)**: 若宝石和神器数量都相同，则共享胜利。

---

## 6. 总结：电子版完整计分流程图

1.  **回合内离开**:
    * 多人离开 -> 宝石逐张分，神器销毁。
    * 单人离开 -> 宝石逐张分，神器获得。
2.  **回合结束 (灾难)**:
    * 灾难卡移出游戏。
    * 路径上神器移出游戏。
    * 手牌宝石归零。
3.  **回合结束 (安全/空牌)**:
    * 路径上神器移出游戏。
    * 手牌宝石入库。
4.  **游戏结束**:
    * `Score = Banked_Gems + (Artifacts * Value)` (注: 此时神器已转化为分值，不再是卡片)。
    * 对比 Score -> 对比 Artifact_Count -> 判定胜负。
