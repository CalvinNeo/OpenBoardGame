# Task 163：王权骰铸（Dice Throne）

## 范围与规则基线（目标方案）

以下是原始目标方案；实际完成范围与限制见文末记录。

实现 Season One Rerolled 的双人对战盒 **Barbarian（野蛮人）vs Moon Elf（月精灵）**，接入现有房间，支持两名真人或真人与机器人、断线重连与完整胜负结算。不混入其他赛季英雄、多人组队或 Adventures。角色、技能、状态与卡牌规则采用该版本，参考来源和核验结果随实现补充；不将自创规则伪称为原版内容。

两人各 50 点生命（❤️）、2 点 Combat Points（⚡，上限 15）、4 张手牌（🃏），选择不同英雄，随机决定先手。先手首回合跳过收入。正常收入获得 1 CP 并抽 1 张牌。每个回合依次进行维护/收入、主要阶段 I、进攻掷骰、技能与响应、防御掷骰及伤害结算、主要阶段 II、弃牌和回合复盘。进攻阶段使用英雄的五枚骰子，最多三次掷骰，玩家自由保留或重掷任意骰子；根据骰面符号或顺子选择能力。主要阶段可购买技能升级或卖牌获取 CP；手牌上限为 6，牌堆耗尽时重洗弃牌堆。

后端区分可防御、不可防御、纯粹、附带和终极伤害；防御能力、卡牌、状态指示物各按其适用范围处理。终极技能的确认前允许改骰，确认后不允许通过防御、状态或卡牌规避。响应阶段必须为非当前回合玩家保留行动机会，不能因进攻方点击技能就跳过防御方。生命降至 0 时结束，允许同一次结算的同时击倒。

## 状态机与数据

- `game/dice_throne_data.py`：英雄骰面、能力、卡牌、升级、状态以及规则说明，数据与结算逻辑分离。
- `game/dice_throne.py`：初始化、角色选择、阶段推进、掷骰/重掷、卡牌/技能/状态动作、响应优先权、胜负、公开视图、序列化、机器人。
- 所有动作附当前 `revision`；验证操作者、阶段、费用、目标、骰子下标和卡牌归属。先在副本验证与结算，非法动作不得改变生命、CP、牌堆、随机流或阶段。
- 随机状态可 JSON 保存恢复，但不能进入公开视图。对手只看到手牌张数、公开弃牌与升级；日志与机器人思考消息不得泄露秘密卡牌或随机种子。
- 每次双方完整回合结束后保留公开复盘；双方点击 `Next Round` 后继续。机器人自动确认，终局保留最终棋盘与结果。

## 前端

严格遵守 `FRONTEND.md` 与 `designs/task40.md`。
