# Task 189: 似帽非帽 / That's Not a Hat

- 原版：That's Not a Hat，Ravensburger 2023，设计师 Kasper Lapp
- game_id：not_a_hat，3-8 人，turn_mode = turn
- BGG：https://boardgamegeek.com/boardgame/375651/thats-not-a-hat ，averageweight 1.06
- 标签：毛线(filler)、诈唬(bluffing)
- 专门 AI：有，Select Game 显示 🤖

## 1. 实体规则

组件是 110 张礼物牌。牌面是一件日常物品，牌背印着一个指向左或右的箭头，底色一半浅一半深。

**开局**：洗牌后每位玩家面前放一张正面朝上的礼物牌，所有人都能看清每一张。剩下的牌正面朝上叠成礼物商店(🎁)，牌堆顶所有人都看得见。

**首轮**：起始玩家从礼物商店抽一张，展示给全场，翻成背面朝上，按箭头方向递给左邻或右邻，并说出它是什么。从商店抽到的牌永远不会留在自己手里，必须立刻送出去。

**收礼**：收礼人有两个选择。

- 收下：把新牌背面朝上叠在自己原有礼物上面。此时面前有两张牌，但一个人只能持有一份礼物，所以立刻轮到他送礼，而且不能转手刚收到的牌，必须送出最下面那张旧礼物。若这是他第一次送礼，要先把旧礼物翻成背面朝上。连锁就这样一圈圈传下去。
- 质疑：喊「这不是…」，不需要说对正确物品，直接把牌翻开。

**惩罚**：翻开后，谁判断错误谁把这张牌正面朝上放进自己的惩罚堆。送礼人说错了由送礼人受罚，送礼人说对了由质疑者受罚。受罚者随后从商店抽一张新牌，展示后立刻送出去。

**结束**：有人拿到第三张惩罚牌时整局立刻结束，惩罚最少的玩家获胜。

规则要点：一张牌一旦翻成背面朝上，谁都不许再偷看，包括持有它的人。

## 2. 电子化改编

这个游戏的隐藏信息是**记忆**，不是所有权。服务端始终知道每张牌是什么，但任何 viewer 都拿不到背面朝上牌的物品，包括持有者本人。这是整个实现的中心约束。

由此产生三个关键决定：

1. **背面朝上的牌对所有人保密。** get_public_view 里只有 face_up 为真时才输出 item。牌背的箭头与底色是公开信息，因为实体版里牌背本来就朝着所有人。
2. **翻牌时机提前到「成为送礼人」的那一刻。** 实体版里翻牌和递出几乎同时发生，如果照搬到电子版，送礼人在做决定时还能从界面上读到答案，吹牛就不存在了。所以 _begin_pass 在进入 giving 阶段时立刻把牌叠最下面那张翻成背面朝上。
3. **礼物名从清单里选，不能自由输入。** 实体版可以随口说任何东西，电子版用 55 件物品的可搜索清单代替。说出的名字是公开信息，会广播给全场并写进 Gift Log。

商店牌是例外：它刚被全场看到，所以在 giving 阶段仍然正面朝上展示。送礼人依然可以说谎，此时收礼人几乎必定质疑，这正是实体版里「当众抽到的牌不好吹牛」的等价物。

**Gift Log** 记录每一次公开亮牌和每一句声明，因为这些话在实体版里本来就是当场说给所有人听的。日志永远不记录声明的真伪。

## 3. 状态机

| phase | 谁能动 | 合法动作 |
| --- | --- | --- |
| memorize | 所有未准备的人 | ready |
| giving | 当前送礼人 | give + item |
| receiving | 当前收礼人 | accept / refuse |
| review | 所有未继续的人 | continue |
| game_over | 无 | 无 |

memorize 和 review 是 DEV_GUIDE 要求的回合间暂停：开局让所有人记住全场礼物，每次质疑翻牌后让所有人看清结果，全部玩家按下按钮才继续。机器人会自动确认。

牌叠约定：牌叠下标 0 是最老的礼物，也是永远被送出去的那一张。收下礼物时新牌追加到末尾，所以牌叠从左到右是由旧到新。

pending 表示当前送礼人手上必须立刻送出的商店牌。pending 为空时，送出的是牌叠最下面那张。

配置项：max_penalties（默认 3，范围 1-5）对应惩罚上限，starting_gifts（默认 1，范围 1-2）对应原版的高手模式，即每人开局两张牌。

## 4. 牌库

game/not_a_hat_data.py 定义 55 件物品，每件两张，正好 110 张牌，与实体版一致。物品用 Emoji 表示，分成穿戴、玩物、用具、出行、吃喝、生灵六类，同时提供中英文名。牌背底色按卡片 id 奇偶分配，箭头在洗牌时随机。

## 5. AI 设计

game/not_a_hat_ai.py 实现的是专用策略，不是通用随机 bot，因此加入 STRATEGIC_AI_GAME_IDS。

核心是**记忆衰减**。每张牌在局中只被公开亮出一次，亮出时把当时的 seq 记进 state 的 reveal_seq。机器人在需要报出某张牌时，按下面的概率「想起」它：

    age <= 1 : p = min(0.97, skill + 0.2)
    age >  1 : p = skill * 0.986 的 (age - 1) 次方

skill 在开局为每个机器人随机抽 0.55 到 0.92。牌的位置是公开信息，所以机器人唯一的不确定性就是物品本身。

- **送礼**：想起来就说真话，想不起来就从 55 件物品里等概率随机挑一件吹牛。
- **收礼**：想起来且声明与记忆一致时 90% 收下；想起来但不一致时 86% 质疑；完全想不起来时只有 18% 盲猜质疑，因为盲猜质疑猜错要自己受罚。
- **ready / continue**：立即确认，带短延迟。

这套策略让机器人会随时间自然忘事，并且在记得的时候表现可靠，符合真人体验。策略是状态的纯函数，不修改 state。

## 6. 前端

- static/games/not_a_hat.html：模板片段，状态条 + 局势提示 + 牌桌 + 操作区 + 可折叠 Gift Log。
- static/games/not_a_hat.js：Help/Explain 走 obgCreateHelp / obgCreateExplain 共享组件，Explain 属性为 data-nah-explain。Help 与 Explain 按钮放在 index.html 的面板头部，与 Reconnect 同一行，通过清单的 header 钩子 showNotAHatHeaderActions 控制显隐。
- static/games/not_a_hat.css：独立样式，通过清单的 styles 注册。

布局要点：

- 牌桌是主体，按顺时针座位序排成网格。手机端两列，560px 起三列，900px 起左棋盘右操作区的双栏并把操作区 sticky，1280px 起卡片更大。
- 每张牌背显示箭头 ⬅️/➡️ 与浅/深底色，最老的那张牌左边有一条琥珀色标记，因为它才是要送出去的牌。
- 送礼人的收礼对象由前端根据 turn_order 和箭头算出，并直接把名字写在操作区标题里，玩家不需要自己数方向。
- 礼物清单有搜索框 + 分类筛选 + 可滚动网格，避免在 55 件物品里翻找。选中后底部固定显示已选物品和 Give 按钮；再次点击同一物品或点击空白处取消选择，没有 Clear Selection 按钮。
- 质疑按钮的文案会带上被声明的物品 Emoji，例如 🚫 That's not a 🎩!
- 物品名跟随 Help 的中英切换，通过 obg:help-lang 事件重绘。
- 轮到自己行动时，收起的 Room Control Dock 会加上红色边框提示（not-a-hat-turn）。

## 8. 与原版的差异

- 物品用 Emoji 代替手绘插画，55 种而不是原版的全部画稿。
- 礼物名必须从清单里选，不能自由发挥。
- 没有实现原版说明书里的「按底色分堆」困难模式与 2 人变体。2 人需要每人两张礼物，与 starting_gifts=2 组合后规则仍然成立，但 min_players 保持实体版的 3 人。
