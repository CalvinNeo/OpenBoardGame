# Task 134：犯罪现场 / Deception: Murder in Hong Kong

## 范围与规则依据

实现 `deception`，4–12 人。《犯罪现场》亦称 CS-Files / Deception: Murder in Hong Kong。依据 [Gen42 出版方英文规则书](https://www.gen42.com/wp-content/uploads/Deception_Rules_online_EN_202402.pdf)及 [Grey Fox 游戏介绍](https://greyfoxgames.com/products/deception-murder-in-hong-kong)。采用基础规则，支持 6 人以上可选帮凶、目击者（后者必须与帮凶同开），3／4／5 张每类牌的难度配置；默认 4 张。暂不含事件牌和扩展角色。词牌、场景措辞与界面为原创中英双语文本和 Emoji，不复制商业卡图；卡池与实体版不同，在 Help 明示。

随机分配法医、凶手和侦探，可选帮凶与目击者。法医公开；其他身份秘密。除法医外每人公开若干手段牌、线索牌，并获得一次指认机会。凶手秘密选择自己的一张手段牌和一张线索牌作为答案；法医、凶手、帮凶知道答案。目击者只知道两名嫌疑人，不区分凶手与帮凶。

共三轮调查。首轮法医选择地点板，与死因板和随机四张场景板组成六板，依次放置六个标记，每板六选一；标记放下后不可改动。第一枚标记之后允许公开讨论。线索完成后继续讨论，由法医开始轮流陈述；从法医左手座位起，除法医外的所有玩家依次陈述。后两轮法医各抽一张新场景板，替换四张普通场景板中的一张并重新放一个标记，不能替换地点或死因。

除法医外的玩家可在案件选择完成后随时用自己的警徽，指认另一玩家的一对牌，允许打断陈述。服务端只返回正确／错误，不提示对了几项。错误后警徽消耗，仍能讨论与陈述。两牌均正确时侦探方获胜；有目击者时先由凶手猜目击者，猜中则凶手方反胜。无人猜中且所有警徽用尽，或最后一人第三轮陈述结束，凶手方获胜。结果展示全部身份及答案。

## 线上流程与后端

新增 `game/deception.py`、`game/deception_data.py`，实现标准 init/apply/view/legal/bot/serialize 接口。阶段为 `crime → scene_setup → evidence → discussion → presentation → round_review → evidence … → reversal / game_over`。第一、二轮陈述后停留复盘，**包括法医的所有玩家**点击 Next Round 后再继续。第三轮结束直接保留最终结果。线上陈述不强制 30 秒截止，玩家自行点击 Finish Presentation；Help 说明原规则的约 30 秒建议。

提供内置讨论记录：第一枚标记之后，除法医外的玩家可聊天，陈述期仅当前发言人可发言；反转期仅凶手和帮凶可讨论。法医禁止自由文字提示，只能操作场景板。短文本经长度、身份、阶段校验；讨论记录内部滚动、服务端最多保留 120 条聊天；标记、换板、指认等案情记录独立保留，不被聊天挤掉。无需外部语音即可游玩，也可配合语音。

所有动作携带每局随机 `case_token` 和 `round`，避免前局／前轮重放；场景动作指定板 ID，防止替换后旧点击落到新板。所有字段在模块内验证，绕过 JSON Schema 也不能越权，错误动作不改变状态。公开视图严格分离本人身份、秘密答案、目击者知识、待抽／待替换板；旁观者无私密数据或动作。公开事件不携带凶手选牌者、牌库、seed 或未公开身份。

接入游戏目录、中文名、分类、配置和按需加载。更新开发顺序。保护活动存档下载与克隆（含服务冷启动后磁盘存档）；隐藏公开配置 seed。犯罪现场不显示逐座位机器人思考进度，不广播带玩家 ID 的机器人原始动作，以免从选牌行为推断凶手。

基础练习机器人只接收自身视图：法医根据自己有权知道的答案和公开词牌语义给线索；调查员按公开线索推断，罪犯参与流程，目击者使用自己的合法知识。明确为练习机器人，不声称能理解任意自由文字讨论。机器人仅确认自己的 Next Round，不替断线真人确认。

## 前端（FRONTEND.md / task40.md）

新增 `static/games/deception.{html,css,js}`，独立资源注册 `GAME_ASSETS`，首页只加入空面板、配置、页头与弹窗占位，更新公共脚本版本。JS 使用 IIFE，仅暴露 `Deception` 前缀入口；加载后同步房间及最新游戏状态。

采用案卷风格：墨蓝标题、暖纸色卡片，手段（🗡️）蓝色、线索（🧩）橙色、法医（🔬）、警徽（🛡️）配文字。桌面场景板与嫌疑人牌区双栏，手机单栏并紧凑分组；嫌疑人区、讨论区、历史记录内部滚动。320px 起无横向溢出，长姓名换行。选择同一嫌疑人的一对牌后在其卡区附近确认，不增加 Clear Selection；空白或 Esc 取消。最终指认与凶手定案有确认，Next Round 不二次确认。

私人身份默认折叠，点击 Reveal 展开；本人秘密答案与目击者知识同区展示。中央场景板始终展示当前标记，替换历史可展开查看。动作面板显示当前阶段和操作者，轮末显示已确认人数；公开讨论输入仅合法发言者可用。

Help 集中规则、角色、胜负、卡池差异与练习机器人限制；Explain 按 task40 实现点击解释模式，捕获并阻止普通操作，支持 disabled 按钮，只有可解释目标显示虚线高亮与问号，解释后退出。Esc 退出解释并关闭弹窗，弹窗具备焦点管理。静态指标和图标有鼠标悬停／键盘焦点说明，触屏点击显示三秒提示，新提示替换旧提示。Help／Explain 同时写图标和名称，不逐区放 i。非游戏内容 UI 使用英文。

## 实施结果

已完成，游戏目录可选择 **Deception: Murder in Hong Kong · 犯罪现场**。

- 后端支持 4–12 人、3／4／5 张每类牌、基础身份及可选帮凶／目击者、秘密定案、法医六枚顺序标记、两次换板、三轮陈述、全员 Next Round、一次警徽指认、两种目击者反转结果和最终身份揭晓。
- 原创卡池为 64 张手段、64 张线索、16 张普通场景板、4 张地点板及 1 张死因板，均有中英文文本，不含商业图片。基础机器人只使用自身可见信息。
- 内置讨论限定合法发言人，法医无法发文字；聊天作为纯文本显示，最多保留 120 条，不删除案情记录。错误指认即时显示结果；历史记录可查看指认、标记顺序和被替换线索。
- 前端按需加载独立模板、CSS、JS，使用 IIFE 和专属入口。Help／Explain、disabled 按钮解释、键盘拦截、Esc／空白取消、手机三秒提示与新提示替换均已实现。手机讨论区默认折叠，场景确认后收起选项，长姓名换行，牌区与历史内部滚动。
- 隐藏 seed、其他玩家身份、秘密答案、未公开新板及牌库；不广播机器人秘密动作的操作者或逐席位思考状态。活动存档禁止直接下载／克隆。开启 Auto Save 后，服务重启可凭原 room_id、player_id 和 reconnect_token 恢复原房间与原座位，其他座位仍受原凭证保护，并恢复机器人调度；无凭证者不能借冷恢复查看秘密信息。
- BGG 查询脚本已登记游戏链接，实际取得 averageweight **1.5892**，目录显示 **1.59**。开发顺序已刷新，本游戏编号 98。保留工作区内其他任务的修改。
