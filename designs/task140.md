# Task 140：僵尸商场（Mall of Horror）

## 目标与规则依据

新增 `mall_of_horror`，实现 3–6 人的基础版完整对局，支持房间机器人、断线重连、存档和旁观视图。以 [英文基础规则](https://ultraboardgames.com/mall-of-horror/game-rules.php) 为主，交叉核对 [EOG 规则勘误摘要](https://www.orderofgamers.com/games/mall-of-horror/)；地点容量参考 [中文规则资料](https://waterricebgg.pixnet.net/blog/posts/9175021430)。不加入 Director’s Cut 扩展，不复制商业美术或规则原文。

## 规则与流程

- 每人有模特（👱，7 分、1 防御、1 票）、壮汉（💪，5 分、2 防御、1 票）、枪手（🔫，3 分、1 防御、2 票）。三人局另有小女孩（👧，1 分、1 防御、1 票）。角色死亡移出棋盘；终局比较幸存角色分数，再比较剩余行动牌，相同则并列。
- 地点依次为洗手间（🚻，3 格）、服装店（👕，4 格）、玩具店（🧸，4 格）、停车场（🚗，不限）、保安室（📹，3 格）、超市（🛒，6 格）。3／4 人时服装店关闭。容量计算角色数量，不按壮汉防御力计算。
- 布置阶段按座位轮流掷两骰，选择一个尚未布置的角色放入合法骰面地点；两处均不可放时可以选任意可用地点。布置后掷四骰放置初始僵尸。
- 每轮：停车场投票搜索货车 → 获选者取三张、留一张、送另一玩家一张、余下置底 → 保安室选队长 → 秘密掷四骰、按序使用监控 → 当轮当选队长先公开目的地 → 其余玩家秘密锁定目的地 → 已淘汰者在规定轮次放置僵尸 → 同时揭晓目的地和骰子 → 从队长开始依次移动一个角色 → 噪音吸引 → 按 1–6 号地点解决攻击 → 全员回顾。
- 目的地只决定要去哪里，揭晓后再选移动哪个角色。必须换地点；满员或新关闭的目的地把该角色送入停车场。冲刺（🏃）可改往有空位的地点，允许留在原处。空地点在到达阶段有至少 8 只僵尸时永久关闭并清走僵尸；停车场不关闭。
- 角色最多的唯一地点、模特最多的唯一地点各吸引一只额外僵尸，平手不吸引。一般地点僵尸数 ≥ 防御时突破；停车场有僵尸必突破；超市 ≥4 只必突破。普通地点牺牲一个角色后清掉全部僵尸，未进食的僵尸保留；停车场每只僵尸需单独投票选牺牲者，阶段结束清空残余僵尸。
- 投票按玩家颜色选择，自己的全部票投给同一玩家。枪手额外一票，威胁（✊）每张额外一票。首次平票仅在最高票候选人之间重投，不在地点内的玩家（含淘汰者）各获一票；不重新开出牌窗口。二次平票：货车不分牌、队长留任、牺牲按候选玩家等概率抽签。被选玩家自己选择失去哪个未躲藏角色。
- 行动牌共 21 张：威胁、监控（📹）、冲刺、加固（🪵）、单杀武器（🔪）、双杀武器（🪓）、躲藏（🫥）各三张。出牌从队长起，每人只有一个窗口，可连续出多张再 Pass。加固不能用于停车场或抵挡超市四只以上僵尸；躲藏针对自己的一个角色，保留防御但失去投票权且不能牺牲，持续到本轮攻击结束。牌用后不回洗。
- 淘汰者继续参加平票重投，并仅在淘汰后的下一轮获得一次僵尸放置机会。轮末幸存角色不超过 4（六人局为 6），或所有幸存角色同处一个非停车场地点，即终局；不会在攻击途中提前结束。

## 明确的线上约定

初始队长使用第一座位，不采集年龄。牌库不足三张时取剩余牌，优先留一、其次送一，有第三张才置底。采用英文基础版的小女孩数值，不添加部分民间译文的“小女孩不能先牺牲”特权。无商业素材，棋盘、标记和牌面由 CSS／Emoji 绘制。所有人都可查看回顾，包括淘汰玩家；只有每位玩家都点击 `Next Round` 才推进，机器人仅确认自己的席位，断线真人须重连。终局提供最终结果并使用房间现有重开机制。

## 服务端与安全

新增 `game/mall_of_horror.py` 与只读取本人公开视图的机器人。所有动作携带游戏实例 token 和阶段编号；服务端验证字段、玩家资格、阶段、对象归属、容量和牌的时机。非法／重复／过期动作不能部分改变状态。秘密投票和目的地只公开提交状态，本人可以看到自己提交值，揭晓后才公开结果；骰子仅授权玩家在揭晓前可见；不广播完整动作、牌库、对手手牌或随机种子。

接入游戏注册、标签、开发顺序、资源清单和主渲染入口。活跃存档禁止匿名下载／克隆，原席位凭重连令牌可从磁盘恢复。JSON 往返保持全部阶段和随机进度。

## 前端（遵守 FRONTEND.md 与 task40.md）

- `static/games/mall_of_horror.{html,css,js}` 按需加载，首页只保留空面板、header 和弹窗挂载点。使用独立 CSS，脚本封装在 IIFE，少量全局入口以 `MallOfHorror` 命名。兼容延迟执行并同步当前房间及最后状态。
- 深色商场平面图，暖黄色指示条和红色危险提示。六个地点组成紧凑网格，显示容量、僵尸、防御和带颜色／姓名的角色。桌面棋盘旁显示当前操作与手牌；手机重排为双列地点与紧邻的操作区，不横向滚动、不用缩小整页解决排版。
- 点选角色／地点／牌后在操作区确认，空白或 Esc 取消选择，不加 Clear Selection。投票、分牌、移动、用牌均为可点选控件，不要求输入 JSON；确认后的秘密选择显示 Locked。
- `Help` 集中完整规则和线上约定；`Explain` 捕获操作，仅有解释的目标显示虚线与问号，无解释控件也不执行原操作，disabled 按钮仍能解释，查看后自动退出，Esc 可退出。弹窗支持 Esc、焦点返回及小屏滚动。
- 角色属性、地点规则和图标悬停／键盘焦点有说明；手机点击弹出 3 秒提示，再点替换。Help／Explain 同时列出文字和 Emoji。游戏无关 UI 为英文；日志及较长手牌列表内部滚动，避免页面无限增长。
