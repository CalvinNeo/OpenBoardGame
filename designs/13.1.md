# Design 13.1: 印象花语

## 目标与范围
- 实现 3-6 人的印章作画 + 猜题配对玩法，含多轮、计分、角色轮换与中途结束。
- 客户端提供印章画布（印章可旋转）、废纸遮罩（可旋转/缩放）、按压透明度、Undo、拖拽配对。
- 服务端保存最终图像与配对结果，提供基础 bot 行为。

## 规则摘要（默认规则）
- P 人，当前猜题者 1 人，其余 P-1 为出题者。
- 每关重新抽 P+1 词卡，P-1 给出题者，2 张为干扰项。
- 一名猜题者连闯 X 关；第 i 关出题者可用印章数为 N-(i-1)。
- 全部作画结束后，猜题者拖拽词条完成配对。
- 每张配对正确：猜题者 +当前轮次 分，出题者 +当前轮次 分；猜题阶段不隐藏画作者身份。
- 每一轮结束后可选择是否继续游戏；继续时若 X 关结束则轮到下一位猜题者。

## 配置与资源
- 新增 `game/assets/impression_flower.json`：
  - `word_pool`: 词卡列表（字符串数组）
  - `rounds_per_guesser` (X), `base_stamps` (N)
  - `score_mode`: "round"（默认，按当前轮次计分）| "fixed"
  - `score_per_correct`: 当 score_mode=fixed 时使用
  - `stamp_shapes`: 固定 [circle, triangle, square, bar]
  - `stamp_colors`: 4 色（默认红/绿/蓝/黄）
  - `stamp_size`: 基准尺寸（px）
  - `bar_ratio`: 长条宽度比例（例如 0.25）
  - `canvas_size`: 画布尺寸（例如 600）
  - `mask_size`: 废纸尺寸（例如 180）
- `game/impression_flower.py` 读取配置（缓存），并允许 room:start 传入 `config` 覆盖。

## 数据模型

### Game State
- `players`: {player_id -> {score:int}}
- `player_meta`: {player_id -> {name, seat, is_bot}}
- `turn_order`: list[player_id]
- `guesser_index`: int
- `round`: int (1..X)
- `phase`: "draw" | "guess" | "round_end" | "game_over"
- `assignments`: {setter_id -> word}
- `decoys`: list[word] (len=2)
- `drawings`: {setter_id -> image_data}
- `drawing_order`: list[setter_id] (用于给猜题者展示的顺序)
- `word_bank`: list[word] (assignments + decoys，打乱后固定)
- `last_result`: {...} (上一关结果、加分)
- `word_bag`: list[word] (剩余词卡袋)
- `round_end_by`: Optional[player_id]（记录继续/结束选择者）
- `config`, `game_over`

### last_result 示例
```
{
  "round": 2,
  "guesser_id": "...",
  "matches": {"setter_id": "word"},
  "correct": ["setter_id", "setter_id"],
  "scores_delta": {"player_id": 2}
}
```

## 轮次流程
1. 初始化/新猜题者：
   - 设 `guesser_id = turn_order[guesser_index]`
   - 生成 `assignments` 与 `decoys`（抽 P+1 词）
   - 清空 `drawings`/`matches`，`phase="draw"`
2. 作画阶段：
   - 出题者提交图像，猜题者等待
   - 全部提交后进入 `phase="guess"`，生成 `drawing_order`、`word_bank`
3. 猜题阶段：
   - 猜题者提交 `matches`
   - 计分、写入 `last_result`
4. 回合结束：
   - 进入 `phase="round_end"`，玩家选择继续或结束
5. 推进：
   - 选择继续：若 `round < X`，`round += 1` 回到作画阶段并重新抽词
   - 若 `round == X`，`guesser_index += 1`，若轮完所有玩家则 `game_over`
   - 选择结束：`game_over`

## Actions & 校验
- `submit_drawing {image_data}`：
  - 仅出题者、仅 draw 阶段、每人一次
- `submit_matches {matches:[{drawing_id, word}]}`：
  - 仅猜题者、仅 guess 阶段
  - 每个 drawing_id 只能出现一次；word 必须在 word_bank 内且不重复
- `continue_game {}` / `end_game {}`：
  - 仅 round_end 阶段
  - MVP: 任意玩家触发，首个动作生效（可后续扩展为投票或主持人决定）

## Public View
- 公共字段：`phase`, `round`, `rounds_per_guesser`, `guesser_id`, `guesser_name`, `scores`
- 出题者可见：自己的 `prompt_word`
- 猜题者可见：`drawings`（image_data + drawing_id + author_name）、`word_bank`
- 所有人可见：提交状态、`last_result`（用于上轮回顾）与 round_end 选择提示

## 前端实现方案

### 画布与印章
- 新面板：`impressionPanel`，包含画布、印章按钮、旋转控制、剩余印章、Undo、废纸开关。
- 画布使用 `<canvas>`，基础大小来自 config。
- 记录 `stampHistory`：`[{shape, color, alpha, x, y, size, rotation, mask?}]`。
- `renderCanvas()` 清空画布后按历史逐个重绘。

### 选择与旋转控件
- 取消旋转滑动条，改为画布内的“选中框 + 左右旋转按钮”。
- 仅允许**最新**印章被选中/移动/旋转/Mask；旧印章一旦落下即固定。
- 旋转按钮只在画布内且已有印章时显示，位置紧贴选中框并随最新印章移动。

### 印章绘制
- 印章支持旋转（不支持缩放）：`ctx.save()` → `translate(x, y)` → `rotate(rotation)` → 绘制形状 → `restore()`
- circle：`ctx.arc(0, 0, size/2, 0, 2π)`
- square：`ctx.rect(-size/2, -size/2, size, size)`
- triangle：等边三角形顶点计算（以原点为中心）
- bar：`width=size`, `height=size*bar_ratio`

### 按压/透明度
- pointerdown 记录 `pressStart`，按住时长用于计算 alpha（例如 0.2→1.0，500ms 封顶）。
- pointerup 计算 alpha 并落下一个 stamp；不支持持续加深。
- 可选：显示半透明预览或显示进度条。

### 废纸遮罩
- 点击“废纸”后显示可拖拽矩形（overlay div 或第二层 canvas），支持旋转与缩放（手柄或快捷键）。
- 落印时用矩形的变换矩阵生成 clip 区域，`ctx.clip("evenodd")` 将遮罩区域排除。
- 每次落印后自动清除遮罩。

### Undo
- `Undo` 从 `stampHistory` pop，重新渲染。
- 同时恢复剩余印章数。

### 猜题拖拽
- 词条区域：`draggable` 的 chip。
- 画作区域：drop target，显示当前绑定词。
- 支持点击清除或拖回词条区。
- “提交”按钮在所有画作都已绑定词时可用。

### 回合结束
- 显示上一轮结果 + “继续 / 结束”按钮；触发 `continue_game` 或 `end_game`。

## 后端实现方案
- 新模块 `game/impression_flower.py`：
  - `init_game`：初始化轮次、角色、分数、词袋。
  - `apply_action`：收图/收配对并推进（含 round_end 继续/结束）。
  - `get_public_view`：按角色裁剪字段（猜题者可见作者）。
  - `bot_move`：简单随机盖章 + 随机配对。
- 在 `game/definitions.py` 注册 action/config schema；`game/__init__.py` export。
- 在 `static/index.html` 增加游戏选项与面板；`static/style.css` 加样式；`static/app.js` 加渲染与交互逻辑。

## 测试建议
- init_game: P+1 词正确分配；round=1；guesser=seat0。
- draw 阶段：P-1 次提交后切换到 guess。
- guess 阶段：计分按当前轮次累加。
- round_end：continue/end 分支正确推进或结束。
- X 轮后正确进入下一猜题者，所有人轮完 game_over。
- word_pool 为空或不足时能循环补齐。
