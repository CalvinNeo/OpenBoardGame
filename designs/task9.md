# 猜狐狸 / 帕瓦仪式 (Pow Wow / Coyote) 规则说明

## 1. 游戏目标
推测场上**所有玩家**（包括你自己）头顶羽毛数值的**总和**。
* **胜利条件**：成为最后一名未被淘汰的玩家。
* **淘汰条件**：通常集齐 3 个惩罚标记（如秃鹫/弹孔）即出局。

---

## 2. 游戏流程

### 准备阶段
1.  每位玩家佩戴头带。
2.  洗混羽毛牌堆，面朝下放置。
3.  每人抽一张插在头带上。
    * **重点**：只能看别人的牌，**绝对不可看自己的牌**。

### 回合阶段（轮流行动）
按顺时针方向，轮到你时**二选一**：

**A. 报数 (Bid)**
* 报出一个数字，猜测当前场上的**总和**。
* **限制**：你报的数字必须**大于**上家报出的数字。

**B. 质疑 (Challenge / Coyote!)**
* 当你认为上家报数**超过**了实际总和，大喊“**开！**”。
* 所有人摘牌，结算数值。

### 结算阶段
计算所有牌的实际总和：
* **实际总和 < 上家报数**：质疑成功，**上家**（报数者）输，受罚。
* **实际总和 ≥ 上家报数**：质疑失败，**你**（质疑者）输，受罚。

---

## 3. 羽毛列表 (牌表)

### 基础数字牌
直接进行加减运算。

| 牌面 | 数量 | 说明 |
| :--- | :--- | :--- |
| **0** | 4 | 无数值 |
| **1 ~ 5** | 各4 | 小数字 |
| **10** | 3 | 中等数字 |
| **15** | 2 | 大数字 |
| **20** | 1 | 最大基础数字，极具干扰性 |
| **-5** | 2 | 负数 |
| **-10** | 1 | 大负数 |

### 特殊功能牌 (按顺序结算)
必须严格按照以下 **1 -> 2 -> 3** 的优先级顺序结算总和。

#### 1. 归零牌 (Max -> 0)
* **图标**：通常是一个划掉的红圈或写着 Max=0。
* **效果**：场上数值**最大**的那根数字牌变为 **0**。
* *注：仅对正数生效；若有多张最大牌，只变一张（通常效果一样）。*

#### 2. 神秘牌 (?)
* **图标**：问号。
* **效果**：从牌堆顶**再抽一张牌**，将其数值或效果加入计算。
* *注：若抽到特殊牌，继续递归结算。*

#### 3. 翻倍牌 (x2)
* **图标**：x2 或 酋长头像。
* **效果**：将上述所有步骤计算完后的总和 **乘以 2**。
* *注：若场上有两张 x2，则变为 x4。*

---

## 4. 结算示例
**场况**：玩家A(20), 玩家B(Max->0), 玩家C(5)
1.  **原始数字**：20 + 5 = 25
2.  **处理 Max->0**：最大的 20 变为 0
3.  **最终总和**：0 + 5 = **5**

*(若上家叫价 6，则上家输；若上家叫价 5，则质疑者输)*

## 追加实现调整说明（UI/交互）

- 上一轮结果与状态需要展示在一个带背景色的提示框中。
- 提示框中需要显示“我自己的隐藏牌”。
- 若该轮结算过程中出现“问号牌”，Summary 需要标明问号牌抽到的具体牌。
- 当前轮的 Bid 与 Bidder 需要红色、加粗、加大显示。
- Bid 输入框默认填入“当前合法的最小 bid”，并提供 `+` / `-` 按钮便于调整。
- 增加“重置整局游戏”的按钮。
